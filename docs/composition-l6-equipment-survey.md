## 0. 结论速览

| 排序 | 候选 | 定位 | 引擎存量 | 工作量 | 推荐 |
|---|---|---|---|---|---|
| 1 | **条形磁铁（磁偶极子）** | 新场源 kind | 3D 无（2D 有可复用公式） | **S–M** | ✅ 下一批实施 |
| 2 | **匀强磁场区（区域场）** | 新场源 kind（有界区域） | 无（概念简单） | **M** | ✅ 下一批实施 |
| 3 | 有限长通电螺线管 | 新场源 kind 或预设组合 | 无（线圈可近似叠加） | M–L | ⏳ 第二波（可先走预设组合） |
| 4 | 均匀带电球壳（导体球） | 新场源 kind | 无（分段闭式） | S–M | ⏳ 第二波 |
| 5 | 通电矩形线框 | 需先补有限长直段原型 | 无（直导线是无限长） | M–L | ⏳ 第三波 |
| 6 | 接地导体平面（镜像） | 边界值问题 | 无 | L | ❌ 不推荐（超纲 + 数值风险） |
| 7 | 电偶极子 | — | — | — | ❌ 拒绝（与双点电荷重叠） |

**下一批推荐（1–2 类）**：**条形磁铁（磁偶极子）** + **匀强磁场区**。二者互补覆盖高中电磁学两大核心可视化场景
（磁感线拓扑 / 带电粒子在匀强磁场中运动），引擎均为低成本闭式或常量场，与现四类零重叠，且都不引入
有限长分段求和的追踪成本（参见 #93 实测的重追踪成本教训）。

## 1. 现状基线（四类场源的能力与扩展面）

- **引擎原型**（`fields3d.ts:25-78`）：`point-charge`（库仑场）/`charged-plate`（无限大平面）/`straight-wire`（无限长）/
  `circular-coil`（毕奥-萨伐尔 96 段求和）。全部解析求值 + 叠加原理（`totalElectricField` / `totalMagneticField`），
  源点附近以 `FIELD_SOURCE_EPS=1e-9` 遮蔽。
- **校验面**（`physics-core/src/physics/composition.ts:59`）：逐源合法性校验（电荷/面密度、导线方向退化、线圈半径等）+
  粒子/时长/采样数；新增 kind 必须在此补分支。
- **渲染面**（`sourceMeshes.ts`）：每 kind 一段网格构造 + 朝向对齐（四元数）+ 高亮；`userData.sourceId` 拾取。
- **种子面**（`fieldLineSeeds.ts`）：每 kind 一套避奇点种子策略（点电荷球面 / 极板离面网格 / 导线同心圆 / 线圈环向）。
- **交互面现状（关键约束）**：检查器只编辑标量参数（电荷/电流/匝数/半径），**朝向字段（法线/方向/轴）无 UI 编辑**——
  新 kind 的「朝向交互」依赖 #100（器材旋转编辑，M5 parked）；本调查的交互成本按「位置拖拽立即可用、朝向编辑随 #100」估计。
- **成本基线**：场线追踪每场点对每源求值 1 次（RK2 需 2 次/步）；线圈 96 段/求值是当前最贵源（#93 实测 4 源重场景
  2× 密度全量重追踪 ~260ms/次）。**任何新增源的每场点求值成本不得显著高于线圈**——这是候选排序的硬约束之一。

## 2. 候选评估（7 类 × 5 维度）

### A. 条形磁铁（磁偶极子）✅ 推荐

- **引擎原型存量**：3D 无。但 **2D 已有可复用公式**：`current-magnetic-field.ts` 的 `dipoleFieldAt`
  （`B ∝ [3(m·r̂)r̂ − m]/r³`，磁矩 `m = N·I·A`），3D 化为逐分量版本即可，属闭式解析、单次求值（与点电荷同量级成本）。
  数值风险：近场 1/r³ 奇异 → 遮蔽半径需比点电荷更粗（类比 `FIELD_SOURCE_EPS` 上调至特征尺度系数）；远场精度良好。
- **种子策略可行性**：与点电荷同构（偶极矩轴 + 环向/极向种子）；教材需要「外部：N→S 闭合；内部：(磁铁内) S→N」拓扑，
  轴附近种子避开奇异核即可，低难度。
- **sourceMesh / 交互面**：盒体 + 红(N)/蓝(S) 端色，朝向 = 偶极矩方向；位置拖拽立即可用，朝向编辑随 #100。
- **教学价值**：**必修三 第十三章 13.1 磁场 磁感线**——教材以条形磁铁引入磁感线（`experiments/必修三_第5章...:124,161-170`：
  「螺线管外部磁场与条形磁铁相似」，条形磁铁是可复现该结论的基准器材）。实验 2「探究通电直导线和通电线圈周围的磁场（用小磁针/铁屑）」
  同节配套。
- **工作量**：**S–M**（引擎 S + 种子/网格 S + 参数/朝向并入 #100）。

### B. 有限长通电螺线管 ⏳ 第二波

- **引擎原型存量**：无。两条路线：
  (a) **真·分段逼近**：沿轴排 N 匝圆环，每场点 N×96 段求和——重场景（N=20）比单线圈贵 20×，**直接违反成本硬约束**，
  必须降段（每匝 32 段）且仍重；
  (b) **等效磁偶极 + 内部匀强近似**（2D 模型已在用）：外部偶极场、内部轴向匀强——单次求值、正是教材表述
  （「内部近似匀强、外部类似条形磁铁」），缺点是与真螺线管近端有系统偏差（需在 assumptions 明示）。
- **种子策略**：与偶极/线圈同族；内部线段可用轴向导引种子（新增少量策略）。
- **sourceMesh / 交互面**：圆柱 + 绕线纹样 + N/S 标注；长度/半径/匝数参数 + 朝向（随 #100）。
- **教学价值**：**必修三 13.1 实验 2**（通电螺线管磁场，小磁针/铁屑）；「外部像条形磁铁」的对照演示需要条形磁铁（A）先就位。
- **工作量**：路线 (a) M–L（含性能防护）；路线 (b) S–M 但教学保真度打折。**建议先以「预设组合」在 #101 模板中提供**，
  待 A + 预设验证需求后再评估独立 kind。

### C. 匀强磁场区（有界区域场）✅ 推荐

- **引擎原型存量**：无同类；但这是「常量场 + 区域判定」的最简形式（无奇点、无求和）。数值风险在**边界不连续**：
  区域边界处 B 跳变，场线追到边界会折返/终止，需要明确策略（如：域内追踪、越界即停并夹紧末点；或边界处做短过渡带）。
  可先只支持轴对齐盒区（旋转随 #100），把难度压到最低。
- **种子策略**：域内均布平行种子（直线场线）；与「边界终止」策略配合。低难度。
- **sourceMesh / 交互面**：半透明区域盒（低不透明度、可拾取）+ 场方向箭头示意；尺寸参数（长/宽/高）优先，朝向随 #100。
- **教学价值**：**选必二 第一章**：实验 5「观察带电粒子在匀强磁场中做圆周运动」（`experiments/选必二_第1章...:11`）、
  实验 4「电流天平测匀强磁场」（同章）；当前实验台用线圈堆叠**无法产生可靠匀强区**（0.05m 吸附网格使亥姆霍兹几何
  「间距=R」不可达）——区域源是补齐该教学场景的唯一可靠路径。
- **工作量**：**M**（引擎 S + 边界策略 S + 网格/参数 M）。

### D. 均匀带电球壳（导体球）⏳ 第二波

- **引擎原型存量**：无；分段闭式极易（外部等效于球心点电荷、内部 E=0），无求和、无强奇异（球心无源）。
- **种子策略**：点电荷同款球面种子 + 壳内无场线特判；低难度。
- **sourceMesh / 交互面**：球体网格 + 极性着色；仅半径参数（位置拖拽即可，无朝向）。
- **教学价值**：**必修三 第九章 9.4 静电的防止与利用**（实验 6 静电屏蔽 / 实验 7 空腔导体内表面电荷，
  `experiments/必修三_第1章...:14-15`）；但理想球壳仅能表现「屏蔽」的最简形态，**空腔电荷分布/接地现象表达不了**，
  教学价值打折（真正的 9.4 演示需要导体与感应电荷的相互作用，超出当前场源范式）。
- **工作量**：S–M。

### E. 通电矩形线框 ⏳ 第三波

- **引擎原型存量**：无直用原型——现有 `straight-wire` 是**无限长**，矩形线框需要**有限长直段**（新原型，含端部效应）；
  或者用 4 根无限长导线拼接会得到完全错误的角部场。数值风险中等（有限段毕奥-萨伐尔闭式或分段求和）。
- **教学价值**：磁通量（必修三 13.2）、线框在磁场中的转动（发电机原理铺垫）；实验编目中无直接对应演示实验，
  价值低于 A/B/C。
- **工作量**：M–L（先决条件是有限长直段原型）。

### F. 接地导体平面（镜像法）❌ 不推荐

- 引擎为边界值问题（镜像电荷 + 接地约束），与「解析叠加场源」范式不兼容，数值与交互成本均为 L；
  教材层面属静电感应拓展，**超出高中必修演示范围**（必修三 9.4 以定性演示为主）。不建议立项。

### G. 电偶极子 ❌ 拒绝（能力重叠）

- 两个异号 `point-charge` 已可精确构成电偶极子（叠加原理天然支持），独立器材无增量价值；
  如需「一键偶极」体验，归 #101 预设模板（组合层面），不动引擎。

## 3. 重叠分析（逐候选结论）

| 候选 | 能否用现有四类组合替代 | 结论 |
|---|---|---|
| 条形磁铁 | 小半径线圈远场近似偶极，但近场拓扑与 N/S 极视觉符号不同；教材本身需要「条形磁铁」这个对象 | 不可替代（视觉与教学对象不同） |
| 螺线管 | 多线圈沿轴叠放可近似（当前可手动做，但吸附网格让间距随意、体验差） | 部分重叠 → 先预设组合，后评估独立 kind |
| 匀强磁场区 | 亥姆霍兹线圈对理论可行，但 0.05m 吸附网格使「间距=R」不可达，且不适用于电场 | 不可替代 |
| 带电球壳 | 点电荷组合无法表达「内部零场 + 屏蔽」 | 不可替代（但价值打折，见 D） |
| 矩形线框 | 无限长直导线无法拼角部 | 不可替代（需新原型，延后） |
| 电偶极子 | 双点电荷精确构成 | **拒绝** |
| 接地平面 | 无 | 不可替代（但超纲，不推荐） |

## 4. 优先级排序（判定依据）

排序 = 教学价值（教材核心度 × 唯一性）× 引擎成本/风险 × 交互成本 × 与现状重叠，**成本硬约束**：每场点求值成本 ≤ 单线圈量级。

1. **条形磁铁（磁偶极子）**——13.1 磁感线的基准器材；闭式低成本；种子/网格简单。
2. **匀强磁场区**——选必二 1 两大实验的唯一可靠实现路径；常量场低成本；主要成本在边界策略与区域网格。
3. 螺线管——教学价值高但引擎成本高/保真路线未定；先预设组合。
4. 带电球壳——引擎最简单，但教学表达力打折（无空腔/接地）。
5. 矩形线框——先决原型（有限长直段）成本未付，价值一般。
6. 接地平面——超纲 + 高成本，不推荐。
7. 电偶极子——重叠，拒绝。

## 5. 下一批实施拆分建议（供规划者直接立项）

### 推荐批 1：条形磁铁（磁偶极子）

- **实施单 ①（引擎原型）**：`fields3d` 新增 `bar-magnet`（field: 3D 偶极闭式 + 遮蔽半径策略）；
  `composition.ts` 校验分支（磁矩非零、方向退化）；L8 自检接入（轴上解析值差分，参照线圈先例）；
  默认参数（磁矩量级对齐 20 匝/5A 小线圈，使场强尺度与现器材同量级）。
- **实施单 ②（种子与渲染）**：`fieldLineSeeds` 偶极种子（避奇异核、外部 N→S 闭合拓扑）；
  `sourceMeshes` 盒体 + N/S 端色；场线闭环复用 #93 的 `closeNearlyClosedLoop`。
- **实施单 ③（可选并入 ②）**：参数面板（磁矩/尺寸）+ 朝向编辑（依赖 #100；在此之前朝向固定 +y，保持与其他源一致）。

### 推荐批 2：匀强磁场区

- **实施单 ①（引擎原型）**：`fields3d` 新增 `uniform-field-zone`（盒区常量 B + 边界语义：
  域外零场、边界处 `FIELD_SOURCE_EPS` 级过渡或硬边界 + 追踪越界即停；文档化边界约定）；
  校验分支；边界行为的差分测试（域内恒值、域外零）。
- **实施单 ②（种子与渲染）**：域内平行种子 + 边界终止策略；半透明盒网格 + 场方向箭头；
  性能复核（域内直线场线追踪成本极低，不触 #93 成本约束）。
- **实施单 ③（交互）**：区域尺寸参数（三轴）；朝向随 #100。

### 其他候选（第二波后备，供 backlog 参考）

- 螺线管：先并入 **#101 预设模板**（多线圈自动排布 → 一键螺线管），观察需求后再评估独立 kind（含性能单）。
- 带电球壳：引擎单 + 渲染单（两单即可立项，价值取决是否补「空腔导体内表面电荷」的定性示意）。
- 矩形线框：先决「有限长直段」原型单，再谈线框器材。不建议近期启动。
