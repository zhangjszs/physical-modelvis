## 实验 1：焦耳热功当量实验（历史介绍/原理演示）

### 一、实验目的

1. 了解焦耳测定热功当量的实验原理和装置。
2. 理解做功与传热在改变物体内能上的等效性。
3. 体会焦耳的科学研究精神和实验设计的精妙。
4. 知道热功当量 J ≈ 4.18 J/cal。

### 二、实验器材（历史原装置，原理演示用）

- 绝热量热器一只（带叶片搅拌器）
- 重物两个（已知质量，可下落带动叶片）
- 重物下落装置（带绳、滑轮）
- 温度计一支（精度 0.01 ℃，焦耳自制高灵敏度温度计）
- 水（已知质量）
- 卷尺（测量重物下落高度）
- 铅制容器（绝热）

### 三、实验原理

焦耳于 1840 年代进行了多种实验以测定功与热的等量关系。其经典实验装置如下：

重物下落通过绳子带动叶片旋转，叶片搅拌容器中的水。由于水的黏性，水的动能最终转化为内能，使水温上升。

测量：
- 重物质量 m 及下落高度 h，可计算重力做的功 W = mgh。
- 水的质量 M、水的比热容 c、温度升高 Δt，可计算水吸收的热量 Q = McΔt。

在绝热条件下，外界对系统做的功全部转化为系统内能增加，即 W = ΔU = Q。焦耳多次实验发现 W/Q 比值为一常数，称为热功当量 J = W/Q ≈ 4.18 J/cal。

意义：功与热在改变内能上等效，1 cal = 4.18 J。

### 四、实验步骤

1. 在量热器中加入已知质量的水（如 1 kg），用精度高的温度计测量初始温度 t₁。
2. 将两个质量相等的重物（各 5 kg 左右）通过绳子和滑轮连接到叶片轴上。
3. 释放重物，使其下落带动叶片搅拌水。
4. 重物落地后，再将其升起，再次释放，重复多次（如 20 次）。
5. 最后测量水的温度 t₂。
6. 计算重物做的总功 W = nmgh（n 为下落次数）。
7. 计算水吸收的热量 Q = Mc(t₂ - t₁)。
8. 计算热功当量 J = W/Q。

### 五、实验现象与数据记录

| 量 | 数值 |
| - | ---- |
| 水质量 M | 1.0 kg |
| 重物总质量 m | 10.0 kg |
| 下落高度 h | 1.0 m |
| 下落次数 n | 20 |
| 初温 t₁ | 20.00 ℃ |
| 末温 t₂ | 20.47 ℃ |
| 总做功 W = nmgh | 20 × 10 × 9.8 × 1 = 1960 J |
| 水吸热 Q = McΔt | 1 × 4200 × 0.47 = 1974 J |
| 热功当量 J = W/Q | 0.99（约 4.18 J/cal 转换后） |

注：焦耳实际测得的温升极小（约 0.5 ℃），他自制了能识别 1/200 ℃ 的高灵敏度温度计。

### 六、实验结果与结论

1. 重物做的功与水升温吸收的热量数值上相等。
2. 热功当量 J ≈ 4.18 J/cal。
3. 做功和热传递是改变内能的两种等效方式，它们的本质都是能量的转移或转化。

### 七、误差分析

1. **绝热不严**：容器向环境散热使测得的温升偏小。改进措施：使用绝热材料（焦耳用铅容器+空气夹层）。
2. **温度计精度**：普通温度计无法测出微小温升。改进措施：使用高精度温度计。
3. **摩擦损失**：滑轮和轴承摩擦使部分功未传给水。改进措施：减少摩擦。
4. **水的比热容**：水的比热容大，温升小，不利于测量。改进措施：可换用比热容小的液体（如水银）。
5. **重物动能**：重物落地时仍有动能，未完全转化为水的内能。改进措施：让重物缓慢下落。

### 八、注意事项

1. 此实验在中学通常以原理介绍和模拟演示为主，实际操作温升很小，需高精度仪器。
2. 实验关键在于绝热装置和温度计的灵敏度。
3. 焦耳的实验精度极高，是物理学史上的经典实验之一。

## 实验 2：焦耳电热实验（电功改变内能）

### 一、实验目的

1. 通过电功加热液体，验证电功与热效应的等量关系。
2. 知道电功可以转化为内能。
3. 进一步理解做功是改变内能的方式之一。

### 二、实验器材

- 量热器一只（带电阻丝）
- 直流电源（约 6～12 V）
- 电流表一只
- 电压表一只
- 温度计一支（精度 0.1 ℃）
- 水（已知质量）
- 秒表
- 导线若干
- 开关一只

### 三、实验原理

焦耳的另一个实验是用电功加热液体。当电流通过电阻丝时，电能转化为热能（焦耳热），传递给水使水温升高。

电功 W = UIt（U 为电压，I 为电流，t 为时间）。
水吸热 Q = McΔt。

在绝热条件下，W = Q，即电功等于内能增加。

焦耳发现：相同的温升所需电功与机械功相等，证明电功和机械功在改变内能上是等效的。

### 四、实验步骤

1. 在量热器内筒中加入已知质量的水（如 200 g），测量初温 t₁。
2. 将电阻丝浸入水中，连接电路（电源、开关、电流表、电压表、电阻丝）。
3. 接通电源，记录电压 U、电流 I。
4. 同时开始计时，每隔 1 分钟记录一次温度。
5. 加热约 5～10 分钟（温度升高约 5～10 ℃）后断开电源。
6. 记录加热时间 t 和最终温度 t₂。
7. 计算电功 W = UIt 和水吸热 Q = McΔt。
8. 比较 W 和 Q。

### 五、实验现象与数据记录

| 量 | 数值 |
| - | --- |
| 水质量 M | 0.20 kg |
| 电压 U | 6.0 V |
| 电流 I | 1.5 A |
| 加热时间 t | 600 s |
| 初温 t₁ | 20.0 ℃ |
| 末温 t₂ | 32.5 ℃ |
| 温度变化 Δt | 12.5 ℃ |
| 电功 W = UIt | 6 × 1.5 × 600 = 5400 J |
| 水吸热 Q = McΔt | 0.2 × 4200 × 12.5 = 10500 J（注：实际 Q 应等于 W，差异来自散热等误差） |

### 六、实验结果与结论

1. 电流通过电阻丝做功，电能转化为内能，使水温升高。
2. 电功与水吸热近似相等，验证了电功改变内能。
3. 焦耳由此实验得出：相同的温升所需电功与机械功相等。

### 七、误差分析

1. **散热损失**：实验过程中向环境散热。改进措施：用绝热材料包裹量热器。
2. **温度不均**：水温分布不均。改进措施：用搅拌器搅拌。
3. **电阻丝热容**：电阻丝本身也吸热。改进措施：考虑电阻丝的热容。
4. **电压电流不稳**：电源波动。改进措施：使用稳压电源。

### 八、注意事项

1. 电阻丝要完全浸入水中，避免干烧。
2. 通电时间不要过长，温度不要过高。
3. 实验中要不断搅拌使温度均匀。
4. 注意用电安全，防止触电。

## 实验 3：做功改变物体的内能（压缩气体点燃棉花）

### 一、实验目的

1. 通过压缩气体做功使气体温度升高，直观感受做功改变内能。
2. 理解绝热压缩过程中功与内能的关系。
3. 知道做功是改变内能的一种方式。

### 二、实验器材

- 压缩点火仪（带活塞的厚壁玻璃筒，底部可放易燃物）
- 棉花少量（或硝化棉）
- 镊子
- 防护眼镜
- 润滑油少量（用于活塞）

### 三、实验原理

当外界对气体做功时（如压缩气体），气体的内能增加，温度升高。在绝热压缩过程中（即没有热传递），外界做的功全部转化为气体的内能。

根据热力学第一定律 ΔU = W + Q，绝热时 Q = 0，所以 ΔU = W。当外界对气体做功 W > 0，气体内能增加，温度升高。

当气体被快速压缩时，温度可升至棉花（或硝化棉）的燃点，使其点燃。这是柴油机点火的工作原理。

### 四、实验步骤

1. 在压缩点火仪的玻璃筒底部放置少量棉花（用镊子）。
2. 在活塞上涂少量润滑油以保证气密性。
3. 将活塞插入玻璃筒中，迅速用力向下压。
4. 观察筒内棉花是否被点燃。
5. 若未点燃，可重复实验（增大压缩速度或使用硝化棉）。
6. 实验后清理残留物。

### 五、实验现象与数据记录

| 操作 | 现象 |
| ---- | ---- |
| 缓慢压缩 | 棉花不点燃，温度升高不明显 |
| 快速压缩 | 棉花被点燃，闪光并冒烟 |
| 重复实验 | 现象可重复 |

### 六、实验结果与结论

1. 快速压缩气体时，气体温度急剧升高，达到棉花的燃点使其点燃。
2. 实验表明：外界对气体做功，气体内能增加，温度升高。
3. 做功是改变物体内能的一种方式。

### 七、误差分析

1. **气密性不良**：活塞漏气使压缩比不足。改进措施：涂润滑油保证密封。
2. **压缩速度不够**：缓慢压缩时热量散失，温度升高不显著。改进措施：快速用力下压。
3. **棉花潮湿**：潮湿的棉花不易点燃。改进措施：使用干燥棉花或硝化棉。
4. **压缩比不足**：活塞行程不够。改进措施：选择合适的压缩点火仪。

### 八、注意事项

1. 实验时要戴防护眼镜，防止玻璃筒破裂伤人。
2. 棉花不要放太多，少量即可。
3. 使用硝化棉时要特别注意安全，量要少。
4. 活塞要润滑，以防卡死或漏气。
5. 实验后等玻璃筒冷却再清理。
6. 不要将手或脸对准筒口。

## 实验 4：热传递改变物体的内能

### 一、实验目的

1. 通过观察热传递现象，理解热传递是改变内能的另一种方式。
2. 知道热传递的三种方式：传导、对流、辐射。
3. 体会做功和热传递在改变内能上的等效性。

### 二、实验器材

- 金属棒一根（如铜棒或铝棒）
- 凡士林（或黄油）少量
- 几颗小钢珠或图钉
- 酒精灯、火柴
- 铁架台及铁夹
- 烧杯（盛水）
- 锅或烧杯（可加热）
- 红墨水少量
- 验温器或温度计
- 黑白两只烧瓶（涂黑漆和白漆）
- 红外灯或白炽灯

### 三、实验原理

热传递是改变物体内能的另一种方式。热传递有三种方式：
1. 热传导：热量沿物体从高温部分传向低温部分。
2. 对流：流体中由于温度差引起的热量传递。
3. 热辐射：物体以电磁波形式向外辐射热量。

热传递的本质是内能从高温物体转移到低温物体，过程中内能总和不变。

热传递与做功在改变内能上是等效的：ΔU = W + Q。当不做功时（W = 0），ΔU = Q。

### 四、实验步骤

1. **热传导**：在金属棒上等距贴几粒用凡士林粘住的小钢珠，一端用酒精灯加热。观察钢珠依次脱落的顺序。
2. **对流**：在烧杯中加水，滴入几滴红墨水，从底部加热。观察红色水流的运动路径。
3. **热辐射**：将两只烧瓶（一只涂黑、一只涂白）内充入空气，连接 U 形管。用红外灯照射，观察哪只瓶内气体膨胀更多。
4. **热平衡**：将热水倒入冷水中，测量混合前后的温度。

### 五、实验现象与数据记录

| 实验 | 现象 |
| ---- | ---- |
| 热传导 | 靠近加热端的钢珠先脱落，依次由近及远脱落 |
| 对流 | 红色水流上升、下降，形成循环（底部热水上升，顶部冷水下降） |
| 热辐射（黑瓶） | 涂黑瓶内气体膨胀更多，U 形管液面差更大 |
| 热辐射（白瓶） | 白瓶内气体膨胀较少 |
| 热平衡 | 混合后温度介于两者之间 |

### 六、实验结果与结论

1. 热传导使热量沿物体由高温端传向低温端。
2. 对流是流体中由于温差引起的循环传热。
3. 黑色物体吸收辐射热的能力强于白色物体。
4. 热传递是改变内能的方式之一，与做功在改变内能上等效。

### 七、误差分析

1. **凡士林量不同**：粘钢珠的凡士林量不一致影响脱落顺序。改进措施：每颗钢珠用相同量凡士林。
2. **环境气流**：对流实验受气流影响。改进措施：在密闭容器中进行。
3. **辐射源距离**：辐射灯到两只瓶距离不一致。改进措施：保持距离相等。
4. **散热损失**：实验中向环境散热。改进措施：保温。

### 八、注意事项

1. 加热金属棒时注意防止烫伤。
2. 加热烧杯时要均匀加热，避免局部过热。
3. 红外灯温度高，避免直视或长时间照射皮肤。
4. 实验中注意防火。

## 实验 5：能量转化与守恒演示

### 一、实验目的

1. 演示不同形式能量之间的相互转化。
2. 理解能量守恒定律：能量不会创生也不会消灭，只能从一种形式转化为另一种形式。
3. 体会能量守恒定律是自然界最基本的普遍规律之一。

### 二、实验器材

- 单摆（小球+细线）
- 滚摆（约氏摆）
- 电磁感应演示器（线圈+磁铁+电流计）
- 手摇发电机
- 小灯泡
- 太阳能电池板
- 小风扇（电动机）
- 干电池
- 钩码、弹簧
- 验证机械能守恒的装置（如光电门）

### 三、实验原理

能量守恒定律：能量既不会凭空产生，也不会凭空消失，它只能从一种形式转化为其他形式，或者从一个物体转移到其他物体，在转化和转移过程中能量的总量保持不变。

各种形式能量可相互转化：
- 重力势能 ↔ 动能（单摆、滚摆）
- 电能 ↔ 机械能（发电机、电动机）
- 电能 → 光能和热能（灯泡）
- 光能 → 电能（太阳能电池）
- 化学能 → 电能（电池）

热力学第一定律是能量守恒定律在热现象中的具体体现。

### 四、实验步骤

1. **机械能守恒**：让单摆摆动，观察摆球高度；让滚摆上下运动，观察其上升高度。
2. **电能与机械能转化**：摇动手摇发电机，使小灯泡发光（机械能→电能→光能和热能）。反之，通电使小风扇转动（电能→机械能）。
3. **光能与电能转化**：用强光照射太阳能电池板，连接小灯泡使其发光（光能→电能→光能）。
4. **化学能与电能**：用干电池使小灯泡发光（化学能→电能→光能和热能）。
5. **电磁感应**：将磁铁插入或拔出线圈，观察电流计指针偏转（机械能→电能）。
6. 分析各种转化过程中能量的去向。

### 五、实验现象与数据记录

| 实验 | 能量转化 |
| ---- | -------- |
| 单摆 | 重力势能 ↔ 动能（总机械能基本守恒，略有减少因空气阻力） |
| 滚摆 | 重力势能 ↔ 动能（每次上升高度略减，因摩擦） |
| 手摇发电机 | 机械能 → 电能 → 光能和热能 |
| 太阳能电池 | 光能 → 电能 → 光能 |
| 电磁感应 | 机械能 → 电能 |

### 六、实验结果与结论

1. 各种形式能量可以相互转化。
2. 转化过程中总能量保持不变（守恒）。
3. 实际过程中由于摩擦等因素，部分机械能会转化为内能，但总能量仍守恒。

### 七、误差分析

1. **摩擦损失**：单摆、滚摆的振幅逐渐减小，机械能转化为内能。这是正常的能量耗散，非误差。
2. **能量转换效率**：发电机、电动机等转换效率不为 100%。改进措施：使用高品质器材。
3. **测量精度**：定性演示无需精确测量。

### 八、注意事项

1. 实验以定性演示为主，重点突出能量转化的思想。
2. 手摇发电机不要过快，以防烧坏灯泡。
3. 太阳能电池板避免强烈光照时间过长。
4. 强调能量守恒是自然界最普遍的规律之一。

## 实验 6：第二类永动机演示（不可能制成）

### 一、实验目的

1. 了解第二类永动机的概念。
2. 知道第二类永动机不可能制成的原因——热力学第二定律。
3. 理解热传递的方向性和热机效率的极限。

### 二、实验器材

- 历史资料介绍（卡诺热机模型图）
- 制冷机/热泵示意图
- 热机模型（如有）
- 多媒体课件

### 三、实验原理

第二类永动机是指只从单一热源吸热，全部转化为功而不产生其他影响的机器。它不违反能量守恒定律，但违反热力学第二定律。

热力学第二定律的开尔文表述：不可能从单一热源吸热，使之完全变为功而不产生其他影响。
克劳修斯表述：不可能把热量从低温物体传到高温物体而不产生其他影响。

热机效率 η = 1 - T₂/T₁（卡诺效率），永远小于 100%。

### 四、实验步骤

1. **介绍历史**：讲述历史上各种第二类永动机的设计及其失败原因。
2. **分析热机模型**：分析卡诺热机的工作原理，强调必须有高温热源和低温热源。
3. **讨论制冷机**：制冷机将热量从低温物体传到高温物体，但需要消耗电能做功。
4. **介绍热传导方向性**：热量自发地从高温物体传向低温物体，反之需要消耗外功。

### 五、实验现象与数据记录

| 内容 | 说明 |
| ---- | ---- |
| 第二类永动机设想 | 从海水吸热做功，海水温度降低 |
| 实际情况 | 不可能实现，违反热力学第二定律 |
| 卡诺效率 | η = 1 - T₂/T₁ < 100% |
| 制冷机 | 需消耗电能才能将热量从低温传到高温 |

### 六、实验结果与结论

1. 第二类永动机不可能制成。
2. 热机效率永远小于 100%，必须向低温热源放热。
3. 热量传递有方向性：自发从高温传向低温。

### 七、误差分析

本实验为概念性介绍，无测量误差。

### 八、注意事项

1. 本实验以讲授和讨论为主。
2. 要强调热力学第二定律的两种表述是等价的。
3. 区分第一类永动机（违反能量守恒）和第二类永动机（违反热力学第二定律）。

## 实验 7：热传导的方向性演示

### 一、实验目的

1. 观察热传导的方向性，知道热量自发地从高温物体传向低温物体。
2. 理解热力学第二定律的克劳修斯表述。
3. 体会自然过程的方向性。

### 二、实验器材

- 两只相同烧杯
- 热水、冷水
- 温度计两支
- 红墨水少量
- 大试管（导热材料）
- 小试管（盛有色水）

### 三、实验原理

热力学第二定律的克劳修斯表述：热量不能自发地从低温物体传到高温物体。

实验中：
- 热水放入冷水环境中，热水会自动降温，冷水升温，最终达到热平衡。
- 反过来，热量不会自发地从低温物体传到高温物体。

这种自发过程的方向性是热力学第二定律的体现。

### 四、实验步骤

1. 在两只烧杯中分别盛等质量的热水（约 60 ℃）和冷水（约 20 ℃）。
2. 用温度计分别测量初温，并记录。
3. 将装热水的烧杯放入装冷水的更大容器中（或两烧杯紧贴）。
4. 每隔 1 分钟测量并记录两只烧杯的水温。
5. 观察热水温度下降、冷水温度上升的过程。
6. 等待两杯水温接近相同（约 40 ℃），记录终温。
7. 思考：能否让热量自发地从低温物体传到高温物体？

### 五、实验现象与数据记录

| 时间 (min) | 热水温度 (℃) | 冷水温度 (℃) |
| ---------- | ----------- | ----------- |
| 0 | 60.0 | 20.0 |
| 2 | 55.0 | 25.0 |
| 5 | 48.0 | 32.0 |
| 10 | 42.0 | 38.0 |
| 20 | 40.0 | 40.0 |

观察：热水持续降温，冷水持续升温，最终两杯水温相同（达到热平衡）。

### 六、实验结果与结论

1. 热量自发地从高温物体（热水）传向低温物体（冷水）。
2. 最终达到热平衡（两杯水温相同）。
3. 反方向（从低温传向高温）不会自发发生，需要外界做功（如制冷机）。
4. 热传导有方向性，符合热力学第二定律。

### 七、误差分析

1. **散热损失**：实验过程中向环境散热。改进措施：用保温材料包裹。
2. **温度不均**：水温分布不均。改进措施：搅拌。
3. **温度计精度**：普通温度计读数有偏差。

### 八、注意事项

1. 实验中要不断搅拌使水温均匀。
2. 热水温度不要过高，避免烫伤。
3. 实验时间要足够长，使两杯水温接近相同。
4. 强调"自发"二字，即不需外界干预；通过做功可以实现相反方向的热传递（如制冷机）。
