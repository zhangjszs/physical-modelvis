## 实验 1：演示奥斯特实验（电流的磁效应）

### 一、实验目的

1. 通过实验观察通电导线对小磁针的作用，认识电流的磁效应。
2. 理解电与磁之间的联系，体会奥斯特发现的重要意义。
3. 知道电流周围存在磁场，磁场方向与电流方向有关。

### 二、实验器材

- 直流电源一个（一节干电池或稳压电源 3-6 V）
- 直导线一根（长约 30-50 cm，铜质）
- 小磁针若干（支架式或自由转动式）
- 开关一个
- 滑动变阻器一个（限制电流，保护电路）
- 导线若干
- 铁架台一个（用于支撑导线）

### 三、实验原理

1820 年丹麦物理学家奥斯特发现：当导线通电时，导线下方平行放置的小磁针会发生偏转。这一现象首次揭示了电与磁的联系，称为电流的磁效应。

电流的磁效应表明：电流周围存在磁场，磁场对放入其中的磁针有力的作用。磁场的方向与电流方向有关，遵循安培定则（右手螺旋定则）：
- 直线电流的磁场：右手握住导线，拇指指向电流方向，四指弯曲的方向即为磁场方向。
- 通电螺线管的磁场：右手握住螺线管，四指弯曲指向电流方向，拇指所指即为 N 极。

奥斯特实验的重要意义：首次揭示了电与磁的联系，打破了电现象和磁现象相互孤立的观念，为电磁学的发展奠定了基础，也为法拉第发现电磁感应现象开启了思路。

### 四、实验步骤

1. 将小磁针放在水平桌面上，使其能在水平面内自由转动，待其静止时指向南北方向。
2. 在小磁针上方（或下方）沿南北方向水平放置直导线，导线与小磁针平行。
3. 将导线通过开关、滑动变阻器连接到电源。
4. 闭合开关，使导线通电（电流方向由南向北或由北向南），观察小磁针的偏转情况。
5. 改变电流方向（交换电源正负极），观察小磁针的偏转方向是否改变。
6. 断开开关，观察小磁针是否恢复到原来位置。
7. 改变电流大小（调节滑动变阻器），观察小磁针偏转角度的变化。
8. 将导线放在小磁针下方，重复实验，对比上下方磁针偏转方向。

### 五、实验现象与数据记录

| 实验情景 | 小磁针偏转方向 | 现象分析 |
| -------- | -------------- | -------- |
| 不通电 | 不偏转 | 导线不带电，无磁场 |
| 通电，电流向北 | N 极向西偏转 | 电流方向决定磁场方向 |
| 通电，电流向南 | N 极向东偏转 | 反向电流，磁场反向 |
| 断电 | 恢复原位 | 无电流即无磁场 |
| 增大电流 | 偏转角度变大 | 电流越大，磁场越强 |
| 导线在小磁针上方/下方 | 偏转方向相反 | 导线两侧磁场方向相反 |

### 六、实验结果与结论

1. 通电导线对小磁针有力的作用，说明电流周围存在磁场，即电流具有磁效应。
2. 小磁针的偏转方向与电流方向有关，改变电流方向，小磁针偏转方向也改变。
3. 小磁针偏转角度随电流增大而增大，说明磁场强弱与电流大小有关。
4. 导线上方和下方的磁场方向相反，符合安培定则。
5. 奥斯特实验首次揭示了电与磁的联系，是电磁学的奠基性实验。

### 七、误差分析

1. **地磁场的干扰**：地磁场对小磁针有影响，实验时应使导线沿南北方向放置，这样电流产生的磁场方向为东西方向，与地磁场方向垂直，作用效果最明显。
2. **小磁针磁性不足**：小磁针磁性减弱会导致偏转不明显。改进措施：使用磁性较强的小磁针。
3. **小磁针转轴摩擦**：小磁针转轴摩擦过大会影响偏转。改进措施：使用转轴灵活的小磁针。
4. **电流强度不足**：电流过小时磁场太弱，小磁针偏转不明显。改进措施：适当增大电流，但不要超过导线承受能力。
5. **空气流动影响**：空气流动会干扰小磁针的偏转。改进措施：在无风环境下进行。
6. **导线磁场不均匀**：实际导线有一定粗细，磁场分布与理想直线电流有偏差。
7. **外部磁场干扰**：附近金属物体或电器产生的磁场会干扰实验。

### 八、注意事项

1. 导线必须沿南北方向水平放置，与小磁针平行，使电流磁场垂直于地磁场，效果最明显。
2. 导线应尽量靠近小磁针，但不要接触，以增强磁场作用。
3. 电流不要过大，避免导线发热或损坏电源。
4. 实验应在无风环境下进行，避免空气流动干扰小磁针。
5. 小磁针应能自由转动，转轴摩擦要小。
6. 附近不应有强磁性物体，避免干扰。
7. 通电时间要短，每次读数后立即断电，避免长时间通电。
8. 改变电流方向时应先断开开关，再交换接线。

## 实验 2：探究通电直导线和通电线圈周围的磁场（用小磁针/铁屑）

### 一、实验目的

1. 通过实验观察通电直导线和通电螺线管周围的磁场分布。
2. 学会用铁屑和小磁针显示磁场的分布，理解磁感线的概念。
3. 验证安培定则（右手螺旋定则），理解电流方向与磁场方向的关系。

### 二、实验器材

- 直流电源一个（4-6 V）
- 直导线一根（铜质，长 30 cm）
- 通电螺线管一个（多匝线圈）
- 铁屑一盒（细小铁粉）
- 小磁针若干
- 硬纸板一块（用于撒铁屑）
- 开关、滑动变阻器各一个
- 导线若干
- 透明塑料板或玻璃板（用于观察铁屑分布）

### 三、实验原理

电流周围存在磁场，磁场的分布可以用磁感线形象地描述。磁感线上每一点的切线方向表示该点的磁场方向，磁感线的疏密表示磁场的强弱。

**通电直导线的磁场**：磁场方向由安培定则确定，右手握住导线，拇指指向电流方向，四指弯曲方向即为磁场方向。磁感线是以导线为圆心的同心圆，越靠近导线磁场越强。

**通电螺线管的磁场**：磁场方向由安培定则确定，右手握住螺线管，四指弯曲指向电流方向，拇指所指即为 N 极。螺线管外部磁感线从 N 极出发到 S 极，内部磁感线从 S 极到 N 极，形成闭合曲线。螺线管内部磁场近似匀强磁场。

铁屑在磁场中会被磁化，成为小磁针，沿磁场方向排列，从而显示磁感线的分布。小磁针的 N 极指向即为该点的磁场方向。

### 四、实验步骤

1. **观察通电直导线的磁场**：
   - 将直导线垂直穿过硬纸板，纸板水平放置。
   - 在纸板上均匀撒上一层铁屑。
   - 闭合开关，使导线通电（电流较大）。
   - 轻轻敲击纸板，观察铁屑的排列图案。
   - 在铁屑排列的几个位置放小磁针，观察小磁针的指向。
   - 改变电流方向，观察铁屑和小磁针的变化。
2. **观察通电螺线管的磁场**：
   - 将螺线管水平放置在桌面上，上方放硬纸板。
   - 在纸板上均匀撒上铁屑。
   - 闭合开关，使螺线管通电。
   - 轻轻敲击纸板，观察铁屑的排列图案。
   - 在螺线管两端和内部各放一个小磁针，观察小磁针的指向。
   - 改变电流方向，观察小磁针的变化。
3. 实验完毕后断开电源，整理器材。

### 五、实验现象与数据记录

**通电直导线磁场**

| 观察位置 | 铁屑排列 | 小磁针指向 | 现象分析 |
| -------- | -------- | ---------- | -------- |
| 导线周围 | 同心圆 | N 极沿圆切线方向 | 磁场为环形 |
| 靠近导线 | 铁屑密集 | 偏转明显 | 磁场强 |
| 远离导线 | 铁屑稀疏 | 偏转不明显 | 磁场弱 |
| 改变电流方向 | 同心圆（方向相反） | N 极反向 | 磁场方向反向 |

**通电螺线管磁场**

| 观察位置 | 铁屑排列 | 小磁针指向 | 现象分析 |
| -------- | -------- | ---------- | -------- |
| 螺线管外部 | 类似条形磁铁 | N 极指向 S 极方向 | 外部磁场类似条形磁铁 |
| 螺线管两端 | 铁屑密集 | 偏转明显 | 两端磁场强 |
| 螺线管内部 | 铁屑平行排列 | N 极沿轴向 | 内部为匀强磁场 |
| 改变电流方向 | 类似条形磁铁（极性相反） | N 极反向 | 极性反向 |

### 六、实验结果与结论

1. 通电直导线周围的磁感线是以导线为圆心的同心圆，越靠近导线磁场越强。
2. 通电直导线的磁场方向由安培定则确定：右手握住导线，拇指指向电流方向，四指弯曲方向即为磁场方向。
3. 通电螺线管的外部磁场与条形磁铁相似，两端为 N、S 极；内部磁场近似匀强磁场，方向沿轴向。
4. 通电螺线管的极性由安培定则确定：右手握住螺线管，四指弯曲指向电流方向，拇指指向 N 极。
5. 改变电流方向，磁场方向也改变，但磁场分布的形状不变。

### 七、误差分析

1. **铁屑分布不均**：铁屑撒布不均匀会导致图案紊乱。改进措施：用筛子均匀撒布。
2. **铁屑磁化不足**：铁屑在弱磁场中磁化不明显。改进措施：增大电流，增强磁场。
3. **纸板振动过大**：敲击纸板过猛会使铁屑弹起，影响排列。改进措施：轻轻敲击。
4. **铁屑质量过大**：铁屑过重时磁场力不足以使其重新排列。改进措施：使用细小的铁粉。
5. **外部磁场干扰**：地磁场和周围电器的磁场会干扰实验。改进措施：远离大型电器，注意地磁场影响。
6. **螺线管磁场不严格匀强**：实际螺线管有限长，内部磁场并非严格匀强。
7. **小磁针磁性减弱**：小磁针磁性减弱会导致偏转不明显。

### 八、注意事项

1. 实验应在无风环境下进行，避免空气流动干扰。
2. 电流较大时通电时间要短，避免导线发热或电源过载。
3. 铁屑要细小、干燥，撒布均匀。
4. 敲击纸板要轻，避免铁屑弹起。
5. 小磁针应能自由转动，附近不应有强磁性物体。
6. 实验完毕后及时断电，整理器材。
7. 铁屑可重复使用，应用磁铁收集。
8. 注意电源极性，电流方向要记录准确。

## 实验 3：探究影响通电导线受力的因素（安培力）

### 一、实验目的

1. 通过实验探究通电导线在磁场中受力（安培力）的大小与电流、导线长度、磁场强弱的关系。
2. 理解安培力的公式 F = BIL 及其方向判定（左手定则）。
3. 培养科学探究能力和控制变量法的应用能力。

### 二、实验器材

- 蹄形磁铁一个或多个（提供匀强磁场区域）
- 直导线一根（铜质，长 10-20 cm，可悬挂）
- 铁架台一个
- 细导线两根（用于悬挂直导线并通电）
- 直流电源一个（4-6 V）
- 电流表一个（量程 0-0.6 A 或 0-3 A）
- 滑动变阻器一个
- 开关一个
- 刻度尺一个
- 螺旋测微器（测量导线直径）

### 三、实验原理

通电导线在磁场中会受到力的作用，这个力称为安培力。安培力的大小与下列因素有关：

$$F = BIL\sin\theta$$

其中 B 为磁感应强度，I 为电流，L 为导线在磁场中的长度，θ 为电流方向与磁场方向的夹角。当电流方向与磁场方向垂直时（θ = 90°）：

$$F = BIL$$

安培力的方向由左手定则判定：伸开左手，让磁感线穿过掌心，四指指向电流方向，拇指所指方向即为安培力方向。

实验采用控制变量法：
- 保持磁场（B）和导线长度（L）不变，改变电流 I，观察导线受力情况。
- 保持磁场（B）和电流（I）不变，改变导线在磁场中的长度 L，观察导线受力情况。
- 保持电流（I）和导线长度（L）不变，改变磁场强弱（增减磁铁数量），观察导线受力情况。

导线受力大小可以通过导线偏转的角度或位移来反映：偏转越大，受力越大。

### 四、实验步骤

1. 将蹄形磁铁固定在铁架台上，磁场区域水平。
2. 用细导线将直导线水平悬挂在蹄形磁铁的两极之间，使导线与磁场方向垂直。
3. 将直导线通过电流表、滑动变阻器、开关连接到电源。
4. 检查电路无误后，闭合开关，观察导线的偏转情况。
5. **探究 F 与电流 I 的关系**：
   - 保持磁铁数量和导线在磁场中长度不变。
   - 调节滑动变阻器，改变电流大小（如 0.1 A、0.2 A、0.3 A、0.4 A）。
   - 记录每次导线偏转的角度或位移。
6. **探究 F 与导线长度 L 的关系**：
   - 保持磁铁数量和电流不变。
   - 改变导线在磁场中的长度（如使用不同长度的导线，或调整导线在磁场中的位置）。
   - 记录每次导线偏转情况。
7. **探究 F 与磁场强弱 B 的关系**：
   - 保持电流和导线长度不变。
   - 增减磁铁数量（如 1 块、2 块、3 块蹄形磁铁串联），改变磁场强弱。
   - 记录每次导线偏转情况。
8. 改变电流方向或磁场方向，观察导线偏转方向的变化。
9. 断开开关，整理器材。

- 同时改变电流方向和磁场方向：导线偏转方向不变。

### 六、实验结果与结论

1. 当磁场和导线长度一定时，安培力 F 与电流 I 成正比：F ∝ I。
2. 当磁场和电流一定时，安培力 F 与导线在磁场中的长度 L 成正比：F ∝ L。
3. 当电流和导线长度一定时，安培力 F 与磁场强弱 B 成正比：F ∝ B。
4. 综合：F = BIL（当电流方向与磁场方向垂直时）。
5. 安培力的方向由左手定则判定，与电流方向和磁场方向都有关。
6. 同时改变电流方向和磁场方向，安培力方向不变。

### 七、误差分析

1. **磁场不均匀**：蹄形磁铁的磁场并非严格匀强，导线在不同位置受力不同。
2. **导线质量影响**：导线本身有质量，重力会影响偏转角度，偏转角度与安培力的关系并非严格线性。
3. **空气阻力**：导线偏转时受空气阻力，使偏转角度偏小。
4. **悬挂点的摩擦**：悬挂导线的细导线在悬挂点有摩擦，影响偏转。
5. **电流测量误差**：电流表读数存在误差。
6. **导线长度测量误差**：导线在磁场中的有效长度难以精确测定。
7. **磁铁数量与磁场强度并非线性关系**：多块磁铁叠加时磁场并非简单地按倍数增加。
8. **磁场边缘效应**：磁铁边缘磁场减弱，影响测量。

### 八、注意事项

1. 通电时间要短，避免导线发热或电源过载。
2. 电流不要过大，避免损坏电路元件。
3. 导线应与磁场方向垂直，以获得最大安培力。
4. 悬挂导线的细导线要轻而软，减小对导线运动的影响。
5. 实验应在无风环境下进行，避免空气流动干扰。
6. 磁铁要远离铁磁性物体，避免磁场被影响。
7. 改变电流方向时要先断开开关，再交换接线。
8. 多次测量取平均，减小偶然误差。

## 实验 4：探究感应电流产生的条件

### 一、实验目的

1. 通过实验探究产生感应电流的条件，理解电磁感应现象。
2. 经历从实验现象到物理规律的归纳过程，培养科学探究能力。
3. 知道"穿过闭合电路的磁通量发生变化"是产生感应电流的条件。
4. 体会法拉第发现电磁感应现象的科学思想和坚持精神。

### 二、实验器材

- 蹄形磁铁一个
- 条形磁铁一个
- 灵敏电流计一个（量程 ± 300 μA）
- 闭合线圈一个（多匝，带铁芯）
- 直导线一根
- 直流电源一个（4-6 V）
- 滑动变阻器一个
- 开关一个
- 铁架台一个
- 导线若干

### 三、实验原理

电磁感应现象：当穿过闭合电路的磁通量发生变化时，电路中产生感应电流。

磁通量 Φ = BS（当磁场与平面垂直时），单位为韦伯（Wb）。磁通量变化的原因有：
1. 磁感应强度 B 变化（如磁铁靠近或远离线圈）。
2. 闭合电路的面积 S 变化（如线圈在磁场中收缩或扩张）。
3. 磁场方向与电路平面夹角变化（如线圈在磁场中转动）。
4. 部分导体切割磁感线（如导体棒在磁场中运动）。

实验通过几种典型情况，归纳得出感应电流产生的条件：**只要穿过闭合电路的磁通量发生变化，闭合电路中就会产生感应电流**。

法拉第在 1831 年发现电磁感应现象，这是 19 世纪最伟大的物理学发现之一，为人类进入电气化时代奠定了基础。

### 四、实验步骤

1. **实验一：磁铁与线圈相对运动**：
   - 将闭合线圈放在桌面上，连接灵敏电流计组成闭合回路。
   - 将条形磁铁的 N 极迅速插入线圈，观察电流计指针偏转。
   - 将条形磁铁停在线圈内不动，观察电流计指针。
   - 将条形磁铁从线圈中迅速拔出，观察电流计指针偏转方向。
   - 改用 S 极插入和拔出，观察指针偏转方向。
   - 改变磁铁插入或拔出的速度，观察指针偏转幅度。

2. **实验二：导体切割磁感线**：
   - 将直导线通过电流计组成闭合回路。
   - 将直导线放在蹄形磁铁的两极之间。
   - 让直导线水平切割磁感线运动（垂直于磁场方向），观察电流计指针偏转。
   - 让直导线沿磁场方向运动（不切割磁感线），观察电流计指针是否偏转。
   - 让直导线斜向运动，观察指针偏转情况。
   - 改变运动方向，观察指针偏转方向。

3. **实验三：原副线圈电磁感应**：
   - 将原线圈 A（带铁芯）插入副线圈 B 中，原线圈通过开关、滑动变阻器连接到电源。
   - 副线圈 B 连接灵敏电流计组成闭合回路。
   - 闭合开关瞬间，观察电流计指针偏转。
   - 开关保持闭合，电流稳定后，观察电流计指针。
   - 断开开关瞬间，观察电流计指针偏转方向。
   - 开关闭合时，迅速移动滑动变阻器滑片（改变原线圈电流），观察电流计指针偏转。

4. 整理器材，分析实验现象。

### 五、实验现象与数据记录

**实验一：磁铁与线圈相对运动**

| 操作 | 电流计指针 | 现象分析 |
| ---- | ---------- | -------- |
| N 极迅速插入线圈 | 偏转（如向右） | 磁通量增大，产生感应电流 |
| 磁铁停在线圈内不动 | 不偏转 | 磁通量不变，无感应电流 |
| N 极迅速拔出线圈 | 偏转（向左） | 磁通量减小，产生反向感应电流 |
| S 极插入线圈 | 偏转（向左） | 磁通量增大但方向相反，电流方向相反 |
| 快速插入 vs 慢速插入 | 快速偏转大 | 磁通量变化越快，感应电流越大 |

**实验二：导体切割磁感线**

| 操作 | 电流计指针 | 现象分析 |
| ---- | ---------- | -------- |
| 导线垂直切割磁感线 | 偏转 | 切割磁感线，磁通量变化 |
| 导线沿磁场方向运动 | 不偏转 | 不切割磁感线，磁通量不变 |
| 导线斜向运动 | 偏转较小 | 部分切割磁感线 |
| 改变运动方向 | 偏转反向 | 磁通量变化方向相反 |

**实验三：原副线圈电磁感应**

| 操作 | 电流计指针 | 现象分析 |
| ---- | ---------- | -------- |
| 开关闭合瞬间 | 偏转（如向右） | 原线圈电流增大，副线圈磁通量增大 |
| 开关保持闭合，电流稳定 | 不偏转 | 磁通量不变 |
| 开关断开瞬间 | 偏转（向左） | 原线圈电流减小，副线圈磁通量减小 |
| 移动滑动变阻器 | 偏转 | 原线圈电流变化，副线圈磁通量变化 |

### 六、实验结果与结论

1. 当磁铁与线圈相对运动（磁通量变化）时，闭合电路中产生感应电流。
2. 当导体切割磁感线（磁通量变化）时，闭合电路中产生感应电流。
3. 当原线圈电流变化导致副线圈磁通量变化时，副线圈中产生感应电流。
4. 当磁通量不变时，无感应电流。
5. 磁通量变化越快，感应电流越大。
6. **实验结论**：只要穿过闭合电路的磁通量发生变化，闭合电路中就会产生感应电流。这是产生感应电流的条件。

### 七、误差分析

1. **灵敏电流计的灵敏度**：电流计灵敏度不足时，小电流检测不到。改进措施：使用高灵敏度的电流计或示波器。
2. **线圈匝数不足**：匝数少时感应电动势小，电流小。改进措施：使用多匝线圈。
3. **磁铁磁性减弱**：磁铁使用久了磁性减弱，磁场强度不足。改进措施：使用强磁铁。
4. **运动速度不均匀**：手动操作时速度难以保持均匀，影响电流大小的比较。
5. **接触电阻**：电路连接处接触电阻使感应电流减弱。
6. **环境磁场干扰**：地磁场和周围电器的磁场会干扰实验。
7. **原线圈电流不稳定**：电源电压波动导致原线圈电流变化，影响实验。
8. **铁芯剩磁**：铁芯可能有剩磁，影响磁通量变化的对称性。

### 八、注意事项

1. 灵敏电流计的量程要小（如 ± 300 μA），以便检测微弱电流。
2. 闭合线圈的匝数要多，以增大感应电动势。
3. 磁铁运动要迅速，但要避免碰撞线圈。
4. 实验前要检查电路是否闭合，接触是否良好。
5. 电流计的指针在零点要校准。
6. 操作时要观察指针偏转方向，判断感应电流方向。
7. 实验完毕后及时断电，整理器材。
8. 磁铁要远离铁磁性物体，避免磁场被影响。
9. 原副线圈实验中，开关切换要迅速，避免电流计指针因长时间偏转而损坏。

## 实验 5：演示电磁波的发射与接收

### 一、实验目的

1. 通过实验演示电磁波的发射和接收，认识电磁波的存在。
2. 理解电磁波的产生原理（振荡电路辐射电磁波）。
3. 了解电磁波在真空中的传播特性及其应用。

### 二、实验器材

- 感应圈一个（用于产生高频振荡，发射电磁波）
- 莱顿瓶一个或平行板电容器（与感应圈组成 LC 振荡电路）
- 发射天线一根（金属棒或导线）
- 接收天线一根（金属棒，带可调节间隙的放电小球）
- 氖泡或小灯泡一个（接在接收天线上，指示接收信号）
- 直流电源一个（6-12 V）
- 导线若干
- 绝缘支架

### 三、实验原理

麦克斯韦电磁场理论指出：变化的磁场产生电场，变化的电场产生磁场。当电路中有高频振荡电流时，电场和磁场相互激发，向周围空间传播，形成电磁波。

**发射原理**：感应圈产生高频振荡电流，使发射天线上的电荷快速变化，产生变化的电场，进而产生变化的磁场，电磁波向四周传播。

**接收原理**：当电磁波传播到接收天线时，电磁波中的电场使接收天线上的自由电荷做受迫振动，产生感应电流。当接收天线的固有频率与电磁波频率相同时，发生电谐振，接收效果最好。接收天线上的氖泡或小灯泡发光，指示接收到电磁波信号。

赫兹在 1887 年用类似的实验装置首次验证了电磁波的存在，证实了麦克斯韦的预言。

### 四、实验步骤

1. **组装发射装置**：
   - 将感应圈、莱顿瓶（电容器）、发射天线连接成 LC 振荡电路。
   - 接通感应圈电源，使其产生高频振荡。
   - 观察发射天线间隙是否产生火花放电（表明有高频振荡）。
2. **组装接收装置**：
   - 将接收天线两端接上氖泡或小灯泡。
   - 在接收天线两端设置可调节间隙（放电小球）。
3. **演示电磁波的传播**：
   - 将接收天线放在发射天线附近（不接触）。
   - 观察接收天线上的氖泡是否发光或放电小球间是否产生火花。
   - 改变接收天线与发射天线的距离，观察接收效果的变化。
   - 改变接收天线的方向（与发射天线平行或垂直），观察接收效果。
   - 在发射天线和接收天线之间放置金属板或导体，观察接收效果是否减弱（屏蔽效应）。
4. 演示电磁波屏蔽：
   - 用金属网罩将接收天线罩住，观察接收效果是否减弱或消失。
5. 实验完毕后断开电源，整理器材。

### 五、实验现象与数据记录

| 实验情景 | 接收天线氖泡 | 现象分析 |
| -------- | ------------ | -------- |
| 接收天线靠近发射天线 | 发光 | 接收到电磁波信号 |
| 接收天线远离发射天线 | 变暗或熄灭 | 电磁波强度随距离减弱 |
| 接收天线与发射天线平行 | 发光明显 | 极化方向匹配，接收效果好 |
| 接收天线与发射天线垂直 | 不发光或极弱 | 极化方向不匹配，接收效果差 |
| 中间放金属板 | 不发光 | 金属板屏蔽电磁波 |
| 接收天线在金属网罩内 | 不发光或极弱 | 金属网罩屏蔽电磁波 |

### 六、实验结果与结论

1. 发射天线辐射电磁波，接收天线能接收到电磁波信号。
2. 电磁波强度随距离增大而减弱。
3. 电磁波有极化特性，接收天线方向影响接收效果。
4. 金属导体（板、网罩）能屏蔽电磁波。
5. 实验证实了电磁波的存在，验证了麦克斯韦的电磁场理论。

### 七、误差分析

1. **发射功率不足**：感应圈或振荡电路功率不足，电磁波信号弱。改进措施：增大电源电压，使用更强的振荡电路。
2. **接收天线灵敏度低**：氖泡起辉电压较高，弱信号检测不到。改进措施：使用更灵敏的指示器（如示波器、收音机）。
3. **环境电磁干扰**：周围电器产生的电磁波会干扰实验。改进措施：在远离电器的环境中实验。
4. **接地不良**：发射和接收装置接地不良会影响信号传播。
5. **天线方向不准**：天线方向调整不精确影响接收效果。
6. **金属屏蔽不严密**：金属网罩孔径过大或缝隙会导致屏蔽不完全。

### 八、注意事项

1. 感应圈产生高压，操作时注意安全，不要接触裸露部分。
2. 实验时人体应远离发射天线，避免电击。
3. 接收天线与发射天线开始时应远离，避免直接耦合。
4. 实验环境应远离大型电器，避免干扰。
5. 长时间通电后感应圈可能发热，应间歇使用。
6. 实验完毕后及时断电，整理器材。
7. 氖泡和小灯泡有极性，注意连接方向。
8. 金属屏蔽实验时，要确保屏蔽体接地良好。
