## 实验 1：测定玻璃的折射率

### 一、实验目的

1. 学会用「插针法」测定玻璃的折射率。
2. 掌握入射光线、折射光线的确定方法。
3. 学会用计算法、图像法、单位圆法处理实验数据。

### 二、实验器材

- 长方形玻璃砖（宽度大于 5 cm，两面抛光）
- 白纸（A4 大小，若干张）
- 平木板
- 大头针（4 枚）
- 图钉（4 枚）
- 量角器
- 刻度尺、三角板
- 铅笔

### 三、实验原理

光由空气射入玻璃时发生折射。根据折射定律，玻璃的折射率

$$n=\dfrac{\sin\theta_1}{\sin\theta_2}$$

其中 $\theta_1$ 为入射角（入射光线与法线的夹角），$\theta_2$ 为折射角（折射光线与法线的夹角）。

用「插针法」确定光路：在白纸上插大头针标出入射光线的方向，透过玻璃砖观察大头针的像，再在另一侧插大头针确定出射光线方向。移去玻璃砖后连接相应大头针位置，得到入射光线和折射光线，量出入射角和折射角，即可计算折射率。

### 四、实验步骤

1. **铺纸：** 将白纸用图钉钉在平板上。
2. **画界面：** 用刻度尺画一条直线 $aa'$ 作为界面（平行于玻璃砖的一个长边），过 $aa'$ 上一点 $O$ 作垂直于 $aa'$ 的直线 $NN'$ 作为法线。过 $O$ 画一条入射光线 $AO$，使入射角 $\theta_1$ 适当大些（约 30°~60°）。
3. **放置玻璃砖：** 将玻璃砖放在白纸上，使其长边与 $aa'$ 对齐。沿玻璃砖另一长边画直线 $bb'$。
4. **插针 P1、P2：** 在直线 $AO$ 上竖直插两枚大头针 $P_1$、$P_2$（间距适当大些，约 5~10 cm）。
5. **插针 P3：** 在玻璃砖 $bb'$ 一侧观察，透过玻璃砖看 $P_1$、$P_2$ 的像。同时移动一枚大头针 $P_3$ 的位置，直到 $P_3$ 能同时挡住 $P_1$、$P_2$ 的像，将 $P_3$ 插好。
6. **插针 P4：** 在 $bb'$ 一侧再插一枚大头针 $P_4$，使 $P_4$ 挡住 $P_3$ 本身同时也能挡住 $P_1$、$P_2$ 的像。
7. **确定折射光线：** 移去玻璃砖和大头针，过 $P_3$、$P_4$ 连一条直线 $O'B$，交 $bb'$ 于 $O'$。连接 $OO'$，$OO'$ 即为折射光线。折射角 $\theta_2=\angle O'ON'$。
8. **测量角度：** 用量角器量出入射角 $\theta_1$ 和折射角 $\theta_2$。
9. **重复实验：** 改变入射角 $\theta_1$（约 30°、45°、60°），重复上述步骤 3~4 次。

### 五、实验现象与数据记录

| 实验次数 | 入射角 $\theta_1$ | 折射角 $\theta_2$ | $\sin\theta_1$ | $\sin\theta_2$ | $n=\sin\theta_1/\sin\theta_2$ |
|---|---|---|---|---|---|
| 1 | 30° | | | | |
| 2 | 45° | | | | |
| 3 | 60° | | | | |
| 4 | 75° | | | | |

折射率的平均值 $\bar n=$________

### 六、实验结果与结论

**方法一（计算法）：** 算出不同入射角时的 $\dfrac{\sin\theta_1}{\sin\theta_2}$，取平均值即为玻璃的折射率。

**方法二（图像法）：** 求出多组对应的 $\sin\theta_1$ 与 $\sin\theta_2$，作 $\sin\theta_1\text{-}\sin\theta_2$ 图像，应为过原点的直线，斜率即为折射率 $n$。

**方法三（单位圆法）：** 以入射点 $O$ 为圆心，以一定长度 $R$ 为半径画圆，交入射光线 $AO$ 于 $E$，交折射光线 $OO'$ 于 $E'$。过 $E$ 作 $NN'$ 的垂线 $EH$，过 $E'$ 作 $NN'$ 的垂线 $E'H'$。因 $OE=OE'=R$，所以

$$n=\dfrac{\sin\theta_1}{\sin\theta_2}=\dfrac{EH/OE}{E'H'/OE'}=\dfrac{EH}{E'H'}$$

只需用刻度尺测出 $EH$、$E'H'$ 的长度即可求出 $n$。

**实验结论：** 测得玻璃的折射率约为 1.5（具体值因玻璃种类而异），多次测量结果基本一致，验证了折射定律。

### 七、误差分析

1. **系统误差：**
   - 玻璃砖两面不严格平行，导致出射光线与入射光线不平行。
   - 量角器精度有限，角度测量有误差。
   - 玻璃砖位置在实验中改变。
2. **偶然误差：**
   - 大头针插得不竖直，导致视线方向有偏差。
   - 入射光线、出射光线确定不准（大头针位置读数误差）。
   - 入射角过小时，折射角也很小，相对误差大。
   - 作图时连线的偏差。

### 八、注意事项

1. 玻璃砖在白纸上的位置不可移动，实验中不要触碰。
2. 不能用手触摸玻璃砖光洁的光学面，更不能把玻璃砖当尺子画线。
3. 大头针应竖直插在白纸上，且 $P_1$ 与 $P_2$、$P_3$ 与 $P_4$ 间距适当大些（5~10 cm）。
4. 入射角不宜过小或过大，一般控制在 30°~60° 之间。过小则相对误差大；过大则反射光增强，折射光减弱，观察困难。
5. 玻璃砖应选用宽度较大的（>5 cm），宽度太小则折射光线短，测量误差大。
6. 用铅笔连线时用力适中，避免纸面凹陷。

## 实验 2：观察全反射现象

### 一、实验目的

1. 观察光从光密介质射向光疏介质时的全反射现象。
2. 理解临界角的概念和全反射条件。
3. 加深对折射率与全反射关系的认识。

### 二、实验器材

- 半圆形玻璃砖（或矩形玻璃砖）
- 激光笔（红色或绿色）
- 量角器
- 白纸、铅笔
- 旋转平台（可选）

### 三、实验原理

光从光密介质（如玻璃）射向光疏介质（如空气）时，折射角大于入射角。当入射角增大到某一值（临界角 $C$）时，折射角达到 90°，折射光线沿界面传播；入射角继续增大，光线全部反射回玻璃中，发生全反射。临界角 $C$ 满足

$$\sin C=\dfrac{1}{n}$$

其中 $n$ 为光密介质的折射率。

### 四、实验步骤

1. 将半圆形玻璃砖放在白纸上，使其平的一面朝下。
2. 用激光笔从弧面射入，调整入射角度，使光线在玻璃砖平面的下表面（玻璃-空气界面）发生折射和反射。
3. 逐渐增大入射角，观察折射光线和反射光线的强度变化。
4. 当入射角达到临界角时，折射光线消失，光线全部反射回玻璃中，发生全反射。
5. 测量临界角 $C$，由 $\sin C=\dfrac{1}{n}$ 计算玻璃的折射率。
6. 改变激光颜色（红、绿），观察临界角是否相同。

### 五、实验现象与数据记录

- 入射角较小时，同时出现折射光线（进入空气）和反射光线（回到玻璃）。
- 入射角增大时，折射光线变弱，反射光线变强；折射角始终大于入射角。
- 入射角达到临界角时，折射光线沿界面传播（折射角为 90°）。
- 入射角超过临界角时，光线全部反射回玻璃，发生全反射。
- 测得玻璃的临界角约 41°~42°（对应折射率约 1.5）。

### 六、实验结果与结论

光从光密介质射向光疏介质，且入射角大于临界角时，发生全反射现象。临界角满足 $\sin C=\dfrac{1}{n}$，由此可计算介质的折射率。

### 七、误差分析

1. 激光不严格沿半径方向入射，导致入射角读数偏差。
2. 玻璃砖平面与白纸不完全接触，影响角度测量。
3. 临界状态（折射角 90°）判断主观性强。
4. 不同颜色光的折射率略有差异（色散）。

### 八、注意事项

1. 激光笔勿直射眼睛。
2. 半圆形玻璃砖的弧面圆心应与折射点重合，使光线方向不因弧面折射而改变。
3. 逐渐增大入射角，仔细观察临界状态。
4. 环境较暗时观察更清晰。

## 实验 3：弯曲的有机玻璃棒能导光

### 一、实验目的

1. 观察光沿弯曲有机玻璃棒传播的现象。
2. 理解光导纤维的原理——全反射。
3. 了解光导纤维的应用。

### 二、实验器材

- 弯曲的实心有机玻璃棒（直径约 1 cm，弯曲半径约 5 cm）
- 激光笔
- 暗室

### 三、实验原理

光从有机玻璃（光密介质，$n\approx1.49$）射向空气（光疏介质）时，若入射角大于临界角（约 42°），发生全反射。弯曲的有机玻璃棒中，光线在棒壁多次发生全反射，沿弯曲路径传播，从棒另一端射出。这就是光导纤维导光的基本原理。

### 四、实验步骤

1. 在暗室中，将激光笔对准有机玻璃棒的一端面。
2. 观察光从棒的另一端射出。
3. 观察棒体侧面，几乎看不到光泄漏（仅端面有光射出）。
4. 改变棒的弯曲程度，观察是否仍能导光。
5. 可用白纸接住棒两端的光斑。

### 五、实验现象与数据记录

- 激光从棒一端射入，从另一端射出，光强损失很少。
- 棒体弯曲处看不到光泄漏。
- 即使棒弯曲成圆弧，光仍能沿棒传播。

### 六、实验结果与结论

光在弯曲的有机玻璃棒中通过多次全反射传播，证明全反射现象可用于导光，这就是光导纤维的工作原理。

### 七、误差分析

1. 棒端面不光滑，入射或出射有散射损失。
2. 棒内杂质吸收部分光。
3. 弯曲半径过小时，部分光线入射角小于临界角，光泄漏。

### 八、注意事项

1. 激光勿直射眼睛。
2. 有机玻璃棒端面应抛光。
3. 演示时配合讲解光导纤维的构造（纤芯+包层）和应用（通信、医用内窥镜）。

## 实验 4：水流导光

### 一、实验目的

1. 观察光沿水流传播的现象。
2. 理解水流导光的原理——全反射。
3. 加深对光导纤维原理的认识。

### 二、实验器材

- 透明塑料瓶（带侧壁小孔）
- 水
- 激光笔
- 接水容器
- 暗室

### 三、实验原理

激光从瓶内射向小孔处的水流，水流落下形成弧形水柱。光在水-空气界面发生全反射（水的临界角约 48.6°，$n=1.33$），光沿水流弯曲传播，跟随水柱一起落下。这就是早期光导实验的演示。

### 四、实验步骤

1. 在塑料瓶侧壁钻一小孔（直径 2~3 mm）。
2. 装水至小孔上方，让水从小孔流出形成水柱。
3. 在暗室中，用激光笔从瓶另一侧射入，对准小孔位置。
4. 观察光是否跟随水柱弯曲传播。
5. 用手接住水流末端，可见光斑落在手上。
6. 调整激光入射角度，观察光的传播效果。

### 五、实验现象与数据记录

- 水流呈弧形落下，激光跟随水流弯曲传播。
- 水流末端可见明亮光斑。
- 水流中间可见光柱（弱光晕）。
- 调整入射角后导光效果变化。

### 六、实验结果与结论

光通过全反射沿水流弯曲传播，验证了全反射导光原理。这与光导纤维原理一致，水流相当于光导纤维的纤芯，空气相当于包层。

### 七、误差分析

1. 水流不稳定，影响光路连续性。
2. 水中杂质散射光，导致部分光泄漏。
3. 入射角不当，部分光不发生全反射。

### 八、注意事项

1. 激光勿直射眼睛。
2. 实验在暗室进行，效果更明显。
3. 水流应连续稳定。
4. 接水容器放在水流下方。

## 实验 5：光的双缝干涉实验

### 一、实验目的

1. 观察杨氏双缝干涉现象，认识光的波动性。
2. 理解双缝干涉条纹的形成原理。
3. 测量干涉条纹间距，了解波长对条纹间距的影响。

### 二、实验器材

- 激光笔（红色或绿色）
- 双缝片（缝间距 $d$ 已知，如 0.1 mm 或 0.2 mm）
- 屏幕（白纸或白墙）
- 米尺

### 三、实验原理

激光通过双缝后形成两束相干光，在屏幕上叠加形成明暗相间的干涉条纹。相邻明条纹（或暗条纹）中心间距

$$\Delta x=\dfrac{l}{d}\lambda$$

其中 $l$ 为双缝到屏的距离，$d$ 为双缝间距，$\lambda$ 为光波长。

明纹条件：双缝到屏上某点 $P$ 的波程差 $\Delta r=k\lambda$（$k=0,\pm1,\pm2,\dots$）
暗纹条件：$\Delta r=(k+\frac{1}{2})\lambda$

### 四、实验步骤

1. 将激光笔对准双缝片，使激光通过双缝。
2. 在双缝后方 1~2 m 处放屏幕（白纸或白墙）。
3. 观察屏幕上的干涉条纹（明暗相间的条纹）。
4. 用米尺测量条纹间距 $\Delta x$（取多个条纹总宽度除以条纹数）。
5. 测量双缝到屏的距离 $l$。
6. 改变 $l$，观察条纹间距的变化。
7. 改变双缝间距 $d$，观察条纹间距的变化。
8. 改变激光颜色（红、绿），观察条纹间距的变化。

### 五、实验现象与数据记录

| 激光颜色 | 波长 $\lambda$/nm | 双缝间距 $d$/mm | 双缝到屏距离 $l$/m | 条纹间距 $\Delta x$/mm |
|---|---|---|---|---|
| 红 | 约 650 | 0.20 | 1.0 | |
| 绿 | 约 532 | 0.20 | 1.0 | |
| 红 | 约 650 | 0.10 | 1.0 | |

### 六、实验结果与结论

- 屏幕上出现明暗相间的干涉条纹，中央为明纹。
- 条纹间距与波长 $\lambda$、双缝到屏的距离 $l$ 成正比，与双缝间距 $d$ 成反比。
- 实验数据符合 $\Delta x=\dfrac{l}{d}\lambda$，验证了光的波动性。

### 七、误差分析

1. 双缝间距 $d$ 制造精度限制。
2. 条纹间距测量误差（条纹边缘不清晰）。
3. 距离 $l$ 测量误差。
4. 激光波长不严格单一（多模激光）。
5. 实验环境振动使条纹抖动。

### 八、注意事项

1. 激光勿直射眼睛。
2. 双缝片应与激光方向垂直。
3. 双缝到屏距离适当大（1~2 m），条纹清晰。
4. 实验环境应较暗，便于观察条纹。

## 实验 6：自制器材观察双缝干涉现象

### 一、实验目的

1. 用日常材料自制双缝，观察光的干涉现象。
2. 体会物理实验可以用简单器材完成。
3. 加深对双缝干涉原理的理解。

### 二、实验器材

- 黑色卡纸或曝光胶片
- 缝衣针（细的）
- 双面刀片（两片）
- 蜡烛
- 激光笔或日光灯
- 放大镜

### 三、实验原理

两片刀片并排可形成双缝，针在黑色卡纸上扎两个相距很近的小孔也可形成双孔。光通过双缝或双孔时发生干涉，在屏幕上形成明暗相间的条纹。早期托马斯·杨就是用类似简单装置首次观察到光的干涉现象。

### 四、实验步骤

1. **刀片法：** 将两片刀片并排放置，间距约 0.1~0.2 mm，固定在硬纸板框上制成双缝。
2. **打孔法：** 用针在黑色卡纸上扎两个相距 0.1~0.2 mm 的小孔。
3. 将激光笔对准自制双缝，后方放屏幕。
4. 观察屏幕上的干涉条纹。
5. 用日光灯作为光源，配合滤光片观察。

### 五、实验现象与数据记录

- 激光通过自制双缝后，屏幕上出现明暗相间的条纹。
- 双缝间距越小，条纹间距越大。
- 自制双孔可观察到类似但圆形的干涉条纹。

### 六、实验结果与结论

用简单器材也能观察到光的干涉现象，证明光的波动性。这重现了杨氏双缝干涉实验。

### 七、误差分析

1. 双缝间距难以精确控制。
2. 刀片边缘可能不直，缝宽不均匀。
3. 缝口可能不光滑，产生衍射干扰。

### 八、注意事项

1. 使用刀片时小心割伤。
2. 双缝间距越小越好观察，但太小则光强过弱。
3. 实验在暗处观察效果更好。

## 实验 7：用白光做双缝干涉实验

### 一、实验目的

1. 观察白光的双缝干涉条纹。
2. 理解不同色光波长不同导致条纹间距不同。
3. 认识白光是由多种色光组成的。

### 二、实验器材

- 双缝干涉仪（光源、单缝、双缝、屏等）
- 白光光源（如卤素灯、日光灯）
- 红色、绿色滤光片

### 三、实验原理

白光由不同波长的色光组成。不同颜色的光通过双缝后形成不同间距的干涉条纹，中央明纹为白色，两侧条纹因不同色光条纹间距不同而呈现彩色（中央为白色，两侧由紫到红依次排列）。中央明纹是白色的，因为所有色光在中央均为明纹。两侧条纹中，红光条纹间距大、紫光条纹间距小，因此彩色条纹中外侧偏红、内侧偏紫。

### 四、实验步骤

1. 调整双缝干涉仪，使白光通过单缝照亮双缝。
2. 观察屏上的干涉条纹。
3. 注意中央明纹的颜色和两侧条纹的颜色排列。
4. 在光源前加红色滤光片，观察条纹变化。
5. 改用绿色滤光片，观察条纹变化。

### 五、实验现象与数据记录

- 白光干涉条纹：中央为白色明纹，两侧为彩色条纹。
- 彩色条纹中，外侧偏红（红光波长长，条纹间距大），内侧偏紫（紫光波长短，条纹间距小）。
- 加红色滤光片后，条纹变为红黑相间的等间距条纹。
- 加绿色滤光片后，条纹变为绿黑相间，间距比红光小。

### 六、实验结果与结论

白光双缝干涉条纹中央为白色，两侧为彩色，说明白光由不同波长的色光组成，各色光的条纹间距按波长排列。这证明了光的色散现象和波动性。

### 七、误差分析

1. 白光不是理想的连续光谱。
2. 滤光片的通带宽度使条纹边缘不清晰。
3. 单缝不严格单色，使条纹对比度降低。

### 八、注意事项

1. 光源应足够亮。
2. 单缝与双缝应严格平行。
3. 实验环境应较暗。
4. 观察彩色条纹时注意色序排列。

## 实验 8：用光传感器做双缝干涉的实验

### 一、实验目的

1. 用光传感器和计算机定量测量双缝干涉条纹的光强分布。
2. 验证条纹间距公式 $\Delta x=\dfrac{l}{d}\lambda$。
3. 体验现代传感器技术在物理实验中的应用。

### 二、实验器材

- 双缝片
- 激光笔
- 光传感器（CCD 线阵或光敏元件阵列）
- 数据采集器
- 计算机（含数据采集软件）
- 光具座

### 三、实验原理

光传感器可同时测量屏上不同位置的光强，得到光强分布曲线。理论上双缝干涉条纹的光强分布为

$$I=I_0\cos^2\left(\dfrac{\pi d}{\lambda l}x\right)$$

其中 $x$ 为屏上位置坐标。条纹间距为 $\Delta x=\dfrac{l}{d}\lambda$。

### 四、实验步骤

1. 调节光路，使激光通过双缝后形成清晰干涉条纹。
2. 将光传感器置于双缝后方，正对干涉条纹。
3. 启动数据采集软件，采集光强分布。
4. 软件自动绘制光强—位置曲线。
5. 测量相邻明条纹间距 $\Delta x$。
6. 改变双缝间距、距离 $l$，重复测量。
7. 由公式计算激光波长。

### 五、实验现象与数据记录

- 光强分布曲线呈正弦平方分布（$\cos^2$ 形）。
- 明条纹光强相等，间距均匀。
- 实验值与理论值符合度高。

### 六、实验结果与结论

光传感器测得的双缝干涉条纹光强分布与理论曲线吻合，验证了 $\Delta x=\dfrac{l}{d}\lambda$ 公式。这种方法比目测更精确，可定量研究光的干涉规律。

### 七、误差分析

1. 传感器各光敏单元响应不一致。
2. 激光强度不稳定。
3. 光路未严格对准传感器。
4. 环境光干扰。

### 八、注意事项

1. 光路应严格共轴。
2. 实验在暗室进行。
3. 传感器需校准。
4. 激光强度适中，避免传感器饱和。

## 实验 9：用肥皂膜做薄膜干涉实验

### 一、实验目的

1. 观察肥皂膜的薄膜干涉现象。
2. 理解薄膜干涉的原理（等倾干涉或等厚干涉）。
3. 认识薄膜干涉在生产生活中的应用。

### 二、实验器材

- 肥皂水（用洗洁精或洗衣粉配制）
- 金属丝环（直径约 5 cm）
- 酒精灯（撒钠盐，发出黄光）
- 白光光源
- 暗室

### 三、实验原理

肥皂膜在重力作用下形成上薄下厚的楔形薄膜。光照射到膜上时，从前表面和后表面反射的两束光发生干涉。当膜厚为光波长的 $\frac{1}{4}$ 的奇数倍时，反射光相消；为 $\frac{1}{2}$ 波长的整数倍时，反射光相长。在白光照射下，不同厚度处干涉加强的色光不同，呈现彩色条纹。随着水分蒸发，膜逐渐变薄，条纹向下移动。

### 四、实验步骤

1. 将金属丝环浸入肥皂水，取出后形成肥皂膜。
2. 将肥皂膜竖直放置，让膜在重力作用下形成上薄下厚的形状。
3. 用白光照射肥皂膜，观察反射光的彩色条纹。
4. 用钠光灯（黄光）照射，观察明暗相间的条纹。
5. 静置观察，注意膜变薄过程中条纹的移动。
6. 也可从透射方向观察，条纹与反射互补。

### 五、实验现象与数据记录

- 白光照射：肥皂膜上呈现水平排列的彩色条纹，上疏下密。
- 钠光照射：黄黑相间的水平条纹。
- 静置一段时间后，膜变薄，条纹向下移动，膜上方变黑（厚度小于 $\lambda/4$ 时反射光相消）。
- 膜破裂前可能变薄到几乎透明。

### 六、实验结果与结论

肥皂膜的彩色条纹是薄膜干涉现象，证明光具有波动性。条纹位置与膜厚有关，可用来检测薄膜厚度变化（等厚干涉原理）。

### 七、误差分析

1. 肥皂膜厚度不稳定（受气流、温度影响）。
2. 膜表面不平整使条纹弯曲。
3. 光源波长不单一（白光）。
4. 室内气流干扰条纹稳定。

### 八、注意事项

1. 肥皂水浓度适当，膜才不易破。
2. 实验环境应避免气流。
3. 观察反射光时视角应适当。
4. 演示时可联系「牛顿环」「增透膜」等应用。

## 实验 10：用两块玻璃片观察干涉现象

### 一、实验目的

1. 观察劈尖干涉现象。
2. 理解等厚干涉的原理。
3. 学会用干涉法测量微小厚度。

### 二、实验器材

- 两块载玻片（或长方形玻璃片）
- 钠光灯（或激光）
- 一片薄纸（或头发丝）
- 放大镜或显微镜
- 暗室

### 三、实验原理

两块玻璃片叠放，一端夹入薄纸形成空气劈尖。钠光照射时，从劈尖上下表面反射的光发生干涉。膜厚为 $\frac{1}{2}$ 波长的整数倍处反射光相长（明纹），为 $\frac{1}{4}$ 波长的奇数倍处相消（暗纹）。形成与劈尖棱边平行的明暗相间条纹。

相邻明纹对应的厚度差为 $\Delta d=\dfrac{\lambda}{2}$，相邻条纹间距 $a=\dfrac{\lambda}{2\sin\theta}$，$\theta$ 为劈尖角。

### 四、实验步骤

1. 将两块载玻片洗净擦干，叠放在一起。
2. 在一端夹入薄纸（或头发丝），形成空气劈尖。
3. 用钠光灯照射玻璃片表面，观察反射光的干涉条纹。
4. 用放大镜观察条纹间距。
5. 测量条纹间距和玻璃片长度，由公式计算薄纸厚度。
6. 改变薄纸位置或厚度，观察条纹变化。

### 五、实验现象与数据记录

- 玻璃片表面出现明暗相间的平行条纹，与劈尖棱边平行。
- 条纹等间距。
- 薄纸厚度越大，劈尖角越大，条纹越密。

### 六、实验结果与结论

劈尖干涉条纹间距与劈尖角有关，可用于精密测量微小厚度。这是等厚干涉的典型应用。

### 七、误差分析

1. 玻璃片表面有灰尘或油污，产生杂散条纹。
2. 劈尖角不均匀，条纹间距不均匀。
3. 钠光波长不严格单一（双黄线）。
4. 条纹间距测量误差。

### 八、注意事项

1. 玻璃片应严格清洁，避免手印、灰尘。
2. 薄纸厚度均匀，夹入后玻璃片应紧密接触。
3. 用单色光照射，效果更好。
4. 可配合显微镜精确测量条纹间距。

## 实验 11：观察全息照片

### 一、实验目的

1. 观察全息照片的成像特点。
2. 了解全息照相的原理。
3. 认识全息照相的应用。

### 二、实验器材

- 全息照片（透射式或反射式）
- 激光笔（或白光，根据全息片类型）
- 支架

### 三、实验原理

全息照相利用光的干涉和衍射原理记录物体的振幅和相位信息，能再现物体的三维立体像。全息照片上的干涉条纹包含了物体的全部光场信息，用参考光照射时可重建物体的三维像。普通照片只记录振幅（强度），全息照片还记录了相位信息，因此能看到立体像。

### 四、实验步骤

1. 将全息照片放在支架上。
2. 用激光（或适当光源）以一定角度照射全息片。
3. 从适当角度观察透射光（或反射光）形成的虚像。
4. 改变观察角度，注意像的视差变化（立体感）。
5. 用放大镜观察全息片表面的微观条纹。
6. 将全息片切成小块，观察是否仍能成像。

### 五、实验现象与数据记录

- 从合适角度可看到物体的三维立体像。
- 改变观察角度时，物体前后关系随之变化（视差）。
- 全息片表面看似无序的细密条纹。
- 切成小块后仍能再现完整像（但分辨率降低）。

### 六、实验结果与结论

全息照片能再现物体的三维立体像，证明它记录了光的振幅和相位信息。这是光的干涉和衍射的应用。

### 七、误差分析

1. 全息片质量影响成像清晰度。
2. 光源波长与原记录光源不匹配，成像有色差。
3. 环境振动使像抖动。

### 八、注意事项

1. 用合适波长的光源照射（如 He-Ne 激光 632.8 nm）。
2. 照射角度应与原记录参考光一致。
3. 不要划伤全息片表面。
4. 配合讲解全息照相的应用（防伪、艺术、存储等）。

## 实验 12：实验：用双缝干涉测量光的波长

### 一、实验目的

1. 掌握双缝干涉测量波长的原理。
2. 学会安装实验器材并进行正确的实验操作。
3. 测定单色光的波长。
4. 学习测量头的使用方法和读数。

### 二、实验器材

- 双缝干涉仪（光具座、光源、滤光片、透镜、单缝、双缝、遮光筒、毛玻璃屏、测量头）
- 学生电源
- 导线
- 毫米刻度尺

**器材说明：**
- 双缝间距 $d$ 已知（通常为 0.20 mm、0.25 mm、0.36 mm 等）
- 测量头由分划板、目镜、手轮构成，精度可达 0.01 mm

### 三、实验原理

如图所示，光源发出的光经滤光片后成为单色光，照亮单缝（线光源），单缝再将双缝照亮。来自双缝的两束相干光在双缝后方空间叠加发生干涉，在毛玻璃屏上形成明暗相间的干涉条纹。

相邻明纹（或暗纹）中心间距公式：

$$\Delta x=\dfrac{l}{d}\lambda$$

其中 $l$ 为双缝到屏的距离，$d$ 为双缝间距，$\lambda$ 为单色光波长。变形得

$$\lambda=\dfrac{d\Delta x}{l}$$

只要测出 $l$ 和 $\Delta x$（$d$ 已知），即可算出光波长 $\lambda$。

透镜的作用是使光源发出的光更集中地照亮单缝。

### 四、实验步骤

1. **安装器材：** 将光源、透镜、遮光筒、毛玻璃屏依次安放在光具座上。
2. **接通光源：** 接好电源，打开开关，使灯丝正常发光。
3. **共轴调节：** 调节各器件的高度，使光源灯丝发出的光能沿轴线到达光屏。
4. **观察白光干涉：** 安装单缝和双缝，中心大致位于遮光筒的轴线上，使双缝与单缝平行，二者间距约 5~10 cm。观察白光的双缝干涉条纹。
5. **观察单色光干涉：** 在单缝与光源之间放上滤光片（如绿色或红色滤光片），观察单色光的干涉条纹。
6. **安装测量头：** 在毛玻璃屏外侧安装测量头，调节至可清晰观察到干涉条纹。
7. **测量条纹位置：**
   - 使分划板中心刻线对齐某条明纹的中心，记下手轮读数 $a_1$，将该明纹记为第 1 条。
   - 转动手轮，使分划板中心刻线移至第 $n$ 条明纹的中心（如第 6 条），记下手轮读数 $a_2$。
   - 两条纹间距为 $a=|a_2-a_1|$，相邻明纹间距 $\Delta x=\dfrac{a}{n-1}$。
8. **测量 $l$：** 用毫米刻度尺测量双缝到屏的距离 $l$。
9. **改变条件重复实验：** 分别改变滤光片颜色和双缝间距，重复测量并求出相应波长。

### 五、实验现象与数据记录

**数据记录表格：**

| 实验次数 | 滤光片颜色 | 双缝间距 $d$/mm | 双缝到屏距离 $l$/mm | 第 1 明纹读数 $a_1$/mm | 第 $n$ 明纹读数 $a_2$/mm | $n$ | 条纹间距 $\Delta x$/mm | 波长 $\lambda$/nm |
|---|---|---|---|---|---|---|---|---|
| 1 | 红 | 0.20 | | | | 6 | | |
| 2 | 绿 | 0.20 | | | | 6 | | |
| 3 | 红 | 0.36 | | | | 6 | | |

**计算示例：**
$$\Delta x=\dfrac{|a_2-a_1|}{n-1},\quad \lambda=\dfrac{d\Delta x}{l}$$

**典型参考值：**
- 红光波长约 620~760 nm（依滤光片而定）
- 绿光波长约 500~560 nm

### 六、实验结果与结论

实验测得的单色光波长与标准值相符（误差 5% 以内），验证了 $\Delta x=\dfrac{l}{d}\lambda$ 公式。不同颜色的光波长不同：红光波长较长，绿光波长较短；这与白光干涉条纹中红光在外侧、紫光在内侧的现象一致。

### 七、误差分析

1. **偶然误差：**
   - $l$ 的测量误差：用毫米刻度尺测量，精度有限。多次测量取平均可减小。
   - $\Delta x$ 的测量误差：测量头读数精度限制、分划板对齐误差。采用「累积法」（测 $n$ 条条纹总宽再除以 $n-1$）可减小。
2. **系统误差：**
   - 分划板中心刻线与条纹中心不完全对齐。
   - 双缝间距 $d$ 的制造误差。
   - 滤光片通带较宽，波长不严格单一。
   - 光路未严格共轴，条纹间距不均匀。
3. **误差减小措施：**
   - 多次测量取平均。
   - 采用累积法测 $\Delta x$。
   - 仔细调节光路共轴。
   - 选用质量较好的双缝片和滤光片。

### 八、注意事项

1. 双缝干涉仪是精密仪器，应轻拿轻放，不要随便拆解遮光筒、测量头等元件。
2. 滤光片、单缝、双缝、目镜等如有灰尘，应用擦镜纸轻擦，不可用手直接接触光学面。
3. 安装时，调节光源、滤光片、单缝、双缝的中心均在遮光筒的中心轴线上，并使单缝与双缝平行且竖直，间距约 5~10 cm。
4. 测量头使用时应使分划板中心刻线对齐明纹中心，转动手轮时单向转动，避免回程误差。
5. 测量 $n$ 条条纹总宽度时，$n$ 应取 5~7 条，以减小相对误差。
6. 实验环境应较暗，避免环境光干扰。
7. 光源通电后需预热几分钟，使灯丝发光稳定。
8. 不要直接测单个 $\Delta x$，应通过测 $n$ 条条纹间距求平均（累积法）减小误差。

## 实验 13：用激光笔和传感器做单缝衍射实验

### 一、实验目的

1. 观察单缝衍射现象。
2. 比较单缝衍射与双缝干涉条纹的区别。
3. 理解衍射是波特有的现象。

### 二、实验器材

- 激光笔
- 单缝片（缝宽可调，如 0.05~0.2 mm）
- 光传感器
- 计算机
- 屏幕

### 三、实验原理

激光通过单缝后发生衍射，在屏上形成中央明纹宽且亮、两侧明纹较窄较暗的衍射条纹。衍射条纹的光强分布为

$$I=I_0\left[\dfrac{\sin\alpha}{\alpha}\right]^2,\quad \alpha=\dfrac{\pi a\sin\theta}{\lambda}$$

其中 $a$ 为缝宽，$\theta$ 为衍射角。中央明纹宽，两侧明纹宽为中央明纹的一半，光强递减。

### 四、实验步骤

1. 调节激光通过单缝，在屏上观察衍射条纹。
2. 注意中央明纹的宽度和亮度。
3. 用光传感器扫描条纹，得到光强分布曲线。
4. 改变缝宽，观察衍射条纹的变化。
5. 测量中央明纹宽度，由公式估算波长。

### 五、实验现象与数据记录

- 中央明纹宽且亮，两侧明纹对称分布，宽度递减。
- 缝越窄，衍射条纹越宽（衍射越明显）。
- 缝越宽，衍射条纹越窄（接近直线传播）。
- 光强分布曲线为 $\left(\dfrac{\sin\alpha}{\alpha}\right)^2$ 形。

### 六、实验结果与结论

单缝衍射条纹中央明纹宽且亮，与双缝干涉条纹（等间距）不同。缝越窄衍射越明显，验证了衍射条件。

### 七、误差分析

1. 缝宽测量误差。
2. 条纹间距测量误差。
3. 激光波长不单一。
4. 传感器响应不一致。

### 八、注意事项

1. 激光勿直射眼睛。
2. 单缝片与激光方向垂直。
3. 实验在暗处进行。
4. 缝宽调节适当，太宽衍射不明显，太窄光强过弱。

## 实验 14：用羽毛做光栅衍射实验

### 一、实验目的

1. 用羽毛观察光栅衍射现象。
2. 理解衍射光栅的原理。
3. 体会自然物的衍射效应。

### 二、实验器材

- 鸡毛或鸽羽毛（一根）
- 蜡烛
- 远处小光源（如远处路灯、小灯泡）
- 暗室

### 三、实验原理

羽毛的羽枝排列成周期性结构，相当于透射式衍射光栅。光通过羽毛时发生衍射，形成多级衍射条纹。光栅衍射明纹条件：

$$d\sin\theta=k\lambda,\quad k=0,\pm1,\pm2,\dots$$

其中 $d$ 为光栅常数（相邻羽枝间距），$\theta$ 为衍射角。

### 四、实验步骤

1. 透过羽毛观察远处的点光源（蜡烛或小灯泡）。
2. 注意观察到的衍射图样。
3. 改变光源颜色（用滤光片），观察衍射角变化。
4. 用白光光源观察，注意彩色条纹的排列。
5. 旋转羽毛，观察衍射条纹方向变化。

### 五、实验现象与数据记录

- 透过羽毛看点光源，看到十字形或菱形排列的衍射光斑。
- 中央为零级明纹，两侧依次为一级、二级明纹。
- 白光衍射时条纹呈彩色，红光在外、紫光在内。
- 旋转羽毛时，衍射条纹方向随之旋转。

### 六、实验结果与结论

羽毛的周期性结构相当于衍射光栅，使光发生衍射。这证明光具有波动性，也说明衍射光栅的原理。

### 七、误差分析

1. 羽毛羽枝间距不均匀。
2. 光源非点光源，衍射图样不清晰。
3. 羽毛透光率低，衍射光弱。

### 八、注意事项

1. 选择羽枝排列整齐的羽毛。
2. 光源应小而亮。
3. 实验在暗处进行。
4. 可配合讲解光栅的应用（光谱分析、衍射光栅等）。

## 实验 15：偏振光的实验研究

### 一、实验目的

1. 观察光的偏振现象。
2. 理解偏振片的作用和马吕斯定律。
3. 认识自然光与偏振光的区别。

### 二、实验器材

- 偏振片（2 片）
- 光源（自然光，如白炽灯）
- 激光笔
- 光传感器（或光功率计）
- 量角器
- 玻璃片（反射起偏用）

### 三、实验原理

自然光的光振动在垂直于传播方向的平面内各方向均匀分布。偏振片只允许某一方向的光振动通过，自然光通过偏振片后变为线偏振光。两片偏振片正交时（偏振方向垂直），透射光强为零；平行时透射光强最大。马吕斯定律：

$$I=I_0\cos^2\theta$$

其中 $\theta$ 为两偏振片偏振方向的夹角，$I_0$ 为通过第一片后的光强。

### 四、实验步骤

1. **观察起偏：** 让自然光通过一片偏振片，用光传感器测透射光强。旋转偏振片，观察光强是否变化（自然光通过偏振片后变为偏振光，光强减半，且旋转时光强不变）。
2. **观察检偏：** 在第一片偏振片后再放第二片，旋转第二片，观察透射光强变化。每 10° 记录一次光强。
3. **验证马吕斯定律：** 以 $\cos^2\theta$ 为横轴，$I$ 为纵轴作图，应为直线。
4. **反射起偏：** 让自然光以布儒斯特角（约 56°）照射玻璃片，反射光为偏振光，用偏振片检验。

### 五、实验现象与数据记录

| 夹角 $\theta$ | $\cos^2\theta$ | 透射光强 $I$ |
|---|---|---|
| 0° | 1.00 | 最大 |
| 30° | 0.75 | 较大 |
| 45° | 0.50 | 中等 |
| 60° | 0.25 | 较小 |
| 90° | 0.00 | 几乎为零 |

### 六、实验结果与结论

- 自然光通过偏振片后变为线偏振光。
- 两偏振片正交时（90°）光强最小，平行时（0°）光强最大。
- 透射光强与 $\cos^2\theta$ 成正比，验证了马吕斯定律。

### 七、误差分析

1. 偏振片不理想，有部分漏光。
2. 角度读数误差。
3. 光传感器响应不一致。
4. 自然光并非完全非偏振（如天空散射光有部分偏振）。

### 八、注意事项

1. 偏振片应保持清洁。
2. 旋转偏振片时缓慢均匀。
3. 光源应稳定。
4. 演示时可联系偏振片的应用（液晶显示、3D 眼镜、摄影滤镜等）。

## 实验 16：检验光波是不是横波

### 一、实验目的

1. 通过偏振实验检验光波是横波还是纵波。
2. 理解偏振是横波特有的现象。
3. 加深对光波动性的认识。

### 二、实验器材

- 偏振片（2 片）
- 光源（自然光，如白炽灯或日光灯）
- 演示用弹簧（用于演示纵波通过偏振片的现象）

### 三、实验原理

横波的振动方向与传播方向垂直，通过偏振片后只保留某一方向的振动，旋转偏振片时光强会变化。纵波的振动方向与传播方向平行，不存在偏振现象，通过偏振片后旋转偏振片光强不变。因此，光通过偏振片后旋转偏振片时光强变化，证明光波是横波。

### 四、实验步骤

1. **对比演示纵波：** 让弹簧上的纵波通过「偏振栅」（两根平行细杆），旋转栅的方向，纵波始终能通过。
2. **横波对比：** 让绳上的横波通过偏振栅，当栅方向与振动方向一致时波能通过，垂直时不能通过。
3. **光的偏振：** 让自然光通过一片偏振片，再用第二片偏振片检验。旋转第二片，观察光强变化。
4. **结论：** 光通过偏振片后，旋转检偏器光强会变化，类似于横波通过偏振栅，证明光波是横波。

### 五、实验现象与数据记录

- 纵波通过偏振栅：旋转栅，波始终通过。
- 横波通过偏振栅：栅与振动方向一致时通过，垂直时被阻挡。
- 光通过偏振片：旋转检偏器，光强从最大变到最小（接近零）。
- 光强变化与横波通过偏振栅现象一致。

### 六、实验结果与结论

光通过偏振片后，旋转检偏器时光强发生变化，这与横波通过偏振栅的现象一致。因此光波是横波，即光振动方向与传播方向垂直。

### 七、误差分析

1. 偏振片不理想，正交时光强不为零。
2. 自然光本身可能含有部分偏振成分（如天空光）。
3. 演示横波、纵波时偏振栅与波不完全匹配。

### 八、注意事项

1. 偏振片应严格对准光源。
2. 旋转检偏器时缓慢，便于观察。
3. 演示对比横波、纵波时，偏振栅间距应小于波长。
4. 配合讲解偏振现象的应用：偏振镜、液晶显示、应力检测等。
