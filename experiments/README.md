## 文档统一结构

每个 Markdown 文件均采用以下结构：

- **本章实验概览**：列出本章所有实验清单
- **每个实验包含 8 个小节**：
  1. 实验目的
  2. 实验器材（含规格）
  3. 实验原理（含公式推导）
  4. 实验步骤（编号细致到每一步操作）
  5. 实验现象与数据记录（含表格示例）
  6. 实验结果与结论
  7. 误差分析（区分系统误差与偶然误差）
  8. 注意事项
