## 实验 1：观察扩散现象

### 一、实验目的

1. 通过观察不同物质相互接触时彼此进入对方的现象，认识扩散现象。
2. 理解扩散现象是分子永不停息做无规则运动的直接证据。
3. 探究影响扩散快慢的因素，知道温度对扩散快慢的影响。
4. 体会从宏观现象推测微观本质的科学推理方法。

### 二、实验器材

- 二氧化氮气体一瓶（红棕色，密度大于空气）
- 集气瓶两只（口径相同，配玻璃片）
- 红墨水一瓶
- 两个相同烧杯（各盛等质量清水）
- 滴管一支
- 硫酸铜溶液（蓝色）适量
- 量筒一只（500 mL）
- 试管一支（带橡皮塞）
- 酒精、纯水若干
- 温度计两支
- 热水、冷水（温差 30 ℃以上）

### 三、实验原理

扩散现象是指不同物质相互接触时彼此进入对方的现象。从微观角度看，扩散是由于物质分子的无规则运动产生的。分子的无规则运动使分子能够穿越物质的边界，进入对方内部。温度越高，分子热运动越剧烈，扩散越快；物质状态不同扩散快慢也不同，气体扩散最快，液体次之，固体最慢。

本实验通过气体扩散（二氧化氮与空气）、液体扩散（红墨水在水中、硫酸铜与水）和温度对扩散快慢影响的对比，多角度展示分子热运动。

### 四、实验步骤

1. **气体扩散实验**：取两个集气瓶，一瓶装满红棕色的二氧化氮气体（密度大于空气），另一瓶为空气。将空气瓶倒置在二氧化氮瓶上方，抽去中间玻璃片，静置观察瓶内气体颜色变化。
2. **液体扩散实验**：在一量筒中先加入一定量清水，再用长颈漏斗将硫酸铜溶液缓缓注入水底。静置观察两液体界面随时间的变化。
3. **温度对扩散的影响**：取两个相同烧杯，分别加入等质量的热水和冷水（用温度计记录温差）。用滴管同时向两个烧杯中滴入一滴红墨水，观察并比较两杯水中红墨水扩散的快慢。
4. **固体扩散（演示视频或史料介绍）**：介绍铅片与金片紧压贴合数年后相互渗入约 1 mm 的事实。
5. 记录各组实验的现象，并比较扩散快慢。

### 五、实验现象与数据记录

| 实验内容 | 现象记录 | 结论 |
| -------- | -------- | ---- |
| 气体扩散（NO₂ 向上） | 上方空气瓶逐渐变红棕色，下方 NO₂ 瓶颜色变浅，最后两瓶颜色均匀 | 气体分子相互进入对方，扩散快 |
| 液体扩散（CuSO₄ 与水） | 界面起初清晰，几天后变模糊，几周后整瓶变蓝色均匀 | 液体分子也可扩散，但慢于气体 |
| 冷水中滴红墨水 | 红色扩散缓慢，约 1 分钟后整杯微红 | 扩散慢 |
| 热水中滴红墨水 | 红色扩散迅速，约 20 秒整杯变红 | 温度高，扩散快 |

### 六、实验结果与结论

1. 不同的物质相互接触时，都能彼此进入对方，即发生扩散现象。
2. 气体扩散最快，液体较慢，固体最慢。
3. 温度越高，扩散越快，说明分子无规则运动越剧烈。
4. 扩散现象是分子永不停息做无规则运动的直接证据。

### 七、误差分析

1. **外界气流干扰**：气体扩散实验中若有气流，会产生对流而非单纯扩散。改进措施：实验在密闭、无风的实验室内进行，并静置观察。
2. **温差不易控制**：冷热水温差不足时现象不明显。改进措施：使用接近沸水与冰水，确保温差 30 ℃以上。
3. **滴入红墨水的量与位置不同**：滴入量或位置不一致会影响比较。改进措施：使用同一滴管，每滴体积一致，滴在液面中央相同高度。
4. **观察主观性**：颜色变化由肉眼判断，存在主观误差。可借助相机定时拍摄对比。

### 八、注意事项

1. 二氧化氮有毒，气体扩散实验应在通风良好的实验室进行，或在封闭容器内演示。
2. 硫酸铜有毒，使用时应避免接触皮肤，实验后倒入指定废液缸。
3. 液体扩散实验需要长时间静置，不可晃动容器，否则会影响观察结果。
4. 滴入红墨水时应轻缓，避免产生水流扰动。
5. 实验中要控制变量，保证冷热水质量、烧杯规格、滴入量等一致。

## 实验 2：观察布朗运动

### 一、实验目的

1. 观察悬浮在液体中的微粒所做的无规则运动——布朗运动。
2. 理解布朗运动产生的原因，知道它是液体分子无规则运动的间接反映。
3. 探究影响布朗运动显著程度的因素（颗粒大小、温度）。
4. 体会间接观察的研究方法。

### 二、实验器材

- 显微镜一台（放大倍数 400 倍以上）
- 载玻片、盖玻片若干
- 藤黄粉（或花粉、墨汁）少量
- 蒸馏水
- 滴管一支
- 酒精灯、火柴
- 温度计一支
- 烧杯两只（一只盛冷水，一只盛热水）
- 计时器一只
- 显微镜投影仪或摄像头（可选，便于全班观察）

### 三、实验原理

布朗运动是指悬浮在液体（或气体）中的微粒所做的永不停息的无规则运动。1827 年英国植物学家布朗用显微镜观察悬浮在水中的花粉时发现了这种现象。其产生原因是：液体分子做永不停息的无规则运动，不断撞击悬浮微粒；由于微粒足够小，在某一瞬间来自各个方向的液体分子的撞击作用不平衡，使得微粒受力不平衡而运动。微粒越小，运动状态越容易改变，布朗运动越明显；温度越高，液体分子运动越剧烈，布朗运动也越明显。布朗运动不是分子运动，而是分子热运动的间接反映。

### 四、实验步骤

1. **制备悬浊液**：取少量藤黄粉（或墨汁）放入盛有蒸馏水的烧杯中，搅拌稀释，使微粒在显微镜下能清晰可见且数量适中。
2. 用滴管吸取一滴悬浊液滴在载玻片中央，盖上盖玻片（注意避免产生气泡）。
3. 将载玻片放在显微镜载物台上，先用低倍镜找到微粒，再换高倍镜观察。
4. 调节显微镜焦距，使微粒清晰可见。选择一颗较小的微粒作为观察对象。
5. 每隔 30 秒记录一次该微粒的位置（用显微镜中的目镜测微尺或借助投影描绘），连续记录 8～10 个位置。
6. 用线段依次连接各位置，得到微粒运动的位置连线图。
7. 另选较大的微粒重复观察，对比大、小颗粒运动的剧烈程度。
8. 将悬浊液加热到约 40 ℃（或将载玻片在酒精灯上略微加热），再观察微粒运动的剧烈程度。

### 五、实验现象与数据记录

| 观察对象 | 现象记录 |
| -------- | -------- |
| 较小微粒（约 1 μm） | 微粒做明显的无规则运动，运动方向不断改变 |
| 较大微粒（约 10 μm） | 微粒几乎不动或运动不明显 |
| 室温下的微粒 | 微粒缓慢移动 |
| 加热后的微粒 | 微粒运动明显更剧烈 |
| 30 s 间隔位置连线图 | 折线杂乱无章，无规律性 |

微粒位置连线示意（每 30 s 一个位置）：

```
   •
        \
         •
        /
       •
         \
          •
        /
       •
```

### 六、实验结果与结论

1. 悬浮在液体中的微粒永不停息地做无规则运动，即布朗运动。
2. 微粒越小，布朗运动越明显；温度越高，布朗运动越剧烈。
3. 布朗运动产生的原因是液体分子对微粒撞击的不平衡，间接证明了液体分子在做永不停息的无规则运动。

### 七、误差分析

1. **外界震动干扰**：实验台震动会被误认为是布朗运动。改进措施：实验应在稳固的防震台上进行，避免外界震动。
2. **悬浊液浓度不当**：浓度过高时微粒密集难以分辨，过低时视野中微粒太少。改进措施：稀释到合适浓度。
3. **加热温度不易控制**：加热过度会使水分蒸发过快，影响观察。改进措施：使用恒温水浴或加热载玻片边缘。
4. **观察主观性**：微粒位置的记录存在主观误差。改进措施：使用带有目镜测微尺的显微镜或视频记录。

### 八、注意事项

1. 显微镜放大倍数以 400 倍左右为宜，过高时视野变暗且景深变小。
2. 盖玻片下不能有气泡，否则影响观察。
3. 观察时间不宜过长，水分蒸发后微粒运动会停止。
4. 不能将布朗运动说成是分子运动，布朗微粒远大于分子，肉眼或显微镜才能看到。
5. 加热时温度不宜过高（不超过 50 ℃），以防载玻片破裂或悬浊液迅速蒸发。

## 实验 3：用油膜法估测油酸分子的大小

### 一、实验目的

1. 学会用油膜法估测油酸分子的大小，理解通过测量宏观量间接测量微观量的方法。
2. 通过构建"单分子油膜层"的物理模型，体会建模方法在物理研究中的重要作用。
3. 知道一般分子直径的数量级为 10⁻¹⁰ m。

### 二、实验器材

- 浅盘一只（边长约 30～40 cm，深约 5 cm）
- 容量瓶一只（500 mL）
- 量筒一只（10 mL）
- 注射器一支（或滴管，量程 1 mL）
- 油酸酒精溶液（已配制，浓度 0.2% 或 1∶500）
- 痱子粉（或石膏粉）少量
- 纱布一小块（用于包裹痱子粉）
- 刻有方格的透明玻璃板（或塑料板）一块
- 彩色水笔一支
- 坐标纸一张
- 清水若干
- 脱脂棉、酒精（用于清洗）

### 三、实验原理

将油酸（C₁₇H₃₃COOH）溶于酒精配制成油酸酒精溶液。油酸具有一个亲水基团（COOH）和一个疏水基团（烃链），滴在水面上时，酒精迅速溶于水并挥发，油酸分子会一个紧挨一个地平铺在水面上，形成单分子层油膜。将油酸分子视为球形，则单分子油膜的厚度即为油酸分子的直径 d。

设一滴油酸酒精溶液中纯油酸的体积为 V，油膜在水面上的展开面积为 S，则：

$$d = \frac{V}{S}$$

其中，纯油酸体积 V 的计算方法：

1. 用注射器测出 N 滴油酸酒精溶液的体积 V_N，则一滴溶液的体积 V' = V_N / N。
2. 一滴溶液中纯油酸的体积 V = V' × η，η 为油酸酒精溶液的浓度。

### 四、实验步骤

1. **配制溶液**：取 1 mL 油酸注入 500 mL 容量瓶，加酒精至刻度线，摇匀，得到浓度约 0.2% 的油酸酒精溶液（教师可课前配制）。
2. **测定一滴溶液的体积**：用注射器（或滴管）将油酸酒精溶液一滴一滴地滴入量筒中，记下量筒中增加 1 mL 时所滴的滴数 N（一般约 100 滴），则一滴溶液的体积 V' = 1/N mL。
3. **准备浅盘**：用清水清洗浅盘，洗去油污、粉尘。倒入约 2 cm 深的清水。
4. **撒痱子粉**：用纱布包裹少量痱子粉，在水面上方轻轻拍打，使痱子粉薄而均匀地撒在水面上。
5. **滴入油酸**：用注射器在距水面约 1 cm 处，轻轻滴一滴油酸酒精溶液在水面上。
6. **描绘油膜轮廓**：待油酸薄膜形状稳定（约 1 分钟，等待酒精挥发后油膜收缩至稳定）后，将刻有方格的玻璃板放在浅盘上，用彩笔在玻璃板上描绘油膜的轮廓。
7. **计算油膜面积**：将画有油膜轮廓的玻璃板放在坐标纸上，数出轮廓内方格的数量（不足半格舍去，多于半格算一格），每格面积为 a²（如边长 1 cm 的小格），油膜面积 S = n × a²。
8. **计算分子直径**：根据公式 d = V / S 计算油酸分子直径。
9. **重复实验**：清洗浅盘，重复步骤 3～8 共测 3 次，求平均值。

### 五、实验现象与数据记录

数据记录表（示例数据）：

| 次数 | 1 mL 溶液滴数 N | 一滴溶液体积 V' (mL) | 油酸浓度 η | 一滴纯油酸体积 V (mL) | 油膜方格数 n | 油膜面积 S (cm²) | 分子直径 d (m) |
| ---- | --------------- | -------------------- | ---------- | --------------------- | ------------ | ----------------- | -------------- |
| 1 | 100 | 0.01 | 0.2% | 2.0×10⁻⁵ | 200 | 200 | 1.0×10⁻⁹ |
| 2 | 100 | 0.01 | 0.2% | 2.0×10⁻⁵ | 195 | 195 | 1.03×10⁻⁹ |
| 3 | 100 | 0.01 | 0.2% | 2.0×10⁻⁵ | 205 | 205 | 0.98×10⁻⁹ |
| 平均 | — | — | — | — | — | — | 约 1.0×10⁻⁹ |

注：实际实验测得的油酸分子直径数量级约为 10⁻⁹ m（与油酸分子实际长度相符，因油酸分子为长链结构，长度比一般球体分子直径略大）。

### 六、实验结果与结论

1. 通过宏观量的测量（油酸溶液体积、油膜面积）间接获得了微观量（油酸分子直径）。
2. 测得油酸分子直径数量级为 10⁻⁹ m，与理论值较为吻合，验证了油酸分子大小的数量级。
3. 实验中采用"理想模型法"——将油酸分子视为球形且紧密排列，单分子层平铺。

### 七、误差分析

1. **油膜面积测量误差（偶然误差）**：方格法数格时舍入误差。改进措施：使用方格更小的坐标纸，待油膜稳定后再描绘轮廓。
2. **溶液浓度变化（系统误差）**：油酸酒精溶液长时间放置后酒精挥发，浓度变大。改进措施：现配现用，不长期放置。
3. **非单分子层（系统误差）**：油膜过厚会使测量值偏大。改进措施：使用更稀的溶液（小于 0.1%），保证形成单分子层。
4. **一滴溶液体积测量误差**：滴数 N 不易准确测量。改进措施：多次测量取平均，使用细针头注射器保证滴大小均匀。
5. **痱子粉撒布不均**：粉层过厚或过薄都会影响油膜展开。改进措施：用纱布包裹后轻拍，撒粉薄而均匀。
6. **水面残留油酸**：重复实验时残留油酸影响下次测量。改进措施：每次实验后用酒精清洗浅盘并用脱脂棉擦干，再用水冲洗。

### 八、注意事项

1. 油酸酒精溶液应现配现用，避免长时间放置浓度改变。
2. 实验前必须充分清洗浅盘，去除油污和粉尘。
3. 滴管（或注射器针头）应距水面 1 cm 以内，否则油膜难以形成。
4. 痱子粉要薄而均匀，不可过厚，否则油膜不能充分展开。
5. 油膜形状稳定后再描绘轮廓，不要在扩散或收缩过程中描绘。
6. 描轮廓时视线应与玻璃板垂直。
7. 数方格时，不足半格舍去，多于半格算一格。
8. 实验只要求估测，结果数量级符合要求（10⁻⁹ m）即可。

## 实验 4：酒精与水混合后体积减小

### 一、实验目的

1. 通过观察酒精与水混合后总体积减小的现象，认识分子间存在间隙。
2. 进一步理解分子动理论的基本观点——分子间有空隙。
3. 体会宏观现象与微观结构之间的联系。

### 二、实验器材

- 量筒一支（500 mL，最小刻度 5 mL）
- 酒精若干（纯度 95% 以上）
- 着色水若干（用红墨水染成红色，便于观察）
- 橡胶塞一只（与量筒配套）
- 玻璃管一根（长约 30 cm，可插入橡胶塞中）

### 三、实验原理

分子间存在间隙。当酒精和水混合时，酒精分子和水分子彼此进入对方的分子间隙中，导致混合后的总体积小于混合前两种液体的体积之和。这一现象直观地证明了分子间存在间隙。

### 四、实验步骤

1. 在量筒中加入 50 mL 着色水（红色），记录读数 V₁ = 50 mL。
2. 沿量筒壁缓缓倒入 50 mL 酒精，注意尽量减少扰动，使酒精浮在水面上。
3. 记录混合前总体积 V₂ = V₁ + 50 mL = 100 mL。
4. 用橡胶塞塞紧量筒口（橡胶塞上可插入一根玻璃管以观察液面），颠倒量筒几次使酒精和水充分混合。
5. 将量筒正立静置，观察并记录混合后的总体积 V₃。
6. 计算 ΔV = V₂ - V₃，即体积减小量。

### 五、实验现象与数据记录

| 项目 | 数值 |
| ---- | ---- |
| 水的体积 V₁ | 50 mL |
| 酒精的体积 | 50 mL |
| 混合前总体积 V₂ | 100 mL |
| 混合后总体积 V₃ | 约 96～97 mL |
| 体积减小量 ΔV | 约 3～4 mL |

### 六、实验结果与结论

1. 酒精和水混合后的总体积小于混合前的总体积之和，约减小 3～4 mL。
2. 实验结论：分子之间存在间隙，混合时一种物质的分子进入另一种物质的分子间隙中，使总体积减小。

### 七、误差分析

1. **倾倒扰动**：倒入酒精时若过猛会与水提前混合，使混合前体积读数偏小。改进措施：沿量筒壁缓慢倒入。
2. **读数误差**：弯月面读数时视线不水平会引起误差。改进措施：视线与液面最低处相平。
3. **温度变化**：混合过程可能伴随温度变化，影响体积。改进措施：在恒温环境下进行。
4. **酒精挥发**：酒精易挥发导致体积减小被误判。改进措施：迅速操作，加盖密封。

### 八、注意事项

1. 量筒应竖直放置，读数时视线与液面凹面最低处相平。
2. 倒入酒精时应沿管壁缓缓倒入，避免扰动。
3. 混合时应反复颠倒几次，确保充分混合。
4. 酒精易燃，远离明火。

## 实验 5：观察分子间的引力（铅块实验）

### 一、实验目的

1. 通过观察两铅块压紧后不易拉开的现象，认识分子间存在引力。
2. 进一步理解分子间作用力的特点。
3. 体会分子力在宏观现象上的表现。

### 二、实验器材

- 铅柱（或铅块）两只，端面平整光滑，带挂钩
- 倒钩或细绳
- 砝码若干（500 g～5 kg）
- 细砂纸一张
- 脱脂棉、酒精（用于清洁铅块端面）
- 小刀或刮刀（用于修整端面）

### 三、实验原理

分子之间存在相互作用的引力。当两个铅块的端面被压紧且端面足够平整时，分子间距离接近平衡距离 r₀，分子力表现为引力。铅是一种较软的金属，端面容易密合，因此常被用于演示分子引力。两铅块压紧后可承受数千克的重物而不被拉开，宏观上表现出强大的"粘合力"，这正是分子引力的体现。

### 四、实验步骤

1. 用细砂纸打磨两个铅柱的端面，使其平整光滑，去除氧化层。
2. 用脱脂棉蘸酒精擦拭端面，去除油污。
3. 将两个铅柱的端面相对，沿轴向用力压紧并同时略微旋转，使两端的铅分子尽可能靠近。
4. 松手后观察两铅块是否粘在一起。
5. 提起上方的铅柱，观察下方铅块是否被一起提起。
6. 在下方铅块的挂钩上挂砝码，逐渐增加砝码重量，直到两铅块被拉开，记录最大承重。
7. 重复实验 2～3 次，观察现象的一致性。

### 五、实验现象与数据记录

| 现象 | 描述 |
| ---- | ---- |
| 压紧前 | 两铅块端面光滑但分离 |
| 压紧松手后 | 两铅块粘在一起 |
| 提起上方铅块 | 下方铅块一起被提起 |
| 挂砝码 | 可承受 1～3 kg 重物不被拉开 |
| 拉开瞬间 | 端面有铅被撕裂的痕迹 |

### 六、实验结果与结论

1. 两个铅块压紧后能够粘在一起，并能承受相当大的拉力（数千克）。
2. 这种粘合力不是由于胶水或静电，而是由于分子间的引力。
3. 实验结论：分子之间存在相互作用的引力，宏观上表现为铅块的"粘合"。

### 七、误差分析

1. **端面不平整**：端面有氧化层或划痕时，分子间距过大，引力作用不明显。改进措施：用砂纸仔细打磨端面，使其光滑平整。
2. **压紧力度不够**：压紧力不足会使两铅块端面分子间距过大。改进措施：用力压紧并同时旋转，使端面更紧密接触。
3. **环境潮湿**：水膜会阻碍分子接触。改进措施：保持环境干燥，端面用酒精清洁。
4. **铅块纯度**：铅合金比纯铅硬度大，不易密合。改进措施：使用纯铅块。

### 八、注意事项

1. 铅有毒，实验后应洗手，避免铅进入口中。
2. 实验中挂砝码时应在下方放置软垫，防止铅块突然拉开砝码掉落伤人。
3. 端面打磨时注意安全，避免割伤。
4. 铅块较软，端面易受损，实验前应重新打磨。
5. 压紧铅块时要沿轴向用力，避免侧向滑动。

## 实验 6：模拟分子间作用力（弹簧模型）

### 一、实验目的

1. 通过类比法，用弹簧模型直观理解分子间引力和斥力的变化规律。
2. 知道分子间作用力与分子间距离的关系。
3. 体会物理学中类比方法的运用。

### 二、实验器材

- 弹簧一支（劲度系数较小）
- 两个小球（代表两个分子，可磁性连接）
- 力传感器或弹簧测力计一个
- 米尺一支
- 记录表格

### 三、实验原理

分子间同时存在引力和斥力，它们都随分子间距离 r 的变化而变化。当 r = r₀（约 10⁻¹⁰ m）时，引力等于斥力，分子力为零，此为平衡位置。当 r < r₀ 时，斥力增大更快，分子力表现为斥力；当 r > r₀ 时，斥力减小更快，分子力表现为引力；当 r > 10 r₀ 时，分子力可忽略。

弹簧两端连接小球，类似两个分子：当弹簧被压缩（r < r₀）时表现为斥力，被拉伸（r > r₀）时表现为引力，自然长度对应平衡位置。

### 四、实验步骤

1. 将弹簧两端各连接一个小球，使弹簧处于自然长度，记录此时两球间距 r₀。
2. 用力将两球向内压缩，使间距小于 r₀，感受斥力（弹簧向外推）。
3. 用力将两球向外拉伸，使间距大于 r₀，感受引力（弹簧向内拉）。
4. 用力传感器分别测量不同间距时的力的大小，并记录。
5. 绘制 F-r 图像，与分子力-距离关系曲线对比。

### 五、实验现象与数据记录

| 间距 r 与 r₀ 关系 | 力的方向 | 力的性质 |
| ----------------- | -------- | -------- |
| r < r₀（压缩） | 向外 | 斥力 |
| r = r₀（自然长度） | 无 | 平衡 |
| r > r₀（拉伸） | 向内 | 引力 |
| r >> r₀ | 几乎为零 | 可忽略 |

### 六、实验结果与结论

1. 弹簧在压缩时表现为斥力，在拉伸时表现为引力，自然长度时无力。
2. 类比可知：分子间作用力在 r < r₀ 时表现为斥力，在 r > r₀ 时表现为引力，在 r = r₀ 时为零。
3. 弹簧模型虽不能完全模拟分子力的非线性特征，但能直观反映"近斥远引"的基本规律。

### 七、误差分析

1. **弹簧的非线性**：弹簧力与形变成线性关系（胡克定律），而分子力是非线性的，模型只是定性类比。
2. **测量精度**：力传感器和距离测量存在误差。
3. **类比局限性**：分子力同时存在引力和斥力，而弹簧只能表现一种力（拉或压），需向学生说明。

### 八、注意事项

1. 实验只是定性类比，不能完全等同于分子力。
2. 应强调分子力同时存在引力和斥力，合力表现为引力或斥力。
3. 弹簧不要过度拉伸，以免超过弹性限度。
4. 配合教材中的分子力-距离关系图（F-r 图像）讲解。
