## 实验 1：练习使用游标卡尺

### 一、实验目的

1. 了解游标卡尺的构造和原理，掌握其使用方法。
2. 能正确读出游标卡尺的示数，注意估读规则。
3. 学会用游标卡尺测量长度、内径、外径和深度。

### 二、实验器材

- 游标卡尺一把（10 分度、20 分度或 50 分度均可，常用 20 分度）
- 待测物体：金属圆柱体、金属圆管、小钢珠、玻璃杯等
- 记录纸、笔

### 三、实验原理

游标卡尺由主尺和游标尺组成。主尺的最小分度是 1 mm，游标尺上有若干等分刻度。利用主尺的单位刻度与游标尺的单位刻度之间固定的微量差值来提高测量精度。

**原理**：游标尺上 N 个分度格的总长度等于主尺上 (N-1) 个分度格的总长度，即 (N-1) mm。因此游标尺上每一格的长度为 (N-1)/N mm，与主尺 1 mm 的差值为 1/N mm，这就是游标卡尺的精确度。

| 分度数 N | 游标尺总长 | 每小格与 1 mm 的差值 | 精确度 |
| -------- | ---------- | -------------------- | ------ |
| 10 | 9 mm | 0.1 mm | 0.1 mm |
| 20 | 19 mm | 0.05 mm | 0.05 mm |
| 50 | 49 mm | 0.02 mm | 0.02 mm |

**读数公式**：
测量值 L = 主尺读数 x + 游标尺对齐格数 K × 精确度

其中 x 是主尺上靠近游标尺零刻度线左侧的整毫米数，K 是游标尺上与主尺某刻度线对齐的那一条刻度线的格数（不含零刻度线）。

游标卡尺**不需要估读**，读数最后一位就是精确度所在位。

### 四、实验步骤

1. **观察游标卡尺**：认清主尺、游标尺、内测量爪、外测量爪、深度尺、紧固螺钉。
2. **检查零刻度线**：合拢两测量爪，观察主尺零刻度线与游标尺零刻度线是否对齐。若不对齐，记下零误差。
3. **测量外径**：用外测量爪夹住待测圆柱体的外径，旋紧固定螺钉，读数。
4. **测量内径**：用内测量爪插入待测圆管内，张开至紧贴管壁，读数。
5. **测量深度**：用深度尺插入待测孔或槽中，使主尺末端紧贴孔口，读数。
6. **测量长度**：用外测量爪夹住待测物体的两端，读数。
7. 多次测量取平均值。

### 五、实验现象与数据记录

**游标卡尺读数练习表**

| 测量对象 | 主尺读数 x/mm | 游标尺对齐格数 K | 精确度/mm | 测量值 L/mm |
| -------- | -------------- | ----------------- | --------- | ----------- |
| 圆柱体外径 | 12 | 5 (20 分度) | 0.05 | 12 + 5×0.05 = 12.25 |
| 圆管内径 | 22 | 3 (10 分度) | 0.1 | 22 + 3×0.1 = 22.3 |
| 孔的深度 | 8 | 10 (50 分度) | 0.02 | 8 + 10×0.02 = 8.20 |
| 物体长度 | 30 | 7 (20 分度) | 0.05 | 30 + 7×0.05 = 30.35 |

### 六、实验结果与结论

1. 游标卡尺读数 = 主尺读数 + 游标尺对齐格数 × 精确度。
2. 游标卡尺不需要估读，但读数最后一位是精确度所在位，不能随意加减零。
3. 不同分度数的游标卡尺精确度不同：10 分度 0.1 mm，20 分度 0.05 mm，50 分度 0.02 mm。

### 七、误差分析

1. **零误差**：游标卡尺使用前未校零，存在零误差。改进措施：使用前合拢测量爪检查零刻度线是否对齐，不对齐则记下零误差并在测量结果中修正。
2. **读数误差**：游标尺上对齐刻度线的判断存在主观误差，特别是模糊对齐时。改进措施：用放大镜辅助观察。
3. **测力误差**：测量时夹持力过大或过小都会影响测量结果。改进措施：使用微调螺钉控制夹持力。
4. **温度影响**：被测物体温度与卡尺温度不同时会产生热胀冷缩误差。
5. **视差误差**：读数时视线不垂直于尺面会产生视差。
6. **磨损误差**：长期使用后测量爪磨损，影响精度。

### 八、注意事项

1. 读数时要注意主尺上的单位，1、2、3 等数字通常表示厘米，每小格为 1 mm。
2. 区分游标尺的零刻度线和最前端，对齐的是零刻度线而非最前端。
3. 读数时不需要估读，但精确度所在位的零不能去掉。
4. 测量时要使用适当的夹持力，不要过紧或过松。
5. 使用前要检查零刻度线是否对齐，记下零误差。
6. 测量不同尺寸时要选择合适的测量爪。
7. 读数时视线要垂直于尺面，避免视差。
8. 游标卡尺使用完毕后要擦拭干净，放入专用盒中保存。

## 实验 2：练习使用螺旋测微器

### 一、实验目的

1. 了解螺旋测微器（千分尺）的构造和原理，掌握其使用方法。
2. 能正确读出螺旋测微器的示数，注意估读到 0.001 mm。
3. 学会用螺旋测微器测量细小物体的直径或厚度。

### 二、实验器材

- 螺旋测微器一把（量程 0-25 mm，精确度 0.01 mm）
- 待测物体：金属丝、小钢珠、薄金属片等
- 记录纸、笔

### 三、实验原理

螺旋测微器又叫千分尺，由尺架、测砧、固定刻度、可动刻度、旋钮、微调旋钮、测微螺杆组成。

**原理**：测微螺杆与固定刻度之间的精密螺纹的螺距为 0.5 mm，即旋钮每旋转一周，测微螺杆前进或后退 0.5 mm。可动刻度上有 50 个等分刻度，每旋转一小格，测微螺杆前进或后退 0.01 mm。因此螺旋测微器的精确度为 0.01 mm。

**读数方法**：
1. 先读固定刻度：读出毫米的整数部分。
2. 再读半毫米刻度：观察半毫米刻度线是否露出。若露出，记 0.5 mm；若未露出，记 0.0 mm。
3. 再读可动刻度：注意估读一位，记作 n×0.01 mm。
4. 最终读数 = 固定刻度 + 半刻度 + 可动刻度。

读数公式：
$$L = a + b \times 0.5 + n \times 0.01 \text{ (mm)}$$

其中 a 为固定刻度（mm 整数），b 为 0 或 1（半毫米刻度是否露出），n 为可动刻度读数（含估读）。

**螺旋测微器需要估读**，结果必须保留到毫米的千分位（小数点后三位，单位 mm）。

### 四、实验步骤

1. **观察螺旋测微器**：认清尺架、测砧、固定刻度、可动刻度、旋钮、微调旋钮、测微螺杆、绝热板。
2. **检查零刻度线**：旋出测微螺杆，使测砧和测微螺杆两测量面接触（不要直接旋旋钮，应使用微调旋钮）。观察固定刻度零线与可动刻度零线是否对齐。若不对齐，记下零误差。
3. **测量金属丝直径**：
   - 将金属丝放在测砧和测微螺杆之间。
   - 旋转旋钮使测微螺杆接近金属丝。
   - 当测微螺杆快接触金属丝时，改用微调旋钮，听到"咔哒"声即可。
   - 读数。
4. **测量小钢珠直径**：在不同方向上测量三次，取平均值。
5. **测量薄金属片厚度**：将金属片夹在测砧和测微螺杆之间，读数。
6. 多次测量取平均值。

### 五、实验现象与数据记录

**螺旋测微器读数练习表**

| 测量对象 | 固定刻度/mm | 半毫米刻度/mm | 可动刻度 | 测量值/mm |
| -------- | ------------ | -------------- | -------- | --------- |
| 金属丝直径 | 2.0 | 0 (未露出) | 15.0 | 2.0 + 0 + 15.0×0.01 = 2.150 |
| 钢珠直径 | 5.0 | 0.5 (露出) | 20.0 | 5.0 + 0.5 + 20.0×0.01 = 5.700 |
| 金属片厚度 | 1.0 | 0 (未露出) | 30.5 | 1.0 + 0 + 30.5×0.01 = 1.305 |

### 六、实验结果与结论

1. 螺旋测微器读数 = 固定刻度 + 半毫米刻度 + 可动刻度 × 0.01 mm。
2. 读数时必须注意半毫米刻度线是否露出。
3. 螺旋测微器必须估读到 0.001 mm（即小数点后三位，单位 mm）。
4. 螺旋测微器的精确度比游标卡尺高，适合测量细小物体。

### 七、误差分析

1. **零误差**：测量前未校零，存在零误差。改进措施：使用前校零，记下零误差修正。
2. **测力误差**：旋钮直接旋紧会导致夹持力过大，使被测物体变形或损坏仪器。改进措施：使用微调旋钮控制夹持力。
3. **读数误差**：半毫米刻度线是否露出的判断存在主观误差，可动刻度估读也有误差。
4. **视差误差**：读数时视线不垂直于刻度面会产生视差。
5. **温度影响**：被测物体与螺旋测微器温度不同时会产生热胀冷缩误差。
6. **螺纹间隙误差**：长期使用后螺纹磨损，间隙增大，影响精度。
7. **被测物体形状不规则**：测量细小物体时位置不同结果可能不同，应多次测量取平均值。

### 八、注意事项

1. 读数时准确到 0.01 mm，要估读到 0.001 mm。结果若用毫米作单位，小数点后必须保留三位。
2. 读数时要注意固定刻度上的半毫米刻度线是否露出。
3. 当测微螺杆快接触被测物体时，必须改用微调旋钮，听到"咔哒"声即停止，不能继续旋旋钮。
4. 使用前要校零，记下零误差。
5. 读数时视线要垂直于刻度面，避免视差。
6. 测量完毕后，测砧和测微螺杆之间要留有空隙，避免接触生锈。
7. 螺旋测微器使用完毕后擦拭干净，放入专用盒中保存。
8. 不能测量粗糙或带毛刺的物体，以免损坏测量面。

## 实验 3：探究导体电阻与其影响因素的定量关系

### 一、实验目的

1. 通过实验探究导体的电阻与导体的长度、横截面积、材料的关系。
2. 学习控制变量法在多变量实验中的应用。
3. 推导并验证电阻定律 R = ρL/S，理解电阻率的物理意义。

### 二、实验器材

- 不同材料的金属丝若干（如铜丝、铁丝、镍铬合金丝，直径相同）
- 不同长度的同种金属丝若干（如 0.5 m、1.0 m、1.5 m 长的镍铬合金丝）
- 不同横截面积的同种金属丝若干（如直径 0.2 mm、0.3 mm、0.5 mm 的镍铬合金丝，长度相同）
- 直流电源一个（稳压 4-6 V）
- 电流表一个（量程 0-0.6 A 或 0-3 A）
- 电压表一个（量程 0-3 V 或 0-15 V）
- 滑动变阻器一个
- 开关一个、导线若干
- 螺旋测微器、毫米刻度尺

### 三、实验原理

电阻是导体对电流的阻碍作用，与导体本身的性质有关。根据电阻定律，导体的电阻 R 与导体的长度 L 成正比，与导体的横截面积 S 成反比，还与导体的材料（电阻率 ρ）有关：

$$R = \rho \frac{L}{S}$$

实验采用控制变量法：
- 保持材料（ρ）和横截面积 S 不变，改变长度 L，研究 R 与 L 的关系。
- 保持材料（ρ）和长度 L 不变，改变横截面积 S，研究 R 与 S 的关系。
- 保持长度 L 和横截面积 S 不变，改变材料，研究 R 与 ρ 的关系。

电阻 R 通过伏安法测量：R = U/I。

### 四、实验步骤

1. **探究 R 与 L 的关系**：
   - 取同种材料（镍铬合金）、同一直径、不同长度的金属丝。
   - 用螺旋测微器测量金属丝直径 d，计算横截面积 S = πd²/4。
   - 用毫米刻度尺测量每根金属丝的有效长度 L。
   - 用伏安法分别测量每根金属丝的电阻 R（电路：金属丝与电流表串联，电压表并联在金属丝两端，滑动变阻器调节电流）。
   - 记录数据，分析 R 与 L 的关系。
2. **探究 R 与 S 的关系**：
   - 取同种材料（镍铬合金）、同一长度、不同直径的金属丝。
   - 用螺旋测微器测量每根金属丝的直径 d，计算 S = πd²/4。
   - 用伏安法分别测量每根金属丝的电阻 R。
   - 记录数据，分析 R 与 S 的关系。
3. **探究 R 与材料的关系**：
   - 取长度、横截面积相同但材料不同的金属丝（如铜、铁、镍铬合金）。
   - 用伏安法分别测量电阻 R。
   - 比较不同材料的电阻大小。
4. 整理器材。

### 五、实验现象与数据记录

**表 1：R 与 L 的关系（S 不变，镍铬合金丝）**

| 长度 L/m | 电压 U/V | 电流 I/A | 电阻 R = U/I/Ω |
| -------- | -------- | -------- | --------------- |
| 0.5 | 1.0 | 0.50 | 2.0 |
| 1.0 | 1.0 | 0.25 | 4.0 |
| 1.5 | 1.0 | 0.17 | 6.0 |
| 2.0 | 1.0 | 0.125 | 8.0 |

**表 2：R 与 S 的关系（L 不变，镍铬合金丝）**

| 直径 d/mm | 横截面积 S/mm² | 电阻 R/Ω | R·S 乘积 |
| --------- | -------------- | -------- | -------- |
| 0.20 | 0.0314 | 8.0 | 0.251 |
| 0.30 | 0.0707 | 3.55 | 0.251 |
| 0.40 | 0.1257 | 2.00 | 0.251 |
| 0.50 | 0.1963 | 1.28 | 0.251 |

**表 3：R 与材料的关系（L、S 相同）**

| 材料 | 电压 U/V | 电流 I/A | 电阻 R/Ω |
| ---- | -------- | -------- | -------- |
| 铜 | 0.5 | 0.625 | 0.80 |
| 铁 | 1.0 | 0.50 | 2.0 |
| 镍铬合金 | 2.0 | 0.40 | 5.0 |

### 六、实验结果与结论

1. 当材料和横截面积一定时，电阻 R 与长度 L 成正比：R ∝ L。
2. 当材料和长度一定时，电阻 R 与横截面积 S 成反比：R ∝ 1/S。
3. 当长度和横截面积一定时，电阻 R 与材料有关，不同材料电阻不同。
4. 综合得到电阻定律：R = ρL/S，其中 ρ 为电阻率，单位为 Ω·m。
5. 铜的电阻率最小，镍铬合金的电阻率最大。

### 七、误差分析

1. **测量误差**：长度、直径的测量存在误差，影响横截面积计算。
2. **接触电阻**：导线与接线柱之间、金属丝与夹具之间存在接触电阻，使测得的电阻偏大。
3. **温度影响**：通电后金属丝温度升高，电阻率变化（金属电阻率随温度升高而增大）。改进措施：电流要小，通电时间要短。
4. **电压表分流**：电压表内阻有限，会分流，使电流表示数大于实际通过金属丝的电流。
5. **电流表分压**：电流表内阻不为零，会分压，使电压表示数大于金属丝两端电压。
6. **金属丝不均匀**：金属丝的直径或材料分布不均匀，影响测量结果。
7. **通电时间长导致发热**：金属丝温度升高使电阻率变化，建议每次读数后立即断电。

### 八、注意事项

1. 通电时间要短，每次读数后立即断开开关，避免金属丝发热。
2. 电流不宜过大（一般不超过 0.5 A），避免金属丝温度明显升高。
3. 测量直径时要在金属丝不同位置多次测量取平均。
4. 测量长度时要测量接入电路的有效长度。
5. 电路连接要牢固，减小接触电阻。
6. 由于金属丝电阻较小，应采用电流表外接法（电压表分流影响小）。
7. 滑动变阻器开始时阻值应调至最大。

## 实验 4：测定金属丝的电阻率

### 一、实验目的

1. 掌握螺旋测微器和毫米刻度尺的使用方法。
2. 掌握电流表、电压表、滑动变阻器的使用方法及读数。
3. 会用伏安法测电阻，并能根据电阻定律 R = ρL/S 计算金属丝的电阻率。

### 二、实验器材

- 被测金属丝一根（长约 1 m，电阻约 5 Ω，建议使用镍铬合金丝或康铜丝）
- 直流电源一个（4-6 V，可用稳压电源或干电池组）
- 电流表一个（量程 0-0.6 A，内阻约 0.1 Ω）
- 电压表一个（量程 0-3 V，内阻约 3 kΩ）
- 滑动变阻器一个（最大电阻 20-50 Ω，额定电流 2 A）
- 开关一个
- 螺旋测微器一把
- 毫米刻度尺一把
- 导线若干

### 三、实验原理

根据电阻定律 R = ρL/S，只要测量出金属丝的长度 L 和直径 d（计算横截面积 S = πd²/4），并用伏安法测出金属丝的电阻 R，即可计算出金属丝的电阻率：

$$\rho = R \frac{S}{L} = \frac{R \pi d^2}{4L}$$

伏安法测电阻的原理：用电压表测电阻两端的电压 U，用电流表测通过电阻的电流 I，则 R = U/I。

**电路选择**：由于被测金属丝电阻较小（约 5 Ω），电压表内阻远大于金属丝电阻，电压表分流影响小，应采用**电流表外接法**（电流表接在电压表测量回路之外，电压表直接并联在金属丝两端）。

**滑动变阻器接法**：本实验需要测量多组 U、I 数据，应采用滑动变阻器分压式接法，使电压可以从零开始连续调节。

### 四、实验步骤

1. **测量直径**：用螺旋测微器在被测金属丝上的三个不同位置各测一次直径，求出平均值 d。
2. **测量长度**：将金属丝拉直，用毫米刻度尺测量接入电路的有效长度 L（即金属丝两端接线柱之间的长度），重复三次取平均值。
3. **连接电路**：按电路图连接电路。采用电流表外接法（电压表直接并联在金属丝两端），滑动变阻器分压式接法。
4. 检查电路连接无误后，将滑动变阻器滑片调到使接入电路电阻为零的位置（即电压为零处）。
5. 闭合开关，调节滑动变阻器，读出几组电流表、电压表的示数（建议 5-6 组，电流不要超过 0.5 A）。
6. 断开开关，整理器材。
7. 数据处理：
   - 用 U-I 图线的斜率求电阻 R。
   - 计算电阻率 ρ = Rπd²/(4L)。

### 五、实验现象与数据记录

**金属丝直径测量**

| 测量位置 | 1 | 2 | 3 | 平均值 d/mm |
| -------- | ---- | ---- | ---- | ----------- |
| 读数/mm | 0.402 | 0.400 | 0.398 | 0.400 |

**金属丝长度测量**：L = 1.000 m（三次测量平均值）

**电压、电流数据**

| 实验次数 | 电压 U/V | 电流 I/A | 电阻 R = U/I/Ω |
| -------- | -------- | -------- | --------------- |
| 1 | 0.50 | 0.105 | 4.76 |
| 2 | 1.00 | 0.205 | 4.88 |
| 3 | 1.50 | 0.300 | 5.00 |
| 4 | 2.00 | 0.395 | 5.06 |
| 5 | 2.50 | 0.490 | 5.10 |

**计算**：
- 由 U-I 图线斜率得 R ≈ 5.0 Ω。
- 横截面积 S = πd²/4 = 3.14 × 0.4² / 4 = 0.1256 mm² = 1.256×10⁻⁷ m²。
- 电阻率 ρ = RS/L = 5.0 × 1.256×10⁻⁷ / 1.000 = 6.28×10⁻⁷ Ω·m。

### 六、实验结果与结论

1. 测得金属丝的电阻约为 5.0 Ω。
2. 计算得到金属丝的电阻率约为 6.28×10⁻⁷ Ω·m，与镍铬合金的电阻率（约 1.0×10⁻⁶ Ω·m）量级相符。
3. 验证了电阻定律 R = ρL/S 的正确性。

### 七、误差分析

1. **测量误差**：螺旋测微器测量直径、毫米刻度尺测量长度都存在误差，影响电阻率计算。
2. **电流表外接法导致的系统误差**：电压表分流，电流表示数小于实际通过金属丝的电流，使测得的电阻 R 偏小，进而使 ρ 偏小。
3. **通电发热导致的误差**：通电后金属丝温度升高，电阻率增大，使测得的电阻偏大。改进措施：电流要小，通电时间要短，每次读数后立即断电。
4. **接触电阻**：金属丝与接线柱之间、接线柱与导线之间的接触电阻使测得的总电阻偏大。
5. **电压表内阻有限的影响**：电压表内阻有限，会分流，使 R 测量值偏小。
6. **金属丝直径不均匀**：金属丝不同位置直径不同，导致横截面积计算有偏差。改进措施：在不同位置多次测量取平均。
7. **长度测量误差**：接入电路的有效长度难以精确测量。

### 八、注意事项

1. 测量直径时应先测直径，再连接电路。螺旋测微器要在不同位置测量三次取平均。
2. 被测金属丝的电阻较小，应采用电流表外接法。
3. 开关 S 闭合前，滑动变阻器的滑片要调到使接入电路的电阻最大的位置（或分压为零的位置）。
4. 电流不宜太大（电流表用 0-0.6 A 量程），通电时间不宜太长，以免金属丝温度升高导致电阻率变化。
5. 闭合电路前必须检查电路连接是否正确，避免短路。
6. 实验完毕后要立即断开开关，整理器材。
7. U-I 图像处理数据时，让较多点落在直线上或均匀分布在直线两侧，偏离太远的点可舍去。

## 实验 5：描绘小灯泡的伏安特性曲线

### 一、实验目的

1. 掌握伏安法测电阻的方法，描绘小灯泡的伏安特性曲线。
2. 理解线性元件和非线性元件的区别，认识金属导体电阻随温度变化的特点。
3. 学会滑动变阻器分压式接法的应用。

### 二、实验器材

- 小灯泡一个（额定电压 2.5 V 或 3.8 V，额定电流 0.3 A）
- 直流电源一个（4-6 V，可用稳压电源或干电池组）
- 电流表一个（量程 0-0.6 A，内阻约 0.1 Ω）
- 电压表一个（量程 0-3 V，内阻约 3 kΩ）
- 滑动变阻器一个（最大电阻 20-50 Ω，额定电流 2 A）
- 开关一个
- 导线若干

### 三、实验原理

伏安特性曲线是用电压 U 为横坐标、电流 I 为纵坐标绘制的 I-U 图像。

- **线性元件**：电压与电流成正比，I-U 图像是一条过原点的直线，如金属导体（在温度不变时）。
- **非线性元件**：电压与电流不成正比，I-U 图像是曲线，如小灯泡。

小灯泡是非线性元件，因为灯丝（钨丝）的电阻随温度升高而增大。当电压增大时，灯丝温度升高，电阻增大，导致电流增长比电压增长慢，I-U 图像是曲线。

由于小灯泡电阻较小（约 1-10 Ω），远小于电压表内阻，应采用**电流表外接法**。

由于需要测量多组 U、I 数据（包括零点），应采用**滑动变阻器分压式接法**。

### 四、实验步骤

1. 按电路图连接电路：电流表外接法，滑动变阻器分压式接法。
2. 检查电路无误后，将滑动变阻器滑片调到使电压为零的位置（即分压输出为零）。
3. 闭合开关。
4. 调节滑动变阻器，使电压从零开始逐渐增大，每间隔 0.2 V 记录一组电压、电流数据，直到达到额定电压。
5. 多次测量，记录数据（建议 8-10 组）。
6. 断开开关，整理器材。
7. 在坐标纸上以电压 U 为横轴、电流 I 为纵轴，描点绘制 I-U 图像。

### 五、实验现象与数据记录

| 实验次数 | 电压 U/V | 电流 I/A | 备注 |
| -------- | -------- | -------- | ---- |
| 1 | 0.0 | 0.000 | 起始 |
| 2 | 0.2 | 0.080 | |
| 3 | 0.4 | 0.140 | |
| 4 | 0.6 | 0.190 | |
| 5 | 0.8 | 0.230 | |
| 6 | 1.2 | 0.290 | |
| 7 | 1.6 | 0.340 | |
| 8 | 2.0 | 0.380 | |
| 9 | 2.5 | 0.420 | 额定电压 |
| 10 | 3.0 | 0.450 | 超过额定 |

**I-U 图像特征**：
- 图像不是直线，而是向电压轴弯曲的曲线（即随电压增大，电流增长变慢）。
- 这表明灯丝电阻随温度（电压）升高而增大。
- 图像在原点附近斜率较大（电阻小），随电压增大斜率减小（电阻增大）。

### 六、实验结果与结论

1. 小灯泡的 I-U 图像是曲线，不是过原点的直线，说明小灯泡是非线性元件。
2. 图像的斜率随电压增大而减小，说明灯丝电阻随温度（电压）升高而增大。
3. 小灯泡的电阻随温度变化的原因：钨丝是金属导体，金属的电阻率随温度升高而增大，通电后灯丝温度升高，电阻增大。
4. 在小电压（如 0.2 V）时灯丝温度接近室温，电阻接近冷态电阻；在额定电压时电阻最大。

### 七、误差分析

1. **电压表分流**：电压表内阻有限，会分流，使电流表示数大于实际通过小灯泡的电流。由于小灯泡电阻较小（约 5 Ω），电压表内阻（约 3 kΩ）远大于小灯泡电阻，分流影响小。
2. **电流表分压**：电流表内阻不为零，会分压，使电压表示数大于小灯泡两端电压。由于采用外接法，电流表不与小灯泡串联，无此误差。
3. **温度滞后效应**：调节电压后，灯丝温度变化需要时间，若读数过快可能导致温度未稳定。改进措施：每次调节后稍等片刻再读数。
4. **读数误差**：电压表和电流表的读数存在主观误差，特别是小量程时。
5. **电源电压波动**：电源电压不稳定会影响测量。
6. **小灯泡额定电压超出**：电压超过额定值过多会烧坏灯泡，应在额定电压以下测量。
7. **接触电阻**：电路连接处接触电阻使电压分配不准确。

### 八、注意事项

1. 电路必须采用滑动变阻器分压式接法，以便电压从零开始连续调节。
2. 由于小灯泡电阻小，应采用电流表外接法（电压表分流影响小）。
3. 实验中电流不要超过小灯泡的额定电流（如 0.3 A），以免烧坏灯泡。
4. 每次调节电压后稍等片刻，让灯丝温度稳定后再读数。
5. 实验数据要从 U=0 开始，逐渐增大，不要重复测量（避免热效应滞后）。
6. 绘制 I-U 图像时，要使数据点均匀分布，必要时舍去偏离过大的点。
7. 实验完毕后立即断开开关，避免小灯泡长时间通电。
8. 闭合开关前滑动变阻器应处于分压为零的位置。

## 实验 6：练习使用多用电表

### 一、实验目的

1. 了解多用电表（万用表）的构造和基本原理。
2. 掌握多用电表测量直流电压、直流电流、交流电压、电阻的方法。
3. 学会正确选择量程、读数和操作规范，培养良好的实验习惯。

### 二、实验器材

- 多用电表（指针式，包含直流电压档、直流电流档、交流电压档、电阻档）
- 干电池 1 节或 2 节
- 直流电源一个
- 定值电阻若干（如 100 Ω、1 kΩ、10 kΩ）
- 小灯泡一个
- 开关、导线若干
- 螺丝刀（调节欧姆调零旋钮）

### 三、实验原理

多用电表是一种多用途、多量程的测量仪表，可以测量直流电压、直流电流、交流电压和电阻等。

**基本构造**：
- 表头：灵敏电流计，是测量的核心。
- 测量电路：通过转换开关切换不同的电路，将不同物理量转换为表头可测量的电流。
- 刻度盘：包含直流电流电压刻度、交流电压刻度、电阻刻度等多条刻度线。
- 调零旋钮：机械调零（指针归零）和欧姆调零（测电阻前调零）。

**测量原理**：
- 测电压：通过串联分压电阻扩大电压量程，电压表内阻越大越好。
- 测电流：通过并联分流电阻扩大量程。
- 测电阻：内部有电池，通过电阻与内部电阻串联，由电流大小反推外接电阻值。

**欧姆表原理**：
$$I = \frac{E}{R_\text{内} + R_x}$$

其中 E 为内部电池电动势，R内 为内部总电阻（中值电阻），Rx 为待测电阻。
- 当 Rx = 0（短接）时，I 最大，调零使指针满偏。
- 当 Rx → ∞ 时，I = 0，指针指在最左侧。
- 当 Rx = R内 时，I = Imax/2，指针指在中央（中值电阻）。

欧姆档的刻度是不均匀的，右侧稀疏，左侧密集。每次换档都要重新欧姆调零。

### 四、实验步骤

1. **观察多用电表**：认识表头、转换开关、刻度盘、机械调零旋钮、欧姆调零旋钮、红黑表笔及插孔。
2. **机械调零**：在使用前，若指针不在零刻度线上，用螺丝刀轻旋机械调零旋钮，使指针指在左侧零刻度。
3. **测量直流电压**：
   - 将转换开关旋至直流电压档（DCV），选择合适量程（如 2.5 V 档测干电池）。
   - 红表笔接电池正极，黑表笔接负极，使电流"红进黑出"。
   - 读数（用直流电压刻度线）。
   - 测量电源电压、定值电阻两端电压等。
4. **测量直流电流**：
   - 将转换开关旋至直流电流档（DCmA），选择合适量程。
   - 将多用电表串联接入电路，红表笔接高电位端。
   - 读数（用直流电流刻度线，与电压共用刻度）。
5. **测量电阻**：
   - 将转换开关旋至欧姆档（Ω），选择合适倍率（使指针指在中央附近，如 × 1、× 10、× 100、× 1 k）。
   - 进行欧姆调零：将红黑表笔短接，调节欧姆调零旋钮，使指针指在电阻刻度的零刻度（右侧）。
   - 用红黑表笔接触待测电阻两端，读数（用电阻刻度线）。
   - 实际值 = 读数 × 倍率。
   - 每次换档都要重新欧姆调零。
6. **测量完毕**：将转换开关旋至 OFF 档或交流电压最高档，取出表笔。

### 五、实验现象与数据记录

**测量项目记录表**

| 测量项目 | 量程 | 读数 | 测量值 |
| -------- | ---- | ---- | ------ |
| 干电池电压 | DC 2.5 V | 1.4（25 格中的 14 格） | 1.4 V |
| 直流电源电压 | DC 10 V | 6.0 | 6.0 V |
| 100 Ω 定值电阻 | × 10 档 | 10.0 | 100 Ω |
| 1 kΩ 定值电阻 | × 100 档 | 10.0 | 1000 Ω |
| 10 kΩ 定值电阻 | × 1 k 档 | 10.0 | 10 kΩ |
| 小灯泡电阻（不通电） | × 1 档 | 5.0 | 5 Ω |
| 电路中电流 | DC 0.6 A | 0.20 | 0.20 A |

### 六、实验结果与结论

1. 多用电表可以测量直流电压、直流电流、交流电压和电阻等多种物理量。
2. 测量电压、电流时，红表笔接高电位端，黑表笔接低电位端，电流"红进黑出"。
3. 测电阻时，每次换档都要重新欧姆调零。
4. 欧姆档的刻度不均匀，应在中央附近读数最准确。
5. 测量电阻时要将待测电阻与电源断开，不能带电测量。

### 七、误差分析

1. **读数误差**：刻度盘上多条刻度线，容易读错刻度；指针不在刻度线上的位置需要估读。
2. **量程选择不当**：量程过大使读数精度降低，量程过小可能损坏电表。改进措施：先选大量程试测，再换合适小量程。
3. **欧姆档电池电压不足**：电池电压下降时，欧姆调零不能使指针满偏，测量误差增大。改进措施：及时更换电池。
4. **测量电阻时未与电路断开**：如果带电测量电阻，会损坏电表。
5. **欧姆调零未做或不充分**：换档后未重新调零，导致测量值偏大或偏小。
6. **接触电阻**：表笔与被测电阻接触不良会增加测量误差。
7. **表笔极性接反**：测直流电压电流时极性接反，指针反向偏转，可能损坏表头。
8. **多用电表内阻影响**：测量电压时电表内阻有限，会改变电路状态；测电流时内阻会分压。

### 八、注意事项

1. 使用前必须进行机械调零，使指针指在零刻度。
2. 测量前要选好合适的档位和量程，从大档开始试测，再换小档。
3. 测量电压、电流时，电流方向"红进黑出"，红表笔接高电位。
4. 测量电阻时必须将待测电阻从电路中断开，不能带电测量。
5. 每次换欧姆档后必须重新欧姆调零。
6. 测电阻时两手不能同时接触两表笔的金属部分，避免人体电阻影响。
7. 测量大电阻时，注意人体感应和漏电的影响。
8. 测量完毕后，将转换开关旋至 OFF 档或交流电压最高档，以保护电表。
9. 长期不用时取出电池，避免电池漏液损坏电表。
10. 使用过程中不要剧烈震动或摔落，保护表头。
