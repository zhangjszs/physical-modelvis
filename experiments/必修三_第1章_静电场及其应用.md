## 实验 1：观察静电感应现象

### 一、实验目的

1. 观察导体在带电体附近出现的电荷重新分布现象，认识静电感应的实质。
2. 理解感应起电的原理，知道利用静电感应可以使导体带电的方法。
3. 进一步体会电荷守恒定律：电荷既不会创生也不会消灭，只能从一个物体转移到另一个物体，或从物体的一部分转移到另一部分。

### 二、实验器材

- 两个相同的金属导体 A 和 B（带绝缘支柱，相互接触时形成一体）
- 绝缘支架一对
- 带正电的带电体 C（可用有机玻璃棒或 PVC 棒与丝绸摩擦后获得）
- 两片金属箔片（用于贴在 A、B 下端作为验电器指示）
- 丝绸、毛皮若干（用于摩擦起电）
- 接地导线一根
- 绝缘手套（可选，便于手持绝缘棒）

### 三、实验原理

当一个带电体靠近导体时，由于电荷间的相互吸引或排斥，导体中的自由电荷会趋向或远离带电体。其结果是：导体靠近带电体的一端出现与带电体异种的电荷，远离带电体的一端出现与带电体同种的电荷。这种现象称为静电感应。利用静电感应使金属导体带电的过程叫感应起电。

电荷守恒定律：在静电感应过程中，导体两端出现的正负电荷总量相等，整体仍呈电中性。感应起电的实质是导体中自由电子的重新分布，并未创造新的电荷。

### 四、实验步骤

1. 将两个相同的金属导体 A 和 B 放在绝缘支架上，让它们彼此接触，组成一个整体。确保 A、B 起初不带电（可用手摸一下以接地放电）。
2. 在 A 和 B 下端各贴上一片金属箔片，观察箔片起初处于闭合状态。
3. 手握绝缘棒，将带正电的带电体 C 移近导体 A 一侧（不接触 A），观察 A、B 下端金属箔片的变化。
4. 在 C 仍然靠近 A 的情况下，手持绝缘柱将 A 和 B 分开（不要让 A、B 接触任何物体）。
5. 将带电体 C 移走，观察 A、B 下端金属箔片的状态。
6. 再让分开后的 A 和 B 重新接触，观察金属箔片的变化。
7. 用验电器或带电已知电荷种类的物体检验 A、B 各自所带电荷的种类。

### 五、实验现象与数据记录

| 操作步骤 | A 端金属箔 | B 端金属箔 | 现象分析 |
| -------- | ---------- | ---------- | -------- |
| C 靠近接触的 A、B | 张开 | 张开 | A、B 出现感应电荷 |
| C 未移走，分开 A、B | 仍张开 | 仍张开 | A、B 各自带电保留 |
| 移走 C 后 | 张开 | 张开 | A 带"-"电（近 C 端），B 带"+"电 |
| A、B 重新接触 | 闭合 | 闭合 | 正负电荷中和，恢复电中性 |

### 六、实验结果与结论

1. 当带电体 C 靠近 A、B 整体时，由于静电感应，A 端（近 C 端）带与 C 异种的电荷（负电荷），B 端（远 C 端）带与 C 同种的电荷（正电荷）。
2. 在 C 不移走的情况下分开 A、B，则 A、B 各自保留感应电荷；移走 C 后，A、B 仍然带等量异种电荷。
3. 让 A、B 重新接触时，正负电荷中和，导体恢复电中性。
4. 实验结论：感应起电不创造电荷，而是使导体中的电荷重新分布；电荷守恒。

### 七、误差分析

1. **绝缘不良导致的误差**：如果绝缘支柱或环境潮湿，电荷容易泄漏，使金属箔片闭合过快。改进措施：保持器材干燥，可使用红外灯烘烤或在干燥环境下进行。
2. **带电体 C 电荷量不足**：电荷量过少时感应现象不明显。改进措施：充分摩擦带电棒，并迅速实验。
3. **A、B 分开时操作失误**：若分开过程中 A 或 B 接触到其他物体，会导致电荷泄漏或转移。
4. **环境气流干扰**：金属箔片易受气流影响，导致误判。应在无风环境下进行。

### 八、注意事项

1. 实验环境必须保持干燥，相对湿度宜低于 50%。
2. 带电体 C 不要直接接触导体 A，否则变为接触起电而非感应起电。
3. 绝缘支柱的绝缘性能要好，否则感应电荷会通过支柱泄漏。
4. 手持绝缘棒操作时，不要让手指接触金属部分。
5. A、B 分开前 C 不可移走，否则感应电荷会立即中和。

## 实验 2：制作验电器并检验电荷

### 一、实验目的

1. 了解验电器的基本构造和工作原理。
2. 动手制作简易验电器，培养动手能力和科学探究兴趣。
3. 用验电器检测物体是否带电，判断电荷种类和相对数量。

### 二、实验器材

- 透明玻璃瓶一个（带绝缘瓶塞或橡胶塞）
- 金属导体棒一根（直径约 2 mm，长约 15 cm）
- 金属箔片两片（金箔或铝箔，长约 3 cm，宽约 5 mm）
- 金属球或金属圆盘一个（焊在导体棒上端）
- 绝缘瓶塞（橡胶塞或软木塞，中间钻孔以穿过导体棒）
- 带电体（有机玻璃棒与丝绸、PVC 棒与毛皮等）
- 导线、接地金属物若干

### 三、实验原理

验电器是检测物体是否带电的简单装置。其原理基于同种电荷相互排斥：当带电体接触验电器顶端的金属球时，电荷通过导体棒传到下端的金属箔片上，两片箔片带同种电荷而相互排斥，张开一定角度。箔片张角越大，说明所带电荷量越多；箔片是否张开可判断物体是否带电。

若要判断电荷种类，可先用已知电荷种类的带电体接触验电器使其带电，再用待测物体靠近（不接触）导体棒上端：若箔片张角变大，说明待测物体与验电器带同种电荷；若张角变小，说明带异种电荷。

### 四、实验步骤

1. 将金属导体棒穿过绝缘瓶塞，下端露出约 3 cm，上端焊接金属球。
2. 在导体棒下端挂上两片金属箔片，使其自然下垂并能自由开合。
3. 将组装好的导体棒插入玻璃瓶，用绝缘瓶塞密封瓶口。
4. 检查箔片起初处于闭合状态（若不闭合，调整悬挂位置）。
5. 用丝绸摩擦有机玻璃棒使其带正电，将带电棒接触验电器上端金属球，观察箔片变化。
6. 移开带电棒，观察箔片是否仍张开。
7. 用手触摸金属球（接地），观察箔片是否闭合。
8. 用毛皮摩擦 PVC 棒使其带负电，重复上述检验过程。
9. 检验电荷种类：先用带正电棒使验电器带正电，再用待测物体靠近（不接触）金属球，观察箔片张角变化。

### 五、实验现象与数据记录

| 操作 | 箔片状态 | 现象解释 |
| ---- | -------- | -------- |
| 起始 | 闭合 | 验电器不带电 |
| 带电棒接触金属球 | 张开 | 电荷传到箔片，同种电荷相斥 |
| 移开带电棒 | 仍张开 | 电荷保留在验电器内 |
| 手触摸金属球 | 闭合 | 电荷通过人体导入大地 |
| 待测同种电荷靠近 | 张角变大 | 同种电荷相互排斥增强 |
| 待测异种电荷靠近 | 张角变小 | 异种电荷感应，箔片电荷减少 |

### 六、实验结果与结论

1. 验电器通过箔片张开能够检测物体是否带电。
2. 箔片张角越大，说明带电体所带电荷量越多。
3. 通过感应作用可判断待测物体所带电荷的种类。
4. 验电器工作原理基于电荷间相互作用和电荷守恒。

### 七、误差分析

1. **绝缘不良**：瓶塞或导体棒绝缘性差会导致电荷泄漏，箔片迅速闭合。应使用橡胶塞或石蜡封堵。
2. **箔片重量和刚度不合适**：箔片过重则张角小、灵敏度低；过轻则易受气流干扰。
3. **环境湿度影响**：潮湿环境下空气导电性增强，电荷易散失。
4. **电荷量判断仅是相对的**：箔片张角与电荷量的关系并非严格线性，只能定性比较。

### 八、注意事项

1. 制作验电器时，导体棒必须与瓶塞紧密接触，避免电荷泄漏。
2. 金属箔片要薄而轻，悬挂要灵活，互相不粘连。
3. 实验环境保持干燥，避免潮湿。
4. 接触带电时动作要快，避免反复接触导致电荷重新分布。
5. 接地放电时，手指要确实接触金属部分。

## 实验 3：探究影响电荷间相互作用力的因素

### 一、实验目的

1. 通过定性实验探究电荷间相互作用力与电荷量、电荷间距离的关系。
2. 学习控制变量法在多变量物理规律探究中的应用。
3. 体会将微小力转化为可见偏角的"放大"思想，为库仑定律的学习奠定基础。

### 二、实验器材

- 带正电的球形导体 A（带绝缘支架，可用起电机使其带电）
- 通草球 B 一个（质量小，带丝线悬挂）
- 铁架台一个
- 丝线一根（长约 30 cm）
- 量角器一个
- 直尺一把
- 起电机或带电棒（用于改变 A、B 电量）
- 与 A 完全相同的不带电金属球一个（用于电量平分）

### 三、实验原理

带电小球 B 在带电体 A 的库仑力 F、重力 mg 和丝线拉力 T 作用下处于平衡状态。设丝线偏离竖直方向的角度为 θ，则有：

$$F = mg \tan\theta$$

当 θ 较小时，tan θ ≈ sin θ，且通过测量丝线悬挂点到 B 球的水平距离 x 与悬点到球的竖直距离 L 可得 tan θ = x/L。θ 越大，库仑力 F 越大。这样就把难以测量的微小静电力转化为便于观察和测量的偏角。

实验采用控制变量法：
- 保持 A、B 电荷量不变，改变 A、B 间距离 r，观察偏角变化，研究 F 与 r 的关系。
- 保持 A、B 间距离不变，改变 A、B 电荷量 q，观察偏角变化，研究 F 与 q 的关系。

### 四、实验步骤

1. 将铁架台放于水平桌面上，悬挂通草球 B 于铁架台横杆上，使 B 静止时丝线竖直。
2. 让球形导体 A 和通草球 B 带上同种电荷，并将 A 移至与 B 同一水平面上。
3. **探究 F 与距离 r 的关系**：保持 A、B 电荷量不变，将 A 从远处逐渐靠近 B，再逐渐远离 B，观察并记录丝线偏离竖直方向的角度 θ 与 A、B 间距离 r 的对应关系（取至少 5 组数据）。
4. **探究 F 与电荷量 q 的关系**：保持 A、B 间距离 r 不变，用与 A 完全相同的不带电金属球接触 A（使 A 的电量减半），观察并记录偏角变化。再用不带电球接触 B（使 B 的电量减半），再次记录偏角。
5. 多次重复，整理数据。

### 五、实验现象与数据记录

**表 1：探究 F 与距离 r 的关系（保持 q 不变）**

| 实验次数 | 距离 r/cm | 偏角 θ/° | tan θ | 结论 |
| -------- | --------- | -------- | ----- | ---- |
| 1 | 5 | 较大 | 较大 | r 越小，F 越大 |
| 2 | 10 | 中等 | 中等 | |
| 3 | 15 | 较小 | 较小 | |
| 4 | 20 | 更小 | 更小 | |
| 5 | 25 | 很小 | 很小 | |

**表 2：探究 F 与电荷量 q 的关系（保持 r 不变）**

| 实验次数 | A 的电量 | B 的电量 | 偏角 θ | 结论 |
| -------- | -------- | -------- | ------ | ---- |
| 1 | q | q | 较大 | q 越大，F 越大 |
| 2 | q/2 | q | 减小 | |
| 3 | q/2 | q/2 | 更小 | |

### 六、实验结果与结论

1. 当电荷量一定时，电荷间距离越小，丝线偏角越大，即静电力 F 越大；距离增大时 F 减小。
2. 当电荷间距离一定时，电荷量越大，丝线偏角越大，即静电力 F 越大；电量减小时 F 减小。
3. 定性结论：电荷间相互作用力随电荷量的增大而增大，随距离的增大而减小，为库仑定律 F = k·q₁q₂/r² 的定量研究做铺垫。

### 七、误差分析

1. **空气流动的影响**：通草球质量小，丝线偏角易受空气扰动影响，应在无风环境下实验。
2. **电荷量保持不变的困难**：空气中电荷会逐渐泄漏，导致电量改变。实验应快速进行，并使用绝缘良好的支架。
3. **距离测量的误差**：A、B 球心间的距离不易精确测量，特别是 B 球偏转后位置变化。
4. **电量的"减半"操作误差**：用相同金属球接触以平分电量的前提是两球完全相同，且接触充分，实际操作中可能存在不严格减半的情况。
5. **小角近似误差**：当 θ 较大时，F = mg tan θ 仍成立，但定性观察时易产生误判。
6. **其他带电体的干扰**：实验人员身上可能带有静电，会影响结果。

### 八、注意事项

1. 实验环境必须干燥，相对湿度宜在 50% 以下。
2. 通草球质量要小，丝线要细而轻，以提高灵敏度。
3. 操作要迅速，避免电荷泄漏。
4. A、B 球心连线应保持水平，便于测量距离 r。
5. 改变电量时，要使用与 A 完全相同的不带电金属球，确保电量减半。
6. 不要让 B 球偏角过大以致碰撞 A 球或丝线缠绕。

## 实验 4：库仑扭秤实验（模拟/演示）

### 一、实验目的

1. 了解库仑扭秤的构造和原理，体会"微小量放大"的科学思想。
2. 理解库仑通过控制变量法探究静电力与距离、电荷量定量关系的过程。
3. 认识库仑定律的实验基础，体会科学探究和类比推理在物理定律建立中的作用。

### 二、实验器材

- 库仑扭秤模型或动画演示（包含细银丝、带电金属小球 A 与 C、不带电平衡小球 B、刻度盘、指针、绝缘容器）
- 带电金属球 C（可固定，与 A 同种电荷）
- 与 A 完全相同的不带电金属小球若干（用于电量减半）
- 静电起电机（用于给金属球带电）
- 绝缘镊子、绝缘手套

### 三、实验原理

库仑扭秤的核心原理是：当带电小球 A 在水平面内受到另一个带电球 C 的静电力作用时，悬丝发生扭转。悬丝扭转的角度与外加力矩成正比，而力矩等于力 F 与力臂的乘积。在力臂一定时，悬丝扭转角度 θ 与静电力 F 成正比。这样就把微小的库仑力转化为较大的、可观察的角度测量。

实验采用控制变量法：
- 保持 A、C 电荷量 q 不变，改变 A、C 间距离 r，记录悬丝扭转角度，研究 F 与 r 的关系。
- 保持 A、C 间距离 r 不变，改变 A、C 电荷量（通过相同金属球接触平分电量），记录悬丝扭转角度，研究 F 与 q 的关系。

悬丝扭转角度与静电力满足：
$$F \cdot L = k_\text{悬} \cdot \theta$$
其中 L 为力臂，k悬 为悬丝的扭转系数，θ 为扭转角度。故 F ∝ θ。

### 四、实验步骤

1. **装置准备**：将库仑扭秤水平放置，调节底座螺钉使悬丝自然下垂，A 球处于平衡位置，记录指针在刻度盘上的初始位置（记为 0°）。
2. **给小球带电**：用起电机或摩擦方法使金属球 C 带电，再让 C 接触 A，使 A 与 C 带同种电荷。
3. **探究 F 与距离 r 的关系**：
   - 将 C 球插入容器并靠近 A，记录此时悬丝扭转角度 θ 和 A、C 间距离 r₁。
   - 改变 C 与 A 的距离（增大或减小），每次记录对应的扭转角度 θ 和距离 r。
   - 取至少 5 组数据。
4. **探究 F 与电荷量 q 的关系**：
   - 保持 A、C 间距离 r 不变。
   - 用与 A 完全相同的不带电金属球接触 A，使 A 的电量减半（变为 q/2），记录此时扭转角度。
   - 再次接触使 A 电量变为 q/4，记录扭转角度。
   - 同样对 C 进行电量减半操作，记录数据。
5. 整理数据，分析 F 与 r、F 与 q 的定量关系。

### 五、实验现象与数据记录

**表 1：F 与 r 的关系（q 不变）**

| 次数 | 距离 r/cm | 扭转角 θ/° | 1/r² (1/cm²) | F ∝ θ |
| ---- | --------- | ---------- | ------------ | ----- |
| 1 | 5.0 | 较大 | 0.040 | 较大 |
| 2 | 7.5 | 中等 | 0.0178 | 中等 |
| 3 | 10.0 | 较小 | 0.010 | 较小 |

**表 2：F 与 q 的关系（r 不变）**

| 次数 | q₁ | q₂ | q₁q₂ | 扭转角 θ |
| ---- | -- | -- | ---- | -------- |
| 1 | q | q | q² | θ₁ |
| 2 | q/2 | q | q²/2 | θ₁/2 |
| 3 | q/2 | q/2 | q²/4 | θ₁/4 |

### 六、实验结果与结论

1. 当电荷量不变时，悬丝扭转角度与距离的二次方成反比，即 F ∝ 1/r²。
2. 当距离不变时，悬丝扭转角度与两球电荷量的乘积成正比，即 F ∝ q₁q₂。
3. 综合：F = k·q₁q₂/r²，其中 k 为静电力常量，k = 9.0×10⁹ N·m²/C²。此即库仑定律。

### 七、误差分析

1. **悬丝扭转系数不稳定**：悬丝的扭转系数受温度、湿度影响，导致 F 与 θ 的比例关系变化。
2. **电荷泄漏**：空气中电荷会逐渐散失，特别是湿度大时，导致测量值偏小。
3. **电量减半操作误差**：两金属球接触时电量分配并非严格均等，且接触过程中可能损失部分电荷。
4. **距离测量误差**：A、C 球心间距难以精确测定，特别是金属球带电时电荷分布不均。
5. **零点漂移**：悬丝长时间扭转后可能出现塑性形变，导致零点漂移。
6. **空气扰动**：容器内空气流动会干扰 A 球的平衡。

### 八、注意事项

1. 实验必须在密封容器内进行，避免空气扰动。
2. 悬丝要选用弹性好、扭转变形小的材料（如细银丝或石英丝）。
3. 实验前要调节扭秤水平，并校准零点。
4. 实验应在干燥环境下快速进行，避免电荷泄漏。
5. 电量减半操作时，必须使用与 A 完全相同的金属球，且接触要充分。
6. 每次读数要等悬丝稳定后再进行。

## 实验 5：模拟电场线分布

### 一、实验目的

1. 通过实验形象地观察几种典型电场的电场线分布。
2. 理解电场线是人为引入的、用于描述电场的假想曲线，理解其特点。
3. 培养空间想象能力和物理模型建构能力。

### 二、实验器材

- 玻璃培养皿一个（圆形，直径约 15 cm）
- 蓖麻油或变压器油（适量，能浸没电极即可）
- 头发屑或奎宁粉、石棉粉（细小、轻的悬浮物）
- 电极两个：可以是两个小球形电极（模拟点电荷）、两个平行板电极（模拟匀强电场）、或一个球形电极和一个环形电极
- 高压静电起电机一台（感应起电机或范德格拉夫起电机）
- 导线若干
- 投影仪或摄像机（用于放大展示）

### 三、实验原理

电场线是为了形象地描述电场而引入的假想曲线。电场线上每一点的切线方向表示该点电场强度的方向；电场线的疏密表示电场的强弱。

实验原理：在玻璃培养皿中装入蓖麻油，油中均匀撒入头发屑等微小颗粒。当在油中建立静电场时，油中的微小颗粒在电场作用下极化并沿电场方向排列，形成可见的"电场线"图案。由于颗粒在油中受到电场力作用而定向排列，其排列方向与电场方向一致，从而直观显示电场线的分布。

### 四、实验步骤

1. 将玻璃培养皿水平放置在投影仪上。
2. 在培养皿中倒入适量蓖麻油，油层厚度约 3-5 mm。
3. 在油中均匀撒入头发屑（或奎宁粉），用玻璃棒轻轻搅匀，使颗粒悬浮于油中。
4. 将两个球形电极放入培养皿中，相距约 5 cm，用导线连接到静电起电机的两极。
5. 摇动起电机，给电极加上高压静电，观察油中头发屑的排列情况。
6. 改变电极配置：
   - 两个同种电荷的点电荷（两个电极接起电机同一极，对侧接大地或参考电极）。
   - 两个异种电荷的点电荷（分别接起电机两极）。
   - 平行板电极（模拟匀强电场）。
7. 每种配置下观察并记录头发屑的排列图案。
8. 实验完毕后关闭起电机，先用导线放电，再整理器材。

### 五、实验现象与数据记录

| 电极配置 | 头发屑排列图案特征 | 电场线特点 |
| -------- | ------------------ | ---------- |
| 单个正点电荷 | 由中心向外辐射状 | 由正电荷向外辐射 |
| 单个负点电荷 | 由外向中心汇聚 | 由外向负电荷汇聚 |
| 等量异种点电荷 | 从正电荷出发到负电荷，呈"心形"曲线 | 起于正电荷，止于负电荷 |
| 等量同种正点电荷 | 中垂线上电场线稀疏，呈排斥状 | 中点电场为零 |
| 平行板电容器 | 板间头发屑平行均匀排列 | 匀强电场，电场线平行等距 |

### 六、实验结果与结论

1. 头发屑沿电场方向排列，形成的图案即为电场线的形象化表示。
2. 电场线从正电荷出发，终止于负电荷（或无限远）。
3. 电场线不相交、不闭合。
4. 电场线的疏密反映电场的强弱：密处场强大，疏处场强小。
5. 等量同种点电荷连线中点电场为零（电场线分布稀疏）；等量异种点电荷中垂线上电场方向与连线平行。

### 七、误差分析

1. **颗粒分布不均**：头发屑撒布不均匀会导致图案局部紊乱，应充分搅匀。
2. **油层厚度影响**：油层过厚时颗粒下沉缓慢，电场作用不明显；过薄则颗粒易贴附器壁。
3. **电极形状影响**：实际电极不是理想点电荷，电场分布有一定偏差。
4. **电场强度不足**：起电机电压不够时颗粒排列不明显。
5. **颗粒重力影响**：颗粒较重时电场力不足以使其重新排列。
6. **气泡和杂质干扰**：油中气泡和杂质会扰乱电场分布。

### 八、注意事项

1. 实验应在干燥环境下进行，避免电荷泄漏。
2. 起电机电压较高，实验时人体不要接触电极和裸露导线。
3. 实验完毕后必须先放电再拆卸电极。
4. 头发屑要细而短，撒入量适中。
5. 蓖麻油可反复使用，实验后用玻璃片盖好培养皿。
6. 投影展示时，注意培养皿和投影仪之间的对焦。

## 实验 6：静电屏蔽演示

### 一、实验目的

1. 观察静电屏蔽现象，理解导体壳（金属网罩）对外部电场的屏蔽作用。
2. 了解静电平衡时导体内场强为零的特点。
3. 联系生活实际，理解避雷针、精密仪器金属外壳、手机信号屏蔽等应用原理。

### 二、实验器材

- 验电器一个
- 金属网罩一个（带绝缘底座，可罩住验电器）
- 带电体（有机玻璃棒与丝绸，或起电机）
- 绝缘支架
- 收音机或手机（用于演示电磁屏蔽对无线电信号的影响，作为拓展）
- 鸟笼式金属网罩一个（可放入小鸟，演示"鸟笼实验"）

### 三、实验原理

处于静电平衡状态的导体，其内部场强处处为零。当导体壳（无论是否接地）置于外电场中时，外电场使导体壳外表面感应出电荷，感应电荷在导体内部产生的附加电场与外电场完全抵消，使导体内部场强为零。这样导体壳就屏蔽了外电场对内部的影响，称为静电屏蔽。

导体壳有两种屏蔽方式：
1. **空腔导体不接地**：可以屏蔽外电场对空腔内部的影响，但空腔内有电荷时会在导体外表面感应出电荷，影响外部电场。
2. **空腔导体接地**：既可以屏蔽外电场对内部的影响，也可以屏蔽内部电荷对外部电场的影响，称为全屏蔽。

### 四、实验步骤

1. **演示外电场对验电器的影响**：
   - 将验电器放在桌面上（不罩金属网罩）。
   - 用带电棒靠近验电器顶端金属球（不接触），观察金属箔片张开。
   - 移开带电棒，观察箔片闭合。
2. **演示静电屏蔽**：
   - 将验电器放在绝缘底座上。
   - 用金属网罩罩住验电器（确保网罩与验电器绝缘）。
   - 用带电棒靠近金属网罩外侧（不接触），观察网罩内验电器箔片是否张开。
   - 移开带电棒，观察箔片状态。
3. **演示接地的金属网罩**：
   - 将金属网罩接地。
   - 在网罩内放一带电体，观察网罩外部验电器的反应（应无反应）。
4. **拓展演示：手机信号屏蔽**：
   - 将手机放入金属网罩内（不接地也可），拨打电话或发送信号。
   - 观察信号是否被屏蔽（手机无信号或信号减弱）。
5. 整理器材。

### 五、实验现象与数据记录

| 实验情景 | 验电器箔片状态 | 手机信号 | 现象分析 |
| -------- | -------------- | -------- | -------- |
| 无网罩，带电棒靠近验电器 | 张开 | - | 外电场使验电器感应带电 |
| 网罩内验电器，带电棒靠近网罩 | 不张开 | - | 网罩屏蔽外电场 |
| 接地网罩内放带电体，外部验电器 | 不张开 | - | 接地屏蔽内部电荷影响 |
| 手机在金属网罩内 | - | 无信号或极弱 | 电磁屏蔽 |

### 六、实验结果与结论

1. 不加金属网罩时，外电场使验电器出现感应电荷，箔片张开。
2. 罩上金属网罩后，外电场被屏蔽，验电器不受影响，箔片不张开。
3. 接地的金属网罩既能屏蔽外电场对内部的影响，也能屏蔽内部电荷对外部的影响。
4. 金属网罩也能屏蔽电磁波（手机信号），这是电磁屏蔽的应用。
5. 静电屏蔽的物理本质：静电平衡时导体内场强为零。

### 七、误差分析

1. **网罩不严密**：金属网孔过大或网罩有缺口，会减弱屏蔽效果。应使用网孔小的金属网。
2. **绝缘不良**：验电器与网罩之间绝缘不足，电荷会通过网罩泄漏，使验电器受影响。
3. **接地不良**：接地导线接触不好，无法有效导入大地，屏蔽效果减弱。
4. **环境潮湿**：空气中水汽使电荷容易散失，影响实验效果。
5. **带电体电量不足**：电量不够时现象不明显。
6. **手机屏蔽实验的局限**：手机工作频率为高频电磁波，金属网孔尺寸与波长相当时屏蔽效果减弱。

### 八、注意事项

1. 实验前确保验电器不带电，可用手摸一下金属球以接地放电。
2. 金属网罩要严密，网孔不宜过大。
3. 验电器与网罩之间要绝缘良好。
4. 实验环境保持干燥。
5. 演示接地屏蔽时，接地线要确实接入大地或大型金属物。
6. 手机屏蔽实验只做定性演示，不要长时间将手机置于金属网罩中以免损坏设备。

## 实验 7：研究空腔导体内表面的电荷

### 一、实验目的

1. 通过实验探究静电平衡时空腔导体内表面是否带电。
2. 验证法拉第圆筒实验的结论，加深对静电平衡特点的理解。
3. 体会"电荷只分布在导体外表面"的物理规律。

### 二、实验器材

- 法拉第圆筒（带绝缘底座的金属圆筒，上端开口）
- 验电器两个
- 带绝缘柄的金属小球（用于取电荷）
- 静电起电机或带电棒
- 导线若干
- 接地导线

### 三、实验原理

处于静电平衡状态的导体，电荷只分布在其外表面，内部场强处处为零。对于空腔导体（法拉第圆筒），如果空腔内没有带电体，则无论导体外部是否有电场，导体电荷只分布在外表面，内表面不带电。这一结论称为法拉第圆筒原理。

实验通过将带电小球与法拉第圆筒内壁接触，再用验电器检验小球是否带电，从而验证内壁不带电；而将小球与外壁接触后检验，则小球带电，证明外壁带电。

### 四、实验步骤

1. 将法拉第圆筒放在绝缘底座上，确保圆筒不带电（可接地放电）。
2. 用起电机或带电棒使法拉第圆筒带电（外表面带电）。
3. **检验内壁**：
   - 用带绝缘柄的小金属球与圆筒内壁接触。
   - 取出小球，将其与验电器金属球接触。
   - 观察验电器金属箔片是否张开。
4. **检验外壁**：
   - 用同一带绝缘柄小球与圆筒外壁接触。
   - 取出小球，将其与另一验电器金属球接触。
   - 观察验电器金属箔片是否张开。
5. 对比两组验电器的反应。
6. 整理数据。

### 五、实验现象与数据记录

| 接触位置 | 验电器箔片状态 | 结论 |
| -------- | -------------- | ---- |
| 圆筒内壁 | 不张开 | 内壁不带电 |
| 圆筒外壁 | 张开 | 外壁带电 |

### 六、实验结果与结论

1. 接触圆筒内壁的小球不带电，验电器不张开。
2. 接触圆筒外壁的小球带电，验电器张开。
3. 实验结论：静电平衡时，空腔导体（腔内无电荷时）电荷只分布在外表面，内表面不带电。
4. 此结论与法拉第圆筒实验的结果一致，是静电平衡的重要特点。

### 七、误差分析

1. **小球接触不充分**：小球与圆筒内壁接触不紧密，可能导致电荷未转移，影响判断。
2. **绝缘柄漏电**：绝缘柄绝缘性差时，小球上的电荷会通过绝缘柄泄漏。
3. **圆筒内壁残留电荷**：若圆筒内有残留电荷（如未充分接地放电），可能影响实验。
4. **环境影响**：潮湿环境下电荷易泄漏。
5. **取球过程中感应电荷影响**：从圆筒内取出小球时，可能因静电感应使小球带少量电荷。

### 八、注意事项

1. 圆筒必须先充分放电，确保不带电起始状态。
2. 绝缘柄要绝缘性能好，使用前用红外灯烘烤。
3. 小球与圆筒内壁接触要确实，可用绝缘柄轻按。
4. 取出小球时动作要快，避免感应电荷影响。
5. 实验环境保持干燥。
6. 重复实验前要先放电。

## 附:本章实验总结与对比

本章共包含 7 个实验，按性质可分为：

- **探究类**：探究影响电荷间相互作用力的因素
- **观察/演示类**：观察静电感应现象、制作验电器并检验电荷、库仑扭秤实验（模拟/演示）、模拟电场线分布、静电屏蔽演示、研究空腔导体内表面的电荷

**对比与要点**：从静电感应、库仑力到电场线分布，以演示与模拟为主，注意电荷相互作用与电场可视化方法的区别。
