## 实验 1：观察电容器的充电、放电现象

### 一、实验目的

1. 观察电容器充电和放电过程中电流、电压的变化规律。
2. 理解电容器的储能作用及其能量的转化过程。
3. 认识电容器充电和放电过程中电流、电压随时间变化的特点。

### 二、实验器材

- 直流电源一个（电压约 6-8 V，可用稳压电源或干电池组）
- 单刀双掷开关一个
- 平行板电容器或大容量电解电容器一个（容量 1000 μF 以上，便于观察）
- 直流电流表一个（量程 0-300 μA 或 0-0.6 A，最好用灵敏电流计）
- 直流电压表一个（量程 0-10 V）
- 定值电阻一个（阻值约 1-10 kΩ，限制充放电电流）
- 小灯泡一个（额定电压 6 V，便于直观显示充电电流）
- 导线若干
- 秒表（可选，用于记录时间）

### 三、实验原理

**充电过程**：当电容器两极板与电源两极相连时，在静电力的作用下，自由电子从电源正极流向电容器的负极板（同时电子从电容器正极板流向电源正极），使电容器两极板带上等量异种电荷。在此过程中：
- 电路中有充电电流，方向从电源正极流向电容器正极板。
- 充电开始时电流最大，随着极板上电荷量的增多，电容器两极板间电压增大，与电源电压之差减小，电流逐渐减小。
- 当电容器两极板间电压等于电源电压时，充电结束，电流为零。
- 充电过程中，电源的电能转化为电容器内的电场能。

**放电过程**：当充电后的电容器两极板通过导线（含电阻）相连时，电容器两极板上的电荷发生中和：
- 电路中有放电电流，方向从电容器正极板流出。
- 放电开始时电流最大，随着极板上电荷量减少，电流逐渐减小。
- 当电容器两极板上电荷完全中和时，放电结束，电流为零，电压为零。
- 放电过程中，电容器储存的电场能转化为电路中其他形式的能量（如热能、光能）。

电容器充电和放电都是短暂的过渡过程，电流方向相反。

### 四、实验步骤

1. 按电路图连接电路：电源、开关、电容器、电阻、电流表、电压表按设计连接。注意单刀双掷开关的中间接线柱接电容器一极，开关的"1"端接电源（用于充电），"2"端接电阻（用于放电）。
2. 闭合电路前，确认开关处于断开状态，电容器不带电（电压表示数为零）。
3. **观察充电过程**：
   - 将开关 S 接通"1"端，使电源向电容器充电。
   - 观察电流表读数变化、电压表读数变化和小灯泡亮度变化。
   - 记录充电过程中电流和电压随时间的变化（每隔 5 秒读数一次，记录约 30 秒）。
4. 充电完毕后（电流表示数为零），将开关断开，让电容器保持带电状态。
5. **观察放电过程**：
   - 将开关 S 接通"2"端，使电容器通过电阻放电。
   - 观察电流表、电压表读数和小灯泡亮度变化。
   - 记录放电过程中电流和电压随时间的变化。
6. 实验结束后，断开电源，整理器材。

### 五、实验现象与数据记录

**充电过程数据记录表**

| 时间 t/s | 电流 I/μA | 电压 U/V | 灯泡亮度 |
| -------- | --------- | -------- | -------- |
| 0 | 最大（如 200） | 0 | 最亮 |
| 5 | 减小 | 增大 | 变暗 |
| 10 | 继续减小 | 继续增大 | 更暗 |
| 20 | 较小 | 接近电源电压 | 微亮 |
| 30 | 接近 0 | 等于电源电压 | 熄灭 |

**放电过程数据记录表**

| 时间 t/s | 电流 I/μA | 电压 U/V | 灯泡亮度 |
| -------- | --------- | -------- | -------- |
| 0 | 最大（反向） | 等于电源电压 | 最亮 |
| 5 | 减小 | 减小 | 变暗 |
| 10 | 继续减小 | 继续减小 | 更暗 |
| 20 | 较小 | 较小 | 微亮 |
| 30 | 接近 0 | 接近 0 | 熄灭 |

### 六、实验结果与结论

1. 充电过程中，电流从最大值逐渐减小到零，电压从零逐渐增大到电源电压；充电结束时，电流为零，电压等于电源电压。
2. 放电过程中，电流从最大值逐渐减小到零，电压从电源电压逐渐减小到零；放电结束时，电流和电压均为零。
3. 充电过程中电源的电能转化为电容器内的电场能；放电过程中电容器内的电场能转化为电路中其他形式的能量。
4. 充电电流与放电电流方向相反。
5. 电容器具有"通交流、隔直流"的特性（充电和放电过程有电流，稳定后无电流）。

### 七、误差分析

1. **电流表内阻影响**：电流表内阻会改变电路的等效电阻，影响充电和放电时间常数。
2. **电压表内阻影响**：电压表内阻有限，会在充电完成后通过电压表缓慢放电，导致电压不能保持。
3. **电源内阻影响**：实际电源有内阻，导致充电结束时电压略低于电源电动势。
4. **电容器漏电**：实际电容器存在漏电，特别是电解电容器的漏电流较大，影响测量精度。
5. **读数时间误差**：手动读数存在时间误差，特别是电流变化快的初期。
6. **电表量程选择不当**：量程过大会使读数精度降低，过小可能损坏电表。
7. **小灯泡非线性电阻**：小灯泡的电阻随温度变化，影响放电规律。

### 八、注意事项

1. 电流表要选用小量程的灵敏电流计，以便观察电流的细微变化。
2. 要选择大容量的电容器（如 1000 μF 以上），使充放电过程时间较长，便于观察。
3. 实验要在干燥的环境中进行，避免电荷泄漏。
4. 放电时要在电路中串联一个电阻，以免放电电流过大烧坏电流表。
5. 使用电解电容器时，要注意正负极，不要接反。
6. 充电完成后应立即进行放电实验，避免长时间放置导致电荷泄漏。
7. 电流表和电压表要注意正负接线柱的连接，特别是放电时电流方向相反。

## 实验 2：用传感器观察电容器的放电过程

### 一、实验目的

1. 用电流传感器和电压传感器替代传统电表，实时记录电容器放电过程中电流和电压随时间的变化。
2. 通过 I-t 图像计算电容器放电过程中释放的电荷量，进一步计算电容器的电容。
3. 体会传感器在现代物理实验中的优势，理解图像法处理数据的思想。

### 二、实验器材

- 直流电源一个（电压约 6 V）
- 已知电容的电容器一个（如 470 μF 电解电容器）
- 单刀双掷开关一个
- 定值电阻一个（阻值约 1-10 kΩ）
- 电流传感器一个（量程 ± 100 mA 或更灵敏）
- 电压传感器一个（量程 0-10 V）
- 数据采集器一个
- 计算机一台（安装传感器配套软件）
- 导线若干

### 三、实验原理

传感器可以像传统电表一样测量电流和电压，但比电表灵敏度高，且能与计算机连接，实时记录数据并绘制 I-t 图像和 U-t 图像。

放电过程中，电容器两极板间的电压 U 和通过电路的电流 I 满足：

$$I = -\frac{dQ}{dt} = -C\frac{dU}{dt}$$

通过 I-t 图像，图线与时间轴所围成的面积表示放电过程中通过电路的电荷量：

$$Q = \int I \, dt$$

再由电容的定义式 C = Q/U（U 为放电起始时电容器两端的电压），可计算出电容器的电容 C。

由于放电电流随时间按指数规律衰减，I-t 图像为一条衰减曲线。

### 四、实验步骤

1. 按电路图连接电路：电源、开关、电容器、电阻、传感器按设计连接。
2. 启动数据采集器和计算机软件，设置采样频率（建议 10-100 Hz）。
3. 将开关接通"1"端，使电源对电容器充电，直到电压表示数稳定在电源电压（约 6 V）。
4. 启动数据采集（点击"开始记录"），立即将开关从"1"端扳到"2"端，使电容器通过电阻放电。
5. 让传感器持续记录数据，直到电流接近零为止。
6. 停止数据采集，保存数据。
7. 在计算机软件中调出 I-t 图像和 U-t 图像。
8. 用软件的功能计算 I-t 曲线下方的面积，得到放电电荷量 Q。
9. 由 C = Q/U 计算电容，与电容器标称值比较。

### 五、实验现象与数据记录

**I-t 图像特征**：
- 起始时刻电流最大（如 I₀ = 6 mA）。
- 电流随时间按指数规律衰减，逐渐接近零。
- I-t 曲线与时间轴所围面积为放电电荷量 Q。

**U-t 图像特征**：
- 起始时刻电压最大（等于电源电压，约 6 V）。
- 电压随时间按指数规律衰减，逐渐接近零。

**数据示例**（已知电容 C = 470 μF，电源电压 U = 6 V）：

| 时间 t/s | 电流 I/mA | 电压 U/V |
| -------- | --------- | -------- |
| 0 | 6.00 | 6.00 |
| 0.5 | 3.60 | 3.60 |
| 1.0 | 2.16 | 2.16 |
| 1.5 | 1.30 | 1.30 |
| 2.0 | 0.78 | 0.78 |
| 3.0 | 0.28 | 0.28 |
| 5.0 | 0.04 | 0.04 |

**计算**：通过 I-t 图像计算曲线下面积，得 Q ≈ 2.82×10⁻³ C
电容 C = Q/U = 2.82×10⁻³ / 6 ≈ 470 μF（与标称值一致）。

### 六、实验结果与结论

1. 放电过程中，电流和电压都随时间按指数规律衰减。
2. I-t 曲线下方的面积等于电容器放电过程中释放的电荷量 Q。
3. 由 C = Q/U 可计算出电容器的电容，结果与电容器标称值基本一致。
4. 传感器法比传统电表法更精确、更直观，能更好地展现电容器放电规律。

### 七、误差分析

1. **传感器精度限制**：传感器本身有一定的测量误差，特别是小电流时精度降低。
2. **采样频率的影响**：采样频率过低会丢失初期电流变化信息，过高会增加数据噪声。
3. **电容器漏电**：实际电容器存在漏电，导致放电不完全符合理论模型。
4. **电阻值误差**：定值电阻的实际阻值与标称值有偏差，影响放电时间常数。
5. **积分面积计算误差**：数值积分时采用梯形法或矩形法近似，存在一定误差。
6. **开关切换时间影响**：从充电切换到放电的过程中可能有短暂的电压变化。
7. **接触电阻影响**：开关和接线处的接触电阻会改变电路总电阻。

### 八、注意事项

1. 实验前应充分充电，确保电容器两极板电压稳定后再开始放电。
2. 采样频率要合适，建议 10-100 Hz，既能捕捉细节又不过多占用数据存储。
3. 放电时开关切换要迅速，避免中间过程的电流变化。
4. 电解电容器要注意正负极。
5. 计算面积时可使用软件的"积分"功能，提高精度。
6. 实验数据与理论值比较时，要考虑电容器标称值的允许偏差（通常 ± 20%）。

## 实验 3：探究影响平行板电容器电容大小的因素

### 一、实验目的

1. 通过控制变量法探究平行板电容器的电容与极板正对面积 S、极板间距离 d、极板间电介质的关系。
2. 理解平行板电容器电容的决定式 C = εrS/(4πkd)。
3. 体会控制变量法和静电计测量微小电势差变化的方法。

### 二、实验器材

- 平行板电容器一套（两块圆形金属板，直径约 20 cm，板间距可调）
- 静电计一个（用于测量电容器两极板间电压）
- 静电起电机或起电棒（用于使电容器带电）
- 绝缘支架（支撑电容器和静电计）
- 不同厚度的电介质板（如玻璃板、云母板、硬纸板等，面积大于电容器极板）
- 螺旋测微器或游标卡尺（测量板间距和介质厚度）
- 导线若干
- 接地导线

### 三、实验原理

平行板电容器的电容 C 与极板正对面积 S、极板间距离 d、极板间电介质的相对介电常数 εr 有关，关系式为：

$$C = \frac{\varepsilon_r S}{4\pi k d}$$

其中 k 为静电力常量。

实验中，电容器所带电荷量 Q 保持不变（充电后断开电源）。由 C = Q/U 知，电容 C 与电压 U 成反比。当改变影响 C 的因素时，U 随之变化。静电计可测量 U 的变化（指针偏角越大，电压越高，说明电容越小）。

实验采用控制变量法：
- 保持 Q、d、εr 不变，改变 S，观察 U 变化，研究 C 与 S 的关系。
- 保持 Q、S、εr 不变，改变 d，观察 U 变化，研究 C 与 d 的关系。
- 保持 Q、S、d 不变，插入电介质（改变 εr），观察 U 变化，研究 C 与 εr 的关系。

### 四、实验步骤

1. 将平行板电容器安装在绝缘支架上，板间距约 1 cm，正对面积约 314 cm²（直径 20 cm）。
2. 用导线将电容器两极板与静电计连接。
3. 用起电机或带电棒给电容器充电，使静电计指针偏转一定角度（约 30°-45°）。
4. 充电后立即断开电源（让电容器电荷量 Q 保持不变）。
5. **探究电容 C 与正对面积 S 的关系**：
   - 保持板间距 d 不变，将一块极板沿平行方向逐渐错开，减小正对面积 S。
   - 观察静电计指针偏角变化。
6. **探究电容 C 与板间距 d 的关系**：
   - 恢复极板完全正对（S 最大）。
   - 保持正对面积 S 不变，减小或增大板间距 d。
   - 观察静电计指针偏角变化。
7. **探究电容 C 与电介质的关系**：
   - 保持正对面积 S 和板间距 d 不变。
   - 将电介质板（如玻璃板）插入两极板之间。
   - 观察静电计指针偏角变化。
   - 取出电介质，再插入另一种电介质（如云母板），观察变化。
8. 整理器材。

### 五、实验现象与数据记录

| 实验操作 | 静电计指针偏角变化 | 电压 U 变化 | 电容 C 变化 |
| -------- | ------------------ | ----------- | ----------- |
| 减小正对面积 S | 增大 | 增大 | 减小 |
| 增大正对面积 S | 减小 | 减小 | 增大 |
| 减小板间距 d | 减小 | 减小 | 增大 |
| 增大板间距 d | 增大 | 增大 | 减小 |
| 插入电介质（玻璃） | 减小 | 减小 | 增大 |
| 取出电介质 | 恢复 | 恢复 | 恢复 |

### 六、实验结果与结论

1. 当正对面积 S 减小时，电压 U 增大，说明电容 C 减小。即电容 C 与正对面积 S 成正比：C ∝ S。
2. 当板间距 d 增大时，电压 U 增大，说明电容 C 减小。即电容 C 与板间距 d 成反比：C ∝ 1/d。
3. 当插入电介质时，电压 U 减小，说明电容 C 增大。即电容 C 与电介质的相对介电常数 εr 成正比：C ∝ εr。
4. 综合得到平行板电容器电容的决定式：C = εrS/(4πkd)。

### 七、误差分析

1. **电荷泄漏**：实验过程中电荷会通过空气和绝缘支架缓慢泄漏，导致 Q 不能严格保持不变。改进措施：实验快速进行，环境干燥。
2. **静电计的电容影响**：静电计本身也有电容，会与电容器并联，影响测量结果。静电计的电容远小于电容器电容时影响较小。
3. **边缘效应**：实际平行板电容器存在边缘效应，电场并非完全局限于板间，影响电容值。
4. **极板不严格平行**：极板安装不平行时，板间距不均匀，影响电容。
5. **电介质未完全充满板间**：电介质面积小于极板面积或厚度小于板间距时，影响电容变化。
6. **环境湿度影响**：潮湿环境下电荷泄漏加剧。
7. **读数误差**：静电计指针偏角的读取存在主观误差。

### 八、注意事项

1. 实验前应充分充电，充电后立即断开电源，保持电荷量不变。
2. 改变 S 时，极板要平行移动，避免改变板间距 d。
3. 改变 d 时，两极板要保持平行，正对面积不变。
4. 插入电介质时，电介质板面积应不小于极板面积，厚度应等于或略小于板间距。
5. 静电计的初始零点要校准，避免读数偏差。
6. 实验环境要干燥，避免电荷泄漏。
7. 起电机电压较高，操作时注意安全，避免电击。

## 实验 4：带电粒子在电场中的加速与偏转（演示）

### 一、实验目的

1. 通过实验观察带电粒子在电场中的加速和偏转现象。
2. 理解带电粒子在匀强电场中运动规律，为示波管、电子束管等器件的工作原理打下基础。
3. 培养建立物理模型和应用力学知识解决电学问题的能力。

### 二、实验器材

- 阴极射线管（演示电子束的加速和偏转）
- 高压直流电源（加速电压 0-3000 V 可调）
- 偏转电压电源（0-100 V 可调）
- 荧光屏（已附在阴极射线管末端）
- 磁体（用于对比磁偏转，可选）
- 导线若干
- 安全防护罩

### 三、实验原理

**带电粒子的加速**：在加速电场中，带电粒子在电场力作用下做匀加速直线运动。设加速电压为 U₁，粒子的初速度为零，由动能定理：

$$qU_1 = \frac{1}{2}mv^2$$

粒子获得的速度：v = √(2qU₁/m)

**带电粒子的偏转**：粒子以速度 v 进入偏转电场（极板长 L，板间距 d，偏转电压 U₂）后，在垂直于初速度方向上受电场力作用做类平抛运动：

- 水平方向（沿初速度方向）：匀速运动，t = L/v
- 竖直方向（垂直初速度方向）：匀加速运动，加速度 a = qU₂/(md)
- 离开偏转电场时的偏移量：y = (1/2)at² = qU₂L²/(2mdv²) = U₂L²/(4dU₁)
- 偏转角正切：tan φ = vy/vx = qU₂L/(mv²d) = U₂L/(2dU₁)

实际装置中，偏转电压 U₂ 控制电子束的偏移，使电子束打在荧光屏上的不同位置。

### 四、实验步骤

1. 将阴极射线管水平放置在支架上，安装好防护罩。
2. 连接加速电压电源：阴极接负极，阳极接正极。
3. 连接偏转电压电源：偏转板两极分别接偏转电源的正负极。
4. **演示电子束的加速**：
   - 接通加速电压电源，逐渐增大加速电压 U₁（从 0 到 2000 V）。
   - 观察荧光屏上的亮斑亮度变化（电压越高，电子速度越大，亮斑越亮）。
5. **演示电子束的偏转**：
   - 保持加速电压 U₁ 不变（如 1500 V）。
   - 接通偏转电压电源，从 0 开始逐渐增大偏转电压 U₂。
   - 观察荧光屏上亮斑的位置变化（亮斑向上或向下偏移）。
   - 反向改变偏转电压极性，观察亮斑向相反方向偏移。
6. **研究偏转量与偏转电压的关系**：
   - 记录不同偏转电压 U₂ 下亮斑的偏移量 y。
   - 验证 y ∝ U₂。
7. **研究偏转量与加速电压的关系**：
   - 保持偏转电压 U₂ 不变。
   - 改变加速电压 U₁，观察亮斑偏移量的变化。
   - 验证 y ∝ 1/U₁。
8. 实验结束后，先关闭电源，再整理器材。

### 五、实验现象与数据记录

**表 1：偏转电压 U₂ 与偏移量 y 的关系（U₁ = 1500 V 不变）**

| 偏转电压 U₂/V | 亮斑偏移量 y/cm |
| -------------- | ---------------- |
| 0 | 0 |
| 20 | 1.0 |
| 40 | 2.0 |
| 60 | 3.0 |
| 80 | 4.0 |

**表 2：加速电压 U₁ 与偏移量 y 的关系（U₂ = 60 V 不变）**

| 加速电压 U₁/V | 亮斑偏移量 y/cm |
| -------------- | ---------------- |
| 1000 | 4.5 |
| 1500 | 3.0 |
| 2000 | 2.25 |
| 2500 | 1.8 |

### 六、实验结果与结论

1. 带电粒子在加速电场中获得动能，加速电压越大，粒子速度越大。
2. 带电粒子在偏转电场中做类平抛运动，偏转量与偏转电压 U₂ 成正比，与加速电压 U₁ 成反比。
3. 偏转量公式：y = U₂L²/(4dU₁)，与实验数据基本吻合。
4. 实验原理应用于示波管、显像管、电子束曝光等设备。

### 七、误差分析

1. **加速电压不稳定**：电源电压波动导致加速电压变化，影响电子速度。
2. **偏转板边缘效应**：实际偏转电场并非严格匀强，板边缘电场发散，影响偏转精度。
3. **荧光屏读数误差**：亮斑有一定大小，读数存在主观误差。
4. **地磁场影响**：地磁场会使电子束产生微弱偏转，影响测量。
5. **电子初速度不为零**：实际电子从阴极发射时有一定初速度分布，影响加速效果。
6. **电子之间的排斥**：电子束中电子之间存在排斥力，导致束流发散。
7. **偏转板安装误差**：偏转板不严格平行或长度不准确，影响测量。

### 八、注意事项

1. 实验装置使用高压电源，必须注意安全，操作时不要接触裸露部分。
2. 加速电压应逐渐增大，避免突然加压损坏设备。
3. 偏转电压不宜过大，以免电子打在偏转板上无法到达荧光屏。
4. 实验环境应保持暗光，便于观察荧光屏上的亮斑。
5. 实验结束后应先关闭高压电源，再关闭其他电源。
6. 阴极射线管为玻璃制品，应避免碰撞。
7. 长时间工作后管内可能发热，应间歇使用。
