## 实验 1：探究碰撞中的不变量

### 一、实验目的

1. 通过实验探究两个物体碰撞前后哪些物理量保持不变。
2. 经历「猜想—实验—分析—结论」的科学探究过程。
3. 体会动量概念的形成过程，理解动量守恒的条件。

### 二、实验器材

- 长度相同的细线（2 根，约 30 cm）
- 完全相同的钢球（2 个，质量相等，直径约 2 cm）
- 质量较大的钢球（1 个，直径与上面相同）
- 质量较小的钢球（1 个，直径与上面相同）
- 铁架台及铁夹
- 刻度尺、量角器
- 复写纸、白纸（可选）

### 三、实验原理

碰撞过程中两物体之间存在相互作用力，作用时间很短。猜想碰撞前后可能保持不变的物理量有：
- 两物体的速度之和 $v_1+v_2$
- 两物体的动能之和 $\frac{1}{2}m_1v_1^2+\frac{1}{2}m_2v_2^2$
- 两物体的质量与速度乘积之和 $m_1v_1+m_2v_2$

通过测量碰撞前后两物体的速度，分别计算上述各量，比较碰撞前后是否相等，从而找出在碰撞中保持不变的物理量。两球均做单摆运动，根据机械能守恒 $v=\sqrt{2gh}$，由球摆起的高度可求出碰撞前后的速度大小；摆球到达的最大高度可通过测量摆角（或水平位移）来确定。

### 四、实验步骤

1. 将两根等长的细线一端固定在铁架台的横杆上，另一端分别拴住两个完全相同的钢球 A、B，使两球并排静止悬挂。
2. 把 A 球拉起一定角度（如 30°），由静止释放，观察它与静止的 B 球碰撞后的现象，记录两球摆起的高度。
3. 用质量较大的 C 球替换 A 球，重复步骤 2，比较碰撞前后两球摆起的高度。
4. 用质量较小的 D 球作为入射球，重复步骤 2。
5. 测量每种情况下碰撞前后两球摆起的高度，分别计算 $v_1+v_2$、$\frac{1}{2}m_1v_1^2+\frac{1}{2}m_2v_2^2$、$m_1v_1+m_2v_2$，比较碰撞前后是否相等。

### 五、实验现象与数据记录

**实验现象：**
- 用 A 球（与 B 球等质量）碰撞静止的 B 球时，碰撞后 A 球停止，B 球以与 A 球碰撞前相近的速度摆起，摆到与 A 球被释放时几乎相同的高度。
- 用质量较大的 C 球碰撞静止的 B 球时，碰撞后两球都向前运动，但 B 球摆起的高度比 C 球释放时的高度还高。
- 用质量较小的 D 球碰撞静止的 B 球时，碰撞后 D 球被反弹回来，B 球向前摆动。

**数据记录表格示例：**

| 实验次数 | 入射球质量 $m_1$/kg | 被碰球质量 $m_2$/kg | 碰前入射球摆角 | 碰后 $m_1$ 摆角 | 碰后 $m_2$ 摆角 | $m_1v_1+m_2v_2$（碰前） | $m_1v_1'+m_2v_2'$（碰后） |
|---|---|---|---|---|---|---|---|
| 1 | $m$ | $m$ | 30° | 0° | 约 30° | | |
| 2 | $2m$ | $m$ | 30° | | | | |
| 3 | $m$ | $2m$ | 30° | | | | |

### 六、实验结果与结论

数据分析表明：
- 碰撞前后两球的速度之和一般**不相等**；
- 碰撞前后两球的动能之和一般**不相等**（碰撞中有能量损失）；
- 碰撞前后两球的质量与速度乘积之和（即 $m_1v_1+m_2v_2$）**基本保持不变**。

**结论：** 在一维碰撞中，系统碰撞前后的总动量（$mv$ 之和）保持不变，即动量守恒。

### 七、误差分析

1. **系统误差：**
   - 空气阻力及悬线摩擦使摆球机械能损失，导致由摆高反推的速度小于真实速度。
   - 单摆模型近似（摆角较大时不再是简谐运动）使 $v=\sqrt{2gh}$ 的计算存在偏差。
2. **偶然误差：**
   - 摆角读数不准确。
   - 两球碰撞时并非严格的正碰（一维碰撞），可能存在侧向运动。
   - 碰撞时部分能量转化为内能、声能，使机械能不守恒（这本身是客观现象，但会影响速度测量的关联分析）。

### 八、注意事项

1. 悬点必须固定牢靠，两细线等长且平行。
2. 释放入射球时不要施加初速度，应从静止释放。
3. 摆角不宜过大（小于 30° 较好），避免摆球做圆锥摆动。
4. 两球应在最低点（平衡位置）发生碰撞，保证是正碰。
5. 多次重复实验，取平均值以减小偶然误差。

## 实验 2：观察两球的碰撞

### 一、实验目的

1. 直观感受弹性碰撞与非弹性碰撞的差异。
2. 观察不同质量比的两球碰撞时速度变化规律。
3. 加深对动量守恒与能量守恒关系的理解。

### 二、实验器材

- 物理支架（铁架台）
- 等长细线 2 根（约 40 cm）
- 钢球（约 50 g，2 个，质量相等，直径相同）
- 质量不等的小球 2 个（一个较重、一个较轻，与钢球直径相同）
- 橡皮泥或凡士林（用于做完全非弹性碰撞）
- 刻度尺、量角器

### 三、实验原理

两等质量钢球碰撞时，碰撞前后动能基本不变，可视为弹性碰撞；若在两球接触面涂橡皮泥或凡士林，碰撞后两球粘在一起运动，则为完全非弹性碰撞，动能损失最大。比较两类碰撞中两球碰撞前后的运动状态，可定性认识碰撞的类型与能量变化规律。

### 四、实验步骤

1. 将两等长细线悬挂在铁架台横杆上，下端各拴一个等质量的钢球 A、B，使两球在静止时刚好接触。
2. 拉起 A 球到一定高度后释放，使其与静止的 B 球发生正碰，观察并记录碰撞后两球的运动情况。
3. 在 A、B 两球碰撞面涂少量橡皮泥，重复步骤 2，观察碰撞后两球是否粘在一起运动。
4. 换用质量不等的小球，重复步骤 2，观察质量不同时碰撞后两球的运动情况。

### 五、实验现象与数据记录

| 碰撞类型 | 入射球质量 | 被碰球质量 | 碰撞后 A 球状态 | 碰撞后 B 球状态 |
|---|---|---|---|---|
| 弹性碰撞（等质量钢球） | $m$ | $m$ | 几乎停止 | 摆起，达到 A 球释放时的高度 |
| 完全非弹性碰撞（涂橡皮泥） | $m$ | $m$ | 两球粘在一起，共同运动 | 同左 |
| 弹性碰撞（质量不等） | $2m$ | $m$ | 继续向前运动，速度减小 | 摆起，速度较大 |

### 六、实验结果与结论

- 等质量弹性碰撞时，速度发生「交换」，类似牛顿摆现象。
- 完全非弹性碰撞时，两球粘合共同运动，机械能损失最大。
- 质量不等的弹性碰撞中，入射球碰撞后仍向前运动但速度减小，被碰球获得较大速度。

### 七、误差分析

1. 空气阻力使摆起的最大高度小于理论值。
2. 碰撞时并非完全弹性，部分动能转化为内能。
3. 涂橡皮泥后两球未必完全粘合，可能导致碰撞不完全。

### 八、注意事项

1. 两细线必须严格等长且平行，悬挂点固定。
2. 两球应在平衡位置（最低点）发生正碰。
3. 释放入射球时不能施加初速度。
4. 涂橡皮泥量适中，避免影响碰撞的对称性。

## 实验 3：实验：验证动量守恒定律 「学生必做实验」

### 一、实验目的

1. 明确验证动量守恒定律的基本思路与方法。
2. 在一维碰撞中验证系统碰撞前后总动量守恒。
3. 掌握实验数据的处理方法，了解误差来源。

### 二、实验器材（含规格）

三种测量方案器材如下：

- **方案一（气垫导轨滑块）：** 气垫导轨（含气源）、数字计时器（含 2 个光电门）、天平（精度 0.1 g）、滑块 2 个（带挡光片）、弹性碰撞架、撞针与橡皮泥、轻质弹簧、细线、重物（用于改变滑块质量）、挡光片（宽度 $d$ 已知，通常 1.00 cm）。
- **方案二（斜槽末端小球）：** 斜槽轨道（固定在铁架台上）、入射小球（质量较大，$m_1$）、被碰小球（质量较小，$m_2$，与入射球直径相同）、铅垂线、复写纸与白纸、天平（精度 0.1 g）、刻度尺、圆规、三角板、图钉。
- **方案三（等长摆球）：** 铁架台及铁夹、等长细线 2 根（约 1 m）、两个等大但质量不同的金属球、量角器、刻度尺、天平。

### 三、实验原理（含LaTeX公式推导）

在一维碰撞中，若系统所受合外力为零（或内力远大于外力），则系统动量守恒。设两物体质量分别为 $m_1$、$m_2$，碰撞前速度分别为 $v_1$、$v_2$，碰撞后速度分别为 $v_1'$、$v_2'$，则

$$m_1v_1+m_2v_2=m_1v_1'+m_2v_2'$$

实验中需测出两物体的质量及碰撞前后的速度。由于碰撞时间极短，内力远大于外力，系统近似满足动量守恒条件。教材给出三种测量方案，可根据器材条件选用。

### 四、实验步骤（编号到每步操作）

#### 方案一：气垫导轨上滑块碰撞

1. **安装与调平：** 将气垫导轨放在水平桌面上，接通气源使导轨通气。调节导轨底脚螺丝，使滑块在导轨上静止（或轻轻推动后匀速运动），保证导轨水平。
2. **测量质量：** 用天平分别测出两滑块（含挡光片）的质量 $m_1$、$m_2$。
3. **安装光电门：** 将两光电门固定在导轨上合适位置，连接数字计时器，设置计时模式为「挡光计时」。
4. **碰撞情境 1（弹性碰撞，碰后分开）：** 在两滑块相碰端装上弹性碰撞架，让滑块 1 以一定速度通过光电门 1 后与静止的滑块 2 相碰，分别记录碰撞前后两滑块通过两光电门的挡光时间 $\Delta t_1$、$\Delta t_1'$、$\Delta t_2'$。
5. **碰撞情境 2（完全非弹性碰撞，碰后粘连）：** 在两滑块相碰端分别装上撞针和橡皮泥，使碰撞后两滑块粘合。重复上述测量。
6. **碰撞情境 3（两静止滑块反向弹开）：** 在两滑块间放置被压缩的轻质弹簧并用细线固定，烧断细线后两滑块由静止向相反方向运动，记录两滑块分别通过两光电门的挡光时间。
7. 改变滑块质量或初速度，重复实验多次，将数据记入表格。

#### 方案二：斜槽末端小球碰撞

1. **测质量：** 用天平测出入射小球和被碰小球的质量 $m_1$、$m_2$，并选定质量较大的为入射小球。
2. **安装装置：** 将斜槽固定在铁架台上，调整斜槽末端切线水平（用水平仪或小球在水平段静止法检验）。
3. **铺纸定位：** 在地面上铺白纸（在下），复写纸（在上），用图钉固定。在斜槽正下方挂铅垂线，记下铅垂线尖端所指的位置 $O$（即斜槽末端在地面上的投影点）。
4. **单独释放入射球找落点 P：** 不放被碰小球，让入射小球从斜槽上某一固定高度由静止释放，重复 10 次。用圆规画尽量小的圆把所有落点圈住，圆心即落点平均位置 $P$。
5. **碰撞找落点 M、N：** 在斜槽末端放上被碰小球，让入射小球从同一高度由静止释放，与被碰小球发生正碰，重复 10 次。同样方法标出入射小球落点平均位置 $M$ 和被碰小球落点平均位置 $N$。
6. **测量距离：** 用刻度尺测量 $OP$、$OM$、$ON$ 的长度。
7. 改变释放高度，重复上述步骤获得多组数据。

#### 方案三：等长摆球碰撞

1. 用等长细线将两球悬挂在铁架台上，使两球静止时刚好接触。
2. 测出两球质量 $m_1$、$m_2$。
3. 拉起球 1 至某一摆角 $\theta_1$ 后释放，使其与静止的球 2 碰撞。
4. 记录碰撞后两球摆起的最大角度 $\theta_1'$、$\theta_2'$。
5. 改变释放角度或质量比，重复实验多次。

### 五、实验现象与数据记录（含表格示例）

#### 方案一：气垫导轨滑块

滑块速度由挡光片宽度 $d$ 与挡光时间 $\Delta t$ 计算：$v=\dfrac{d}{\Delta t}$。

挡光片宽度 $d$ 一致时，验证动量守恒可简化为验证 $m_1\Delta t_1'+m_2\Delta t_2'=m_1\Delta t_1+m_2\Delta t_2$（注意速度方向，需引入正负号）。

| 项目 | 滑块 1 | 滑块 2 | 系统总动量 |
|---|---|---|---|
| 质量 / kg | $m_1$ | $m_2$ | — |
| 碰前挡光时间 / s | $\Delta t_1$ | $\Delta t_2=\infty$（静止） | $p=m_1v_1$ |
| 碰前速度 / (m·s⁻¹) | $v_1=d/\Delta t_1$ | 0 | |
| 碰后挡光时间 / s | $\Delta t_1'$ | $\Delta t_2'$ | $p'=m_1v_1'+m_2v_2'$ |
| 碰后速度 / (m·s⁻¹) | $v_1'=d/\Delta t_1'$ | $v_2'=d/\Delta t_2'$ | |

比较 $p$ 与 $p'$，看在误差允许范围内是否相等。

#### 方案二：斜槽末端小球

两球碰撞后均从同一高度（斜槽末端）做平抛运动，下落时间 $t$ 相同。则
$$v_1=\frac{OP}{t},\quad v_1'=\frac{OM}{t},\quad v_2'=\frac{ON}{t}$$

代入动量守恒表达式 $m_1v_1=m_1v_1'+m_2v_2'$，消去 $t$ 得：

$$\boxed{m_1\cdot OP=m_1\cdot OM+m_2\cdot ON}$$

| 项目 | 数值 |
|---|---|
| 入射球质量 $m_1$/g | |
| 被碰球质量 $m_2$/g | |
| $OP$/cm | |
| $OM$/cm | |
| $ON$/cm | |
| $m_1\cdot OP$/(g·cm) | |
| $m_1\cdot OM+m_2\cdot ON$/(g·cm) | |
| 相对误差 | |

#### 方案三：等长摆球

由机械能守恒 $mgh=\frac{1}{2}mv^2$，得 $v=\sqrt{2gl(1-\cos\theta)}$，其中 $l$ 为摆长。代入 $m_1v_1=m_1v_1'+m_2v_2'$ 验证。

### 六、实验结果与结论

在误差允许的范围内，一维碰撞前后系统的总动量保持不变，验证了动量守恒定律。三种方案虽器材与数据处理方法不同，但本质都是测量碰撞前后物体的质量与速度（或其等效量，如平抛水平距离、摆起角度），从而验证 $m_1v_1+m_2v_2=m_1v_1'+m_2v_2'$。

### 七、误差分析（区分系统误差与偶然误差并给出减小方法）

**系统误差：**
- 气垫导轨未严格水平：摩擦力使速度测量值偏小，导致碰撞前后动量不等（调平导轨可减小）。
- 光电门位置距碰撞点较远时，气垫阻力使测得速度小于碰撞瞬时速度（靠近碰撞点安装可减小）。
- 斜槽末端不水平，使小球初速度有竖直分量，平抛时间 $t$ 不一致（调平末端可减小）。
- 碰撞非严格一维（非正碰）（保证球心等高、正碰可减小）。
- 入射球释放点高度每次略有不同，导致碰撞前速度不一致（固定释放高度可减小）。
- 摆角较大时单摆不再做简谐运动，$v=\sqrt{2gl(1-\cos\theta)}$ 仍成立但角度测量误差增大（摆角小于 30° 可减小）。
- 空气阻力及悬线摩擦使摆起高度偏小（减小摆球阻力可减小）。

**偶然误差：**
- 挡光时间读数误差（数字计时器精度限制）。
- 挡光片宽度 $d$、滑块质量、落点位置、圆心定位、距离测量等读数误差。
- 碰撞时可能有侧向偏转。

**减小方法：** 多次测量取平均值可减小偶然误差；严格调平导轨/斜槽末端、固定释放条件、保证一维正碰可减小系统误差。

### 八、注意事项

1. 三种方案都要求碰撞为正碰（一维）。
2. 入射物体每次释放条件必须一致。
3. 速度方向必须明确记录，动量是矢量（应规定正方向）。
4. 气垫导轨必须调到水平，挡光片宽度适当小些（如 1 cm），但不宜过小否则挡光时间过短、计时误差增大；数字计时器计时模式应与挡光片类型匹配（I 型为遮光计时，U 型为透光计时）。
5. 斜槽末端切线必须水平；入射小球每次必须从同一高度由静止释放；入射球质量必须大于被碰球质量（$m_1>m_2$），保证碰后入射球仍向前运动；实验中桌、槽、纸位置不可改变；两球大小相同，保证碰撞时球心等高。
6. 摆角不宜过大（小于 30°）；两摆线等长且悬点固定；两球在平衡位置发生正碰。
7. 碰撞后及时抓住滑块，避免反复碰撞损坏器材；实验中注意保护器材。

## 实验 4：观察气球的反冲运动

### 一、实验目的

1. 通过观察气球释放气体后的运动，认识反冲运动的基本规律。
2. 理解反冲运动的物理原理——动量守恒定律。
3. 体会火箭推进的原理。

### 二、实验器材

- 气球（多个，普通圆形乳胶气球）
- 细线（长约 5 m）
- 吸管（直径约 5 mm）
- 透明胶带
- 气球打气筒
- 双面胶

### 三、实验原理

气球充气后内部气压大于外界大气压。松开气球口时，气体从气球口高速喷出，根据动量守恒定律，气体获得向后的动量，气球获得大小相等、方向相反的动量，从而向前运动。这就是反冲现象。火箭的推进原理与此类似：燃料燃烧产生的高速气体从喷管向后喷出，火箭获得向前的反冲推力。

设气体喷出速度为 $u$，喷出气体质量为 $\Delta m$，气球（含剩余气体）质量为 $M$，则由动量守恒：

$$Mv=\Delta m\cdot u$$

即气球获得的速度 $v=\dfrac{\Delta m\cdot u}{M}$。

### 四、实验步骤

1. **简单实验：** 将气球吹至中等大小，用手捏住气球口。松开手，观察气球的运动情况，注意气球运动方向与气体喷出方向的关系。
2. **导轨式实验：**
   - 将细线穿过吸管，细线两端固定在教室两端（保持水平张紧）。
   - 用打气筒将气球吹至适当大小，捏住气球口。
   - 用透明胶带将气球固定在吸管上（气球口朝向一端）。
   - 松开气球口，观察气球沿细线方向的运动。
3. 改变气球充气量，观察运动距离和速度的变化。
4. 在气球上粘贴不同质量的重物（如硬币），观察运动情况的变化。

### 五、实验现象与数据记录

| 实验条件 | 气球充气量 | 气球运动方向 | 运动距离 | 运动特点 |
|---|---|---|---|---|
| 简单释放 | 中等 | 与气体喷出方向相反 | 不规则 | 轨迹弯曲，呈蛇形 |
| 吸管导轨 | 中等 | 与气体喷出方向相反 | 约 2~3 m | 沿导轨直线运动 |
| 吸管导轨（充气量大） | 较大 | 同上 | 较远（约 3~4 m） | 速度较快 |
| 吸管导轨（加重物） | 中等 | 同上 | 较近 | 速度较慢 |

**现象说明：**
- 气球运动方向始终与气体喷出方向相反，体现反冲运动的方向性。
- 简单释放时气球轨迹不规则，是因为气球口没有固定方向。
- 充气量大时气体喷出量多，反冲速度大，运动距离远。
- 增加气球质量时，由 $v=\Delta m\cdot u/M$，速度减小，运动距离变短。

### 六、实验结果与结论

气球释放气体时，气球向气体喷出的反方向运动，验证了反冲运动的方向规律。气球的反冲速度与气体喷出速度、喷出气体质量成正比，与气球自身质量成反比。这一定性规律与动量守恒定律一致，也是火箭推进的物理基础。

### 七、误差分析

1. **系统误差：**
   - 气球运动受空气阻力影响显著，实际运动距离小于理论值。
   - 气球喷气过程中质量不断减少，是变质量系统，$v=\Delta m\cdot u/M$ 仅适用于瞬时分析。
2. **偶然误差：**
   - 气球充气量难以精确控制。
   - 吸管与细线间摩擦阻力使运动减速。
   - 气球口松开瞬间方向可能偏移。

### 八、注意事项

1. 注意安全：气球突然松开可能弹飞，远离他人面部。
2. 细线需张紧，吸管与细线间摩擦应尽量小。
3. 气球口松开时方向应与导轨平行。
4. 多次实验观察规律，定性分析即可，不必追求数据精确。
5. 配合火箭原理讲解，可拓展讨论多级火箭、比冲等概念。
