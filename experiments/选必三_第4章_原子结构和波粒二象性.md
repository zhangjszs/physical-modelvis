## 实验 1：观察氢原子光谱

### 一、实验目的

1. 观察氢原子在可见光区的四条分立光谱线（Hα、Hβ、Hγ、Hδ）。
2. 知道氢原子光谱是线状谱，是氢原子的特征谱线。
3. 了解巴尔末公式及里德伯常量。
4. 体会光谱分析在科学研究中的重要意义。

### 二、实验器材

- 氢气光谱管一只（充有低压氢气）
- 高压感应线圈（或电源，约 5～10 kV）
- 直流电源（6～12 V，给感应圈供电）
- 分光镜一台（或光栅光谱仪）
- 导线若干
- 三棱镜（或衍射光栅）
- 凸透镜
- 光屏（或观察屏）
- 白炽灯（作连续光源对比）

### 三、实验原理

光谱：用棱镜或光栅把物质发出的光按波长（频率）展开，得到的波长与强度分布记录称为光谱。

光谱分类：
- 连续谱：炽热固体、液体或高压气体发出的光经色散后形成连续的光带，包含一切波长的光。
- 线状谱：稀薄气体发光经色散后形成一些不连续的亮线，是原子的特征谱线。每种原子都有自己的特征谱线。
- 吸收谱：连续光谱通过低温气体后，某些波长的光被吸收，在连续谱上出现暗线。

氢原子是最简单的原子，其光谱也最简单。在可见光区有四条分立谱线（Hα红、Hβ青、Hγ蓝、Hδ紫），1885 年巴尔末发现它们满足公式：

$$\frac{1}{\lambda} = R_\infty \left(\frac{1}{2^2} - \frac{1}{n^2}\right), \quad n = 3, 4, 5, 6$$

其中 R∞ ≈ 1.10×10⁷ m⁻¹ 是里德伯常量。

氢原子光谱的分立特性表明原子内部能量状态是量子化的（不连续），这为玻尔原子模型的提出奠定了基础。

### 四、实验步骤

1. **观察连续光谱**：将白炽灯的光通过分光镜，观察连续光谱（红橙黄绿青蓝紫连续分布）。
2. **观察氢光谱**：将氢气光谱管连接高压感应线圈，通电使氢气发光。
3. 用分光镜观察氢光谱管发出的光，记录可见光区观察到的亮线。
4. 测量（或查阅）各亮线的波长，与巴尔末公式计算值比较。
5. **对比吸收光谱**（可选）：让白炽灯光通过氢气后再分光，观察暗线位置与发射光谱亮线对应关系。
6. 观察其他元素（钠、汞等）的光谱，对比不同元素的特征谱线。

### 五、实验现象与数据记录

氢原子可见光区四条谱线：

| 谱线 | 颜色 | 波长 λ (nm) | n 值 | 计算 1/λ (m⁻¹) |
| ---- | ---- | ----------- | --- | --------------- |
| Hα | 红 | 656.3 | 3 | 1.524×10⁶ |
| Hβ | 青绿 | 486.1 | 4 | 2.057×10⁶ |
| Hγ | 蓝 | 434.1 | 5 | 2.304×10⁶ |
| Hδ | 紫 | 410.2 | 6 | 2.438×10⁶ |

观察：氢光谱是分立的亮线，不是连续谱；不同元素的亮线位置不同。

### 六、实验结果与结论

1. 氢原子在可见光区有四条分立谱线，是线状谱。
2. 各谱线波长满足巴尔末公式，里德伯常量 R∞ ≈ 1.10×10⁷ m⁻¹。
3. 氢原子光谱是氢原子的特征谱线，可用于光谱分析鉴别物质。
4. 光谱的分立特性表明原子内部能量是量子化的。

### 七、误差分析

1. **分光镜精度**：普通分光镜读数精度有限。改进措施：使用光栅光谱仪。
2. **光谱管老化**：使用过久的光谱管亮度减弱。改进措施：使用新的光谱管。
3. **环境光线**：外界光线干扰观察。改进措施：在暗室中观察。
4. **电压不足**：感应圈电压不足时氢气不能充分激发。改进措施：保证电压足够。

### 八、注意事项

1. 高压感应圈电压很高（数千伏），通电时不要接触电极和导线裸露部分。
2. 光谱管通电时间不宜过长，每次观察不超过 30 秒，间歇使用。
3. 通电时会产生臭氧，注意通风。
4. 观察光谱时眼睛要适应黑暗环境。
5. 分光镜的狭缝要调节适当，太宽谱线变粗不准确，太窄光太弱。

## 实验 2：α粒子散射实验（演示与原理介绍）

### 一、实验目的

1. 了解卢瑟福 α 粒子散射实验的装置、过程和现象。
2. 理解实验现象对原子核式结构模型的提出所起的作用。
3. 体会实验在物理理论建立中的关键作用。
4. 知道原子核式结构模型的内容。

### 二、实验器材（教学演示用）

- α粒子散射实验装置示意图
- 多媒体课件（演示实验过程）
- 金箔模型
- α粒子放射源模型（如镭或钋放射源）
- 荧光屏和显微镜示意图
- 铅屏蔽容器（实际实验中有）

### 三、实验原理

1909 年卢瑟福及其助手盖革和马斯登进行了 α 粒子散射实验。装置的核心是：
- α 粒子放射源：发出带正电的 α 粒子（氦核 He²⁺，质量约为电子的 7300 倍，速度约光速的 1/10）。
- 金箔：极薄（约 1 μm，几个原子厚度）。
- 荧光屏：涂有硫化锌，可显示 α 粒子撞击产生的闪光。
- 显微镜：可绕金箔旋转，观察不同散射角 θ 处的 α 粒子。

实验在真空中进行，α 粒子从放射源经过准直后形成细束，轰击金箔，散射后打到荧光屏上产生闪光。通过显微镜观察并计数不同角度上的闪光次数。

卢瑟福原来的预期（基于汤姆孙"枣糕模型"）：α 粒子应该几乎不偏转地穿过原子，因为正电荷均匀分布，对 α 粒子的合力很小。

实际观察结果令人震惊：
1. 绝大多数 α 粒子几乎不偏转地穿过金箔。
2. 少数 α 粒子发生较大角度偏转。
3. 极少数（约 1/8000）α 粒子偏转角大于 90°，甚至被反弹回来。

卢瑟福形容："就像你用一枚 15 英寸的炮弹轰击一张纸巾，结果炮弹被弹回来击中了你。"

根据实验现象，卢瑟福在 1911 年提出原子的核式结构模型：
1. 原子中心有一个极小的原子核（直径约 10⁻¹⁵～10⁻¹⁴ m），几乎集中了原子的全部质量和全部正电荷。
2. 电子在原子核外很大的空间里绕核运动（原子直径约 10⁻¹⁰ m）。
3. 原子绝大部分是空的。

### 四、实验步骤

1. **介绍实验装置**：讲解放射源、金箔、荧光屏、显微镜的布置。
2. **演示实验过程**：用多媒体课件演示 α 粒子穿过金箔后的散射情况。
3. **分析实验现象**：
   - 大多数 α 粒子不偏转 → 原子大部分是空的。
   - 少数 α 粒子偏转 → 接近原子核时受强斥力。
   - 极少数被反弹 → 原子核质量大、带正电、体积小。
4. **推出核式结构模型**：综合三个现象推出原子有核的结构。
5. **定量估算**：用能量守恒估算原子核半径上限。

### 五、实验现象与数据记录

| 现象 | 比例 | 推论 |
| ---- | ---- | ---- |
| 绝大多数 α 粒子直线穿过 | > 99% | 原子内部大部分是空的 |
| 少数 α 粒子发生较大偏转 | 约 1/1000 | 原子内有质量集中、带正电的部分 |
| 极少数 α 粒子反弹（>90°） | 约 1/8000 | 原子核体积很小，质量很大 |

定量估算（α 粒子动能 7.7 MeV，金原子核电荷 Z=79）：
$$d = \frac{2Ze \cdot 2e}{4\pi\varepsilon_0 \cdot E_k} = \frac{79 \times 2 \times (1.6\times10^{-19})^2}{4\pi \times 8.85\times10^{-12} \times 1.2\times10^{-12}} \approx 3.0\times10^{-14} \text{ m}$$

即金原子核半径上限约 3×10⁻¹⁴ m。

### 六、实验结果与结论

1. 实验否定了汤姆孙的"枣糕模型"。
2. 提出了原子的核式结构模型：原子由带正电的、体积小质量大的原子核和核外电子组成。
3. 原子核半径上限约 10⁻¹⁴ m，原子半径约 10⁻¹⁰ m，原子核体积仅占原子体积的 10⁻¹² 量级。
4. 此实验是原子物理学的奠基性实验。

### 七、误差分析

1. **统计误差**：被反弹的 α 粒子极少，需长时间观察才能统计出比例。
2. **α 粒子能量不均**：放射源发出的 α 粒子能量有一定分布。改进措施：使用单一能量的 α 源。
3. **金箔厚度不均**：金箔厚度变化影响散射概率。
4. **真空度不足**：空气分子会使 α 粒子散射。改进措施：保持高真空。
5. **观察主观性**：人工计数闪光有误差。改进措施：现代使用电子探测器和计算机记录。

### 八、注意事项

1. 放射源有放射性，使用时需铅屏蔽，实验后妥善保存。
2. 实际中学通常以原理介绍和多媒体演示为主，不进行实际 α 粒子散射实验。
3. 强调实验现象的"出乎意料"，体会实验对理论建立的重要作用。
4. 解释为什么是金箔：金延展性好，可做成极薄的箔；金原子序数大，核电荷多，散射效应明显。

## 实验 3：光电效应演示（紫外线照射锌板）

### 一、实验目的

1. 观察光电效应现象，知道光照射金属可使其发射电子。
2. 理解光电效应的产生条件：入射光频率必须大于金属的极限频率。
3. 体会光电效应对光的波动说的挑战，理解光子说的提出。
4. 知道光既有波动性又有粒子性。

### 二、实验器材

- 锌板一片（面积约 10 cm × 10 cm，表面用砂纸打磨清洁）
- 验电器一只（灵敏度高）
- 紫外线灯一只（波长 254 nm 或更短）
- 白炽灯一只（功率 100 W 以上）
- 玻璃板一块（可挡紫外线）
- 砂纸或钢丝刷
- 丝绸或毛皮（用于摩擦起电）
- 验电羽或验电笔
- 防护眼镜

### 三、实验原理

光电效应：在光（包括不可见光）的照射下，金属表面发射电子（光电子）的现象。逸出的电子称为光电子。

光电效应的实验规律：
1. 任何金属都有一个极限频率 ν₀，入射光频率必须大于 ν₀ 才能发生光电效应。
2. 光电子的最大初动能与入射光强度无关，只与入射光频率有关，频率越高，初动能越大。
3. 光电子数目（光电流）与入射光强度成正比。
4. 光电效应几乎是瞬时发生的（不超过 10⁻⁹ s）。

经典波动说无法解释：
- 极限频率的存在（按波动说，只要有足够时间积累能量，任何频率的光都应能产生光电效应）。
- 光电子最大初动能与光强无关。
- 瞬时性。

1905 年爱因斯坦提出光子说：光是一份一份的不连续的形式传播的，每一份叫一个光子，光子能量 E = hν（h 为普朗克常量，ν 为光的频率）。一个光子只能被一个电子全部吸收，电子获得足够能量即可逸出金属表面。

光电效应方程：E_k = hν - W（W 为金属的逸出功）。

锌的极限频率约为 8.06×10¹⁴ Hz（波长 372 nm），所以必须用紫外线（波长短于 372 nm）才能产生光电效应，可见光不能。

### 四、实验步骤

1. 用砂纸打磨锌板表面，去除氧化层。
2. 将锌板连接到验电器上。
3. 用毛皮摩擦过的橡胶棒接触锌板，使锌板带负电，验电器指针张开。
4. **白炽灯照射**：用白炽灯近距离照射锌板，观察验电器指针是否变化。
5. **紫外线照射**：用紫外线灯照射锌板，观察验电器指针的变化。
6. **加玻璃板**：在紫外线灯和锌板之间放一块玻璃板，观察指针是否变化。
7. **锌板带正电时**：让锌板带正电，再用紫外线照射，观察指针变化。
8. 记录各组实验现象。

### 五、实验现象与数据记录

| 操作 | 现象 |
| ---- | ---- |
| 锌板带负电，白炽灯照射 | 验电器指针无变化 |
| 锌板带负电，紫外线照射 | 验电器指针迅速闭合（电子从锌板逸出，负电荷减少） |
| 紫外线 + 玻璃板 | 验电器指针无变化（玻璃挡住紫外线） |
| 移开玻璃板 | 指针又迅速闭合 |
| 锌板带正电，紫外线照射 | 验电器指针无变化（电子不能逸出反而被吸引） |

### 六、实验结果与结论

1. 紫外线照射带负电的锌板时，锌板会失去电子（负电荷减少），验电器指针闭合。
2. 可见光不能产生光电效应，因为锌的极限频率高于可见光频率。
3. 玻璃板能挡住紫外线，玻璃后的锌板不发生光电效应。
4. 锌板带正电时，电子被正电荷吸引，不能逸出。
5. 实验结论：光电效应需要入射光频率大于金属的极限频率；光电子带负电。

### 七、误差分析

1. **锌板表面氧化**：氧化层阻碍电子逸出。改进措施：实验前用砂纸打磨。
2. **环境湿度大**：湿气使电荷泄漏。改进措施：在干燥环境进行，可用红外灯烘烤。
3. **紫外线强度不足**：紫外灯老化或功率不足。改进措施：使用足够功率的紫外灯。
4. **验电器灵敏度**：灵敏度不够时现象不明显。改进措施：使用高灵敏度验电器。
5. **可见光干扰**：白炽灯中也含少量紫外光，可能产生微弱光电效应。改进措施：使用滤光片。

### 八、注意事项

1. 紫外线对眼睛和皮肤有害，实验时要戴防护眼镜，避免直视紫外灯。
2. 锌板表面必须打磨清洁，否则光电效应不明显。
3. 实验环境要干燥，湿度过大时验电器难以保持电荷。
4. 紫外灯不要长时间连续使用，间歇开启。
5. 实验中不要用手触摸锌板表面。

## 实验 4：观察金属的极限频率

### 一、实验目的

1. 通过不同频率的光照射同一金属，观察是否产生光电效应。
2. 知道每种金属都有一个极限频率。
3. 理解极限频率与光子说的关系。
4. 测定金属的极限频率（或极限波长）。

### 二、实验器材

- 光电效应演示仪（带光电管）
- 不同颜色的滤光片（红、橙、黄、绿、蓝、紫）
- 紫外光源
- 电流计（微安表）
- 直流电源
- 锌板、铜板、钾（或铯）光电管
- 多种光源：红光激光、绿光激光、紫外灯、白炽灯

### 三、实验原理

光电效应方程：E_k = hν - W
当 E_k = 0 时，hν₀ = W，即 ν₀ = W/h 是金属的极限频率。

不同金属的逸出功 W 不同，极限频率也不同：
- 锌：W ≈ 4.3 eV，ν₀ ≈ 1.04×10¹⁵ Hz，λ₀ ≈ 290 nm（紫外区）
- 钠：W ≈ 2.28 eV，ν₀ ≈ 5.5×10¹⁴ Hz，λ₀ ≈ 545 nm（可见绿光）
- 钾：W ≈ 2.25 eV，ν₀ ≈ 5.4×10¹⁴ Hz
- 铯：W ≈ 1.95 eV，ν₀ ≈ 4.7×10¹⁴ Hz
- 铂：W ≈ 6.35 eV

只有入射光频率大于极限频率时才发生光电效应。光的强度只影响光电子数目，不影响能否发生光电效应。

### 四、实验步骤

1. 将光电管接入电路，电流计调零。
2. **用不同颜色光照射**：依次用红、橙、黄、绿、蓝、紫色光照射光电管阴极，观察电流计是否有电流。
3. **找极限频率**：从低频（红光）到高频（紫外光），找到刚好产生光电流的频率，即为极限频率。
4. **不同金属对比**：换用不同金属的光电管（锌、铜、钾、铯等），重复实验。
5. **强度影响**：固定入射光频率（高于极限频率），改变光强，观察光电流的变化。
6. 记录各金属的极限频率（或波长）。

### 五、实验现象与数据记录

| 金属 | 红光 (4.5×10¹⁴ Hz) | 绿光 (5.5×10¹⁴ Hz) | 蓝光 (6.5×10¹⁴ Hz) | 紫光 (7.5×10¹⁴ Hz) | 紫外 (1.2×10¹⁵ Hz) |
| ---- | ------------------ | ------------------ | ------------------ | ------------------ | ------------------- |
| 锌板 | 无 | 无 | 无 | 无 | 有 |
| 钠光电管 | 无 | 微弱 | 明显 | 强 | 强 |
| 铯光电管 | 微弱 | 明显 | 强 | 强 | 强 |
| 铜板 | 无 | 无 | 无 | 无 | 无 |

光强对光电流的影响（频率高于极限频率时）：

| 光强 | 光电流 |
| ---- | ------ |
| 弱 | 小 |
| 中 | 中 |
| 强 | 大 |

### 六、实验结果与结论

1. 不同金属有不同的极限频率，对应不同的逸出功。
2. 碱金属（钾、铯）的极限频率低，可见光即可产生光电效应；过渡金属（锌、铜）极限频率高，需紫外光。
3. 频率低于极限频率时，无论光多强都不发生光电效应。
4. 频率高于极限频率时，光电流随光强增大而增大。
5. 光子说可以解释极限频率：每个光子能量 hν 必须大于逸出功 W 才能激发光电子。

### 七、误差分析

1. **滤光片不纯**：滤光片透过一定带宽的光，频率不单一。改进措施：使用单色仪或激光。
2. **光电管老化**：光电管使用久了灵敏度下降。改进措施：使用新的光电管。
3. **环境光干扰**：外界光线影响测量。改进措施：在暗室中进行。
4. **电流计灵敏度**：微弱电流不易测出。改进措施：使用高灵敏度微安表或检流计。

### 八、注意事项

1. 实验在暗室中进行，避免环境光干扰。
2. 滤光片要选择透过率高的窄带滤光片。
3. 紫外光源使用时要戴防护眼镜。
4. 光电管是精密器件，避免强光长时间照射。
5. 注意区分"光强"和"光频率"对光电效应的不同影响。

## 实验 5：用光电管探究光电效应规律

### 一、实验目的

1. 测量光电效应的伏安特性曲线。
2. 测定光电子的最大初动能与入射光频率的关系。
3. 测定普朗克常量 h。
4. 验证爱因斯坦光电效应方程。

### 二、实验器材

- 光电管一只
- 微电流计或检流计
- 直流电源（0～30 V）
- 电压表
- 滑线变阻器
- 不同波长的光源（如汞灯的几条特征谱线：365 nm、405 nm、436 nm、546 nm、577 nm）
- 滤光片或单色仪
- 开关、导线

### 三、实验原理

光电管是一个真空管，内有阴极 K 和阳极 A。光照射阴极时，阴极发射光电子。在阴极和阳极之间加电压，可控制光电子的运动。

伏安特性曲线：
- 加正向电压时，光电流随电压增大而增大，达到饱和值（饱和光电流）。
- 加反向电压时，光电流减小，当反向电压达到一定值 U_c 时，光电流为零，U_c 称为遏止电压。
- 光电子最大初动能：E_k = eU_c。

爱因斯坦光电效应方程：E_k = hν - W，即 eU_c = hν - W。

以遏止电压 U_c 为纵坐标，频率 ν 为横坐标，绘制 U_c-ν 图像，应为一条直线，斜率 k = h/e，截距 b = -W/e。由此可测定普朗克常量 h = ke。

### 四、实验步骤

1. 按电路图连接电路：光电管、电源、电压表、电流计、变阻器。
2. 选择某一波长的光（如 546 nm 绿光）照射光电管阴极。
3. 调节变阻器，使阴极和阳极间电压从正向最大逐渐减小到零，再变为反向电压。
4. 记录不同电压下的光电流，绘制 I-U 曲线。
5. 找出光电流为零时的反向电压，即遏止电压 U_c。
6. 换不同波长的光，重复步骤 3～5，测出多个 U_c。
7. 绘制 U_c-ν 图像，求斜率 k。
8. 计算普朗克常量 h = ke。

### 五、实验现象与数据记录

伏安特性曲线（546 nm 绿光）：

| 电压 U (V) | 光电流 I (μA) |
| ---------- | ------------- |
| +5 | 12.5（饱和） |
| +3 | 12.5 |
| +1 | 12.4 |
| 0 | 11.8 |
| -0.5 | 8.5 |
| -1.0 | 4.2 |
| -1.5 | 0（遏止） |

不同波长下的遏止电压：

| 波长 λ (nm) | 频率 ν (×10¹⁴ Hz) | 遏止电压 U_c (V) |
| ----------- | ----------------- | ---------------- |
| 577 | 5.20 | 0.18 |
| 546 | 5.49 | 0.32 |
| 436 | 6.88 | 0.85 |
| 405 | 7.41 | 1.05 |
| 365 | 8.22 | 1.40 |

绘制 U_c-ν 图像为一条直线，斜率约为 k = 4.0×10⁻¹⁵ V·s，则 h = ke ≈ 4.0×10⁻¹⁵ × 1.6×10⁻¹⁹ ≈ 6.4×10⁻³⁴ J·s（与标准值 6.63×10⁻³⁴ J·s 接近）。

### 六、实验结果与结论

1. 光电效应的伏安特性曲线呈"S"形，存在饱和光电流和遏止电压。
2. 遏止电压与入射光频率成线性关系：U_c = (h/e)ν - W/e。
3. 由 U_c-ν 图像斜率测得普朗克常量 h ≈ 6.4×10⁻³⁴ J·s，与标准值接近。
4. 验证了爱因斯坦光电效应方程 E_k = hν - W。

### 七、误差分析

1. **反向电流**：阳极在光照下也可能发射光电子（反向光电效应），使遏止电压测量不准。改进措施：使用特殊设计的光电管，阳极避光。
2. **接触电势差**：阴极和阳极材料不同产生接触电势差。改进措施：考虑修正。
3. **光的单色性**：滤光片透过带宽较宽。改进措施：使用单色仪或激光。
4. **暗电流**：无光照时也有微小电流。改进措施：扣除暗电流。
5. **电压表内阻**：影响测量精度。

### 八、注意事项

1. 光电管要避免强光长时间照射，防止老化。
2. 实验在暗室中进行。
3. 不同光源的频率要准确知道（查阅资料）。
4. 加反向电压时缓慢调节，找到光电流为零的位置。
5. 测量前先调零电流计。

## 实验 6：黑体辐射演示（拓展）

### 一、实验目的

1. 了解黑体辐射的概念。
2. 观察不同温度下物体辐射的颜色和强度变化。
3. 知道普朗克为解释黑体辐射提出了能量量子化假说。

### 二、实验器材

- 白炽灯一只（功率可调）
- 调压器（自耦变压器）
- 三棱镜或光栅
- 光屏
- 黑色金属块（或石墨块）
- 酒精灯或本生灯
- 红外温度计
- 光强计（或光度计）

### 三、实验原理

黑体是指能全部吸收各种波长电磁波的理想物体。在任何温度下，黑体都向外辐射各种波长的电磁波，辐射的能量按波长的分布只与温度有关。

普朗克黑体辐射公式（1900 年）：为解释黑体辐射实验曲线，普朗克提出能量量子化假说——振子能量只能取离散值 E = nhν（n 为正整数，h 为普朗克常量）。这是量子力学的起点。

斯特藩-玻尔兹曼定律：黑体辐射的总能量 E ∝ T⁴。
维恩位移定律：辐射最强对应的波长 λ_m ∝ 1/T（温度升高，辐射峰值向短波方向移动）。

### 四、实验步骤

1. **观察白炽灯发光**：白炽灯通电后，随着电压升高，灯丝温度升高，颜色由暗红 → 红 → 橙 → 黄 → 白。
2. **观察金属加热发光**：将金属块在酒精灯上加热，观察颜色随温度变化。
3. **用棱镜分析光谱**：将白炽灯光通过棱镜，观察不同电压下的连续光谱分布。
4. **测量光强变化**：用光强计测量不同电压下白炽灯的总辐射强度。

### 五、实验现象与数据记录

| 电压 (V) | 灯丝颜色 | 光谱主要分布 | 总光强（相对） |
| -------- | -------- | ------------ | -------------- |
| 50 | 暗红 | 偏红外 | 弱 |
| 100 | 红 | 红光多 | 较弱 |
| 150 | 橙黄 | 黄橙光多 | 中 |
| 220 | 白 | 各色平衡 | 强 |

观察：温度升高，颜色从红→白→蓝白，总辐射强度增加。

### 六、实验结果与结论

1. 物体温度越高，辐射的总能量越大。
2. 温度升高，辐射最强的波长向短波方向移动（维恩位移定律）。
3. 实验现象与普朗克黑体辐射理论一致。

### 七、误差分析

1. **非理想黑体**：白炽灯和金属不是理想黑体。改进措施：使用空腔黑体模型。
2. **温度不易精确测量**：灯丝温度不易直接测量。改进措施：根据电压电流估算。
3. **环境影响**：环境光线干扰。改进措施：在暗室中进行。

### 八、注意事项

1. 白炽灯温度高，注意防烫。
2. 调压器使用要规范，防止触电。
3. 长时间高温会使灯丝烧断，控制时间。
4. 注意用电安全。

## 实验 7：电子衍射实验（演示介绍）

### 一、实验目的

1. 了解电子衍射实验的原理和历史意义。
2. 知道电子具有波动性（物质波/德布罗意波）。
3. 体会波粒二象性的普遍性。

### 二、实验器材

- 电子衍射管（演示用）
- 阴极射线管
- 多晶铜膜或镍膜（衍射靶）
- 高压电源（数千伏）
- 荧光屏
- 多媒体课件

### 三、实验原理

1924 年德布罗意提出物质波假说：一切实物粒子都既有粒子性又有波动性，相应的波长（德布罗意波长）为：

$$\lambda = \frac{h}{p} = \frac{h}{mv}$$

其中 h 为普朗克常量，p 为粒子动量，m 为粒子质量，v 为速度。

1927 年戴维森-革末用电子束照射镍单晶，观察到电子的衍射现象，与德布罗意预言的波长一致，证实了电子的波动性。

电子衍射环的半径与电子的德布罗意波长、晶格常数有关，可通过衍射公式计算波长，与德布罗意公式计算值比较。

### 四、实验步骤

1. 介绍德布罗意的物质波假说和波长公式。
2. 演示电子衍射实验（如有电子衍射管）：电子经高压加速后通过多晶铜膜，在荧光屏上形成同心圆衍射环。
3. 测量衍射环半径，计算电子波长。
4. 用德布罗意公式 λ = h/mv 计算理论值（已知加速电压）。
5. 比较实验值和理论值。

### 五、实验现象与数据记录

| 加速电压 U (V) | 衍射环半径 r (cm) | 计算波长 λ (nm) | 德布罗意波长 λ = h/√(2meU) (nm) |
| -------------- | ----------------- | --------------- | ------------------------------- |
| 2000 | 1.20 | 0.0274 | 0.0274 |
| 4000 | 0.85 | 0.0194 | 0.0194 |
| 6000 | 0.69 | 0.0158 | 0.0158 |

观察：加速电压越高，衍射环半径越小，波长越短。

### 六、实验结果与结论

1. 电子束通过多晶薄膜后形成衍射环，证明电子具有波动性。
2. 由衍射环半径计算出的电子波长与德布罗意公式计算值一致。
3. 实验证实了德布罗意物质波假说，确立了粒子的波粒二象性。

### 七、误差分析

1. **电子能量分散**：电子初始速度不均匀。改进措施：使用单色电子束。
2. **晶格常数测量**：晶格常数精度影响波长计算。
3. **衍射环测量**：环半径读数存在误差。改进措施：使用放大镜或图像处理。

### 八、注意事项

1. 电子衍射管价格较高，使用时要小心。
2. 高压电源危险，注意用电安全。
3. 不要长时间照射，防止荧光屏老化。
4. 此实验在中学通常以原理介绍和视频演示为主。

## 实验 8：观察连续光谱与线状光谱

### 一、实验目的

1. 观察连续光谱和线状光谱的区别。
2. 知道不同光源产生不同类型的光谱。
3. 理解光谱分析的原理。

### 二、实验器材

- 分光镜（或光栅光谱仪）
- 白炽灯（连续光谱源）
- 氢气光谱管
- 钠光谱管
- 氦光谱管
- 氖光谱管
- 汞光谱管
- 高压感应圈（电源）
- 酒精灯
- 食盐（NaCl）
- 铁丝（蘸盐灼烧）

### 三、实验原理

光谱分为：
- 连续谱：炽热的固体、液体或高压气体发出的光经色散后形成连续的光带。
- 线状谱：稀薄气体发光形成的由不连续亮线组成的光谱，是原子的特征谱线。
- 吸收谱：连续谱上叠加暗线，对应于物质吸收特定波长光。

每种元素都有自己的特征谱线，因此可以通过光谱分析确定物质的化学组成。

### 四、实验步骤

1. **观察连续光谱**：用分光镜观察白炽灯的光谱，记录颜色分布。
2. **观察氢光谱**：通电激发氢气光谱管，用分光镜观察，记录亮线位置和颜色。
3. **观察钠光谱**：将铁丝蘸食盐在酒精灯上灼烧，用分光镜观察钠的黄色双线。
4. **观察其他元素光谱**：分别观察氦、氖、汞等元素的光谱，记录各自的亮线分布。
5. **对比吸收光谱**：让白炽灯光通过钠蒸气（火焰）后观察，对比吸收暗线与发射亮线的位置。

### 五、实验现象与数据记录

| 光源 | 光谱类型 | 主要亮线颜色与波长 |
| ---- | -------- | ----------------- |
| 白炽灯 | 连续谱 | 红→紫连续分布 |
| 氢气 | 线状谱 | 红 656 nm、青 486 nm、蓝 434 nm、紫 410 nm |
| 钠 | 线状谱 | 黄色双线 589.0、589.6 nm |
| 氖 | 线状谱 | 多条红、橙、黄亮线 |
| 汞 | 线状谱 | 紫 405、蓝 436、绿 546、黄 577 nm |

### 六、实验结果与结论

1. 白炽灯发出连续光谱，因灯丝是炽热固体。
2. 稀薄气体发光形成线状谱，每种元素有自己的特征谱线。
3. 不同元素的特征谱线位置不同，可用于光谱分析。
4. 吸收光谱中的暗线与同种元素发射光谱中的亮线波长对应。

### 七、误差分析

1. **分光镜精度**：分辨率低时谱线不清晰。改进措施：使用光栅光谱仪。
2. **光谱管亮度**：亮度不足时谱线暗淡。改进措施：使用新的光谱管，电压充足。
3. **环境光**：外界光线干扰。改进措施：在暗室观察。
4. **狭缝调节**：分光镜狭缝宽度不当影响谱线质量。

### 八、注意事项

1. 高压感应圈电压高，注意用电安全。
2. 光谱管通电时间不宜过长（每次约 30 秒，间歇使用）。
3. 观察前让眼睛适应黑暗。
4. 食盐灼烧时注意防止烫伤。
5. 不同元素的光谱对比要清晰，便于学生区分。

- **探究类**：用光电管探究光电效应规律
- **观察/演示类**：观察氢原子光谱、α粒子散射实验（演示与原理介绍）、光电效应演示（紫外线照射锌板）、观察金属的极限频率、黑体辐射演示（拓展）、电子衍射实验（演示介绍）、观察连续光谱与线状光谱

**对比与要点**：光谱、α散射、光电效应、电子衍射，从原子模型到波粒二象性，注意经典与量子图像的更替。
