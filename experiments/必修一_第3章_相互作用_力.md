本章研究力的基本概念和力的合成与分解规律,涉及重力、弹力、摩擦力以及作用力与反作用力等核心知识。本章实验围绕"力的认识"和"力的合成"展开。本章共包含 7 个实验:

- 实验 1: 悬挂法确定物体的重心 (演示实验, §1 重力与弹力)

- 实验 4: 摩擦力的大小和方向 (演示实验, §3 摩擦力)

- 实验 7: 探究作用力与反作用力的关系 (分组实验, §3 牛顿第三定律)

## 实验 1: 悬挂法确定物体的重心

### 一、实验目的

1. 理解重心的概念,知道重心是物体各部分所受重力的等效作用点。
2. 掌握用悬挂法确定形状不规则物体重心的方法。
3. 体会"等效替代"的物理思想。
4. 理解重心位置与物体的形状和质量分布有关。

### 二、实验器材

- 形状不规则的薄板 (如硬纸板、薄木板)
- 细线 (或细绳)
- 重垂线 (带小重物的细线)
- 图钉 (或小钉)
- 铅笔
- 刻度尺
- 支架 (铁架台)

### 三、实验原理

重心是物体各部分所受重力的等效作用点。对于形状规则、质量分布均匀的物体,重心在物体的几何中心;但对于形状不规则或质量分布不均匀的物体,重心的位置不易直接判断,需要用实验方法确定。

**二次悬挂法原理**:当物体在悬挂状态下处于静止时,根据二力平衡条件,细线对物体的拉力与物体的重力大小相等、方向相反、作用在同一直线上,即重心必在悬挂线的延长线上。在不同位置悬挂两次,两次悬挂线的交点即为重心位置。

### 四、实验步骤

1. 在薄板的边缘任选一点 A,用图钉 (或小钉) 固定细线,将薄板悬挂起来。
2. 待薄板静止后,在薄板上沿细线方向画一条直线 (可用重垂线辅助,使画线更准确)。
3. 再选薄板边缘另一点 B (与 A 不在同一直径上),用同样方法悬挂薄板。
4. 待薄板静止后,在薄板上沿细线方向画第二条直线。
5. 两条直线的交点即为薄板的重心位置。
6. 用铅笔在交点处做标记 O。
7. 验证:用手指尖支撑薄板上的 O 点,若薄板能水平静止,说明 O 点确实是重心。
8. 可换第三点 C 悬挂,验证第三条悬挂线也经过 O 点。

### 五、实验现象与数据记录

- 两次悬挂线相交于一点,该点即为薄板的重心。
- 用指尖支撑该点时,薄板能水平静止;支撑其他点时,薄板会倾斜或翻转。

### 六、实验结果与结论

1. 两次 (或多次) 悬挂线的交点即为形状不规则物体的重心位置。
2. 重心不一定在物体上 (如圆环形物体的重心在圆心,不在物体本身),重心位置由物体的形状和质量分布决定。
3. 此实验体现了二力平衡原理和等效替代思想。

### 七、误差分析

1. **系统误差**:
   - 薄板厚度不均匀,导致质量分布不完全在平面内。
   - 悬挂点处的图钉或钉子有一定质量,可能影响重心位置。
2. **偶然误差**:
   - 画线时不够准确,与悬挂线方向有偏差。
   - 薄板未完全静止就画线。
   - 两条画线交点过小,确定位置时存在视觉误差。
3. **减小误差的方法**:
   - 使用质量均匀的薄板。
   - 待薄板完全静止后再画线,可多画几次取平均。
   - 选用较细的笔尖画线。
   - 在薄板不同位置多次悬挂,验证交点重合。

### 八、注意事项

1. 薄板应选质量分布均匀的,以保证重心在板面内。
2. 悬挂时应保证薄板能自由摆动,不受阻碍。
3. 待薄板完全静止后再画线。
4. 两次悬挂点应选在薄板边缘相距较远的位置,且不在同一直径上,以使两条画线有较大夹角,交点更明确。
5. 画线应沿细线方向,可用重垂线辅助。
6. 此方法适用于薄板状物体,不适用于三维立体物体。

## 实验 2: 观察桌面的微小形变

### 一、实验目的

1. 观察坚硬物体 (如桌面) 在外力作用下发生的微小形变。
2. 学习"放大法"在物理实验中的应用,体会"光杠杆放大"思想。
3. 理解"任何物体受力都会发生形变"的物理规律。
4. 体会物理实验中"将微小变化放大为明显变化"的科学方法。

### 二、实验器材

- 大桌子 (或长木板)
- 两个平面镜 M 和 N
- 激光笔 (或点光源)
- 刻度尺
- 铁架台 (固定光源和刻度尺)

### 三、实验原理

桌面受到压力时会发生形变,但形变极其微小,肉眼无法直接观察。本实验利用光学方法将微小形变"放大"为可观察的明显变化。

**光杠杆放大原理**:
- 在桌面上放置两个平面镜 M 和 N,相距一定距离。
- 让激光笔发出的一束光依次被两个平面镜反射,最后投射到刻度尺 (或墙壁) 上,形成一个光点。
- 当用力向下压桌面时,桌面发生微小凹陷形变,两个平面镜随之微微倾斜。
- 根据光的反射定律,平面镜每偏转一个小角度 α,反射光线偏转 2α。
- 光线经过两个平面镜两次反射后,偏转角度被放大两倍。
- 加上平面镜到刻度尺的距离较远,光线微小的角度偏转会在刻度尺上形成明显的位移,从而将桌面的微小形变"放大"为可观察的光点移动。

### 四、实验步骤

1. **安装器材**:在大桌子上放置两个平面镜 M 和 N,相距约 1~2 m,使两镜面相对。
2. **放置光源**:用铁架台固定激光笔,使激光束水平射向第一个平面镜 N,经反射后射向第二个平面镜 M,再经反射后投射到远处的墙壁或刻度尺上,形成一个清晰的光点。
3. **标记初始位置**:在墙壁或刻度尺上标记光点的初始位置。
4. **施加压力**:用力向下按压两个平面镜之间的桌面中央。
5. **观察现象**:观察墙壁或刻度尺上光点的位置变化,记录光点移动的方向和距离。
6. **撤去压力**:松开手后,观察光点是否回到原来的位置。
7. **改变压力大小**:用不同的力按压桌面,观察光点移动距离的变化。
8. **重复实验**:多次实验,验证现象的可靠性。

### 五、实验现象与数据记录

- 用力按压桌面时,墙壁或刻度尺上的光点明显移动 (移动方向与平面镜倾斜方向有关)。
- 撤去压力后,光点回到原来的位置。
- 按压力越大,光点移动距离越大 (在弹性限度内)。

### 六、实验结果与结论

1. 光点的明显移动证明了桌面发生了微小形变,虽然这种形变肉眼无法直接观察,但通过光学放大法可以清楚地显示出来。
2. 结论:任何物体在力的作用下都会发生形变,即使是坚硬的桌面也不例外。
3. 此实验运用了"放大法"——将微小的、难以直接观察的变化转化为明显的、可观察的变化,这是物理实验中重要的科学方法。

### 七、误差分析

1. **系统误差**:
   - 桌面并非刚体,形变恢复可能有滞后。
   - 平面镜与桌面接触不完全贴合,影响形变传递。
2. **偶然误差**:
   - 光点较大或抖动,影响读数。
   - 桌面形变受外界振动干扰 (如人员走动)。
3. **减小误差的方法**:
   - 在较暗的环境下进行实验,使光点更清晰。
   - 平面镜应平稳放置在桌面上,与桌面同步运动。
   - 实验时应保持环境安静,避免振动干扰。
   - 刻度尺或墙壁距离平面镜越远,光点移动越明显。

### 八、注意事项

1. 实验应在较暗的环境下进行,以便清晰观察光点。
2. 激光笔不能直接对人眼照射,以免伤害眼睛。
3. 平面镜应竖直放置,镜面与桌面同步运动。
4. 两个平面镜应相距一定距离 (1~2 m 以上),距离越大,放大效果越明显。
5. 按压桌面的位置应在两个平面镜之间的中央,以保证桌面形变对称。
6. 按压力应适中,不要过大损坏桌面,也不要过小使形变不明显。
7. 此实验方法还可用于观察其他坚硬物体的微小形变,如玻璃瓶的形变等。

## 实验 3: 探究弹簧弹力与形变量的关系 (胡克定律) 「学生必做实验」

### 一、实验目的

1. 探究弹簧弹力与弹簧形变量 (伸长量) 之间的定量关系。
2. 学会用图像法处理实验数据,通过 F-x 图像分析实验结论。
3. 理解胡克定律的内容,掌握劲度系数的概念。
4. 学会测定弹簧的劲度系数。

### 二、实验器材

- 铁架台 (带铁夹)
- 弹簧 (轻质弹簧)
- 毫米刻度尺
- 钩码若干 (质量已知,通常 50 g/个)
- 三角板
- 坐标纸
- 铅笔
- 重垂线 (辅助竖直方向)

### 三、实验原理

1. **弹力与重力平衡**:在弹簧下端悬挂钩码,弹簧伸长后处于平衡状态,此时弹簧产生的弹力 F 与钩码所受重力大小相等:
   $$F = mg$$
   其中 m 为钩码质量,g 为重力加速度。

2. **形变量的计算**:弹簧的形变量 (伸长量) x 为弹簧受力后的长度 L 减去原长 L₀:
   $$x = L - L_0$$

3. **胡克定律**:在弹性限度内,弹簧的弹力 F 与弹簧的伸长量 x 成正比:
   $$F = kx$$
   其中 k 为弹簧的劲度系数,单位为 N/m。k 反映了弹簧的"软硬程度",由弹簧本身的材料、粗细、长度等决定。

4. **图像法**:以弹力 F 为纵轴、伸长量 x 为横轴建立坐标系,描点连线。若图像为一条过原点的倾斜直线,则说明 F 与 x 成正比,直线的斜率即为弹簧的劲度系数 k:
   $$k = \frac{\Delta F}{\Delta x}$$

### 四、实验步骤

1. **测原长**:将弹簧的一端固定在铁架台上,让其自然下垂,用刻度尺测出弹簧自然伸长状态时的长度 L₀ (即原长),记录数据。
2. **挂第一个钩码**:在弹簧下端挂一个钩码 (质量 m₁),待弹簧静止平衡后,用刻度尺测出此时弹簧的长度 L₁,记录 m₁ 和 L₁。
3. **改变钩码数量**:逐个增加钩码 (m₂、m₃、m₄、m₅…),每次增加后,等弹簧静止平衡,测出对应的弹簧长度 L₂、L₃、L₄、L₅…,记录数据。
4. **计算弹力和伸长量**:由 F = mg 计算每次的弹力,由 x = L - L₀ 计算每次的伸长量,填入数据表格。
5. **作 F-x 图像**:在坐标纸上以弹力 F 为纵轴、伸长量 x 为横轴建立坐标系,根据表格数据描点,用平滑曲线连接各点。
6. **分析图像**:观察 F-x 图像是否为一条过原点的倾斜直线。若是,则验证胡克定律;若不是,分析原因 (如超过弹性限度)。
7. **求劲度系数**:在 F-x 图像直线上取相距较远的两点,由斜率 k = ΔF/Δx 计算弹簧的劲度系数。

### 五、实验现象与数据记录

数据记录表 (每个钩码质量 50 g,g = 9.8 m/s²):

| 钩码个数 | 钩码质量 m/g | 弹力 F/N | 弹簧长度 L/cm | 伸长量 x/cm |
|---|---|---|---|---|
| 0 | 0 | 0 | L₀ = | 0 |
| 1 | 50 | 0.49 |  |  |
| 2 | 100 | 0.98 |  |  |
| 3 | 150 | 1.47 |  |  |
| 4 | 200 | 1.96 |  |  |
| 5 | 250 | 2.45 |  |  |
| 6 | 300 | 2.94 |  |  |

### 六、实验结果与结论

1. F-x 图像为一条过原点的倾斜直线 (在弹性限度内),说明弹簧的弹力 F 与弹簧的伸长量 x 成正比,即满足胡克定律 F = kx。
2. F-x 图像直线的斜率即为弹簧的劲度系数 k,通过计算可得 k 的值。
3. 当钩码数量过多时,F-x 图像可能开始偏离直线 (向上或向下弯曲),说明超过弹性限度,胡克定律不再适用。

### 七、误差分析

1. **系统误差**:
   - 弹簧自身重力的影响:弹簧竖直悬挂时,自身重力会使弹簧各部分受到不同程度的拉伸,导致总伸长量不等于某一集中负载的理想情况。弹簧自重使 F-x 图像与 x 轴的交点 (即 F=0 时的 x 值) 大于 0,即不挂钩码时弹簧已有一定伸长。
   - 钩码质量标称值与实际值可能有偏差。
2. **偶然误差**:
   - 弹簧长度测量误差 (刻度尺读数)。
   - 弹簧未完全静止就读数。
   - 描点作图不准确。
3. **减小误差的方法**:
   - 测量弹簧长度时一定要在弹簧竖直悬挂且处于平衡状态时进行。
   - 每次所挂钩码的质量差尽量大一些,使坐标上描的点间距尽可能大,图像更精确。
   - 描点画线时,所描的点不一定都落在一条直线上,但应使各点均匀分布在直线两侧。
   - 多次测量取平均值。

### 八、注意事项

1. **不超过弹性限度**:所挂钩码不要过重,以免弹簧被过分拉伸超过弹性限度。当 F-x 图像开始偏离直线时,应停止增加钩码。注意观察,适可而止。
2. **测量时机**:测弹簧长度时,一定要在弹簧竖直悬挂且处于平衡状态时测量,以免增大误差。
3. **测量方法**:测量弹簧长度时,应使用毫米刻度尺,读数估读到毫米的下一位。
4. **原长测量**:测原长 L₀ 时,弹簧应自然下垂 (不挂钩码),不要用手拉伸。
5. **钩码数量**:每次所挂钩码的质量差尽量大一些,使坐标上描的点间距尽可能大,图像更精确。
6. **描点连线**:作 F-x 图像时,不能连成折线,应作一条直线,让各点尽量落到直线上,落不到的点均匀分布在两侧,偏差过大的点应舍弃。
7. **记录数据**:注意弹力及弹簧伸长量的对应关系及单位。
8. **劲度系数的理解**:弹簧的劲度系数 k 由弹簧本身的性质决定 (材料、粗细、长度等),与所挂钩码多少无关,但不同弹簧 k 值不同。

## 实验 4: 摩擦力的大小和方向

### 一、实验目的

1. 观察摩擦力的存在,认识静摩擦力和滑动摩擦力的区别。
2. 理解静摩擦力的方向和大小特点。
3. 理解滑动摩擦力的方向和大小特点。
4. 体会摩擦力在生活中的作用,认识摩擦力的两面性。

### 二、实验器材

- 弹簧测力计
- 木块 (带钩)
- 长木板
- 毛巾、棉布 (改变接触面粗糙程度)
- 砝码 (若干)
- 力传感器 (可选)

### 三、实验原理

摩擦力是两个相互接触的物体,当它们发生相对运动或有相对运动趋势时,在接触面上产生的阻碍相对运动 (或相对运动趋势) 的力。

1. **静摩擦力**:两个相互接触的物体,当有相对运动趋势但没有发生相对运动时,接触面上产生的摩擦力称为静摩擦力。
   - **方向**:与相对运动趋势方向相反。
   - **大小**:随外力的变化而变化,大小等于外力 (在 0 到最大静摩擦力 f_max 之间)。当外力超过最大静摩擦力时,物体开始滑动。
   - **最大静摩擦力**:略大于滑动摩擦力,与接触面间的压力和粗糙程度有关。

2. **滑动摩擦力**:两个相互接触的物体,当发生相对滑动时,接触面上产生的摩擦力称为滑动摩擦力。
   - **方向**:与相对运动方向相反。
   - **大小**:$f = \mu N$,其中 μ 为动摩擦因数,N 为正压力。

### 四、实验步骤

#### 实验一: 观察静摩擦力

1. 用弹簧测力计水平拉木块,逐渐增大拉力,但木块仍保持静止。
2. 观察弹簧测力计的示数,记录静摩擦力的大小 (等于拉力)。
3. 逐渐增大拉力,直到木块刚开始滑动,记录最大静摩擦力 f_max。
4. 观察静摩擦力随拉力变化的情况:静摩擦力随外力增大而增大,达到最大值后物体开始滑动。

#### 实验二: 观察滑动摩擦力

1. 用弹簧测力计水平拉木块,使木块在长木板上做匀速直线运动 (拉力等于滑动摩擦力)。
2. 记录弹簧测力计的示数,即滑动摩擦力的大小。
3. 比较最大静摩擦力和滑动摩擦力:滑动摩擦力略小于最大静摩擦力。
4. 改变木块运动速度 (匀速),观察滑动摩擦力是否变化 (滑动摩擦力与速度无关)。

#### 实验三: 摩擦力的方向

1. 在木块上放一张纸,推动木块,观察纸相对木块的运动方向。
2. 或在长木板上放砂纸,观察砂纸相对于木块的运动方向,从而判断摩擦力方向。
3. 用力传感器 (或弹簧测力计) 拉木块,使木块有运动趋势但未运动,观察静摩擦力方向 (与运动趋势方向相反)。

### 五、实验现象与数据记录

- 静摩擦力随外力增大而增大,达到最大静摩擦力后物体开始滑动。
- 滑动摩擦力略小于最大静摩擦力。
- 滑动摩擦力大小与运动速度无关 (匀速情况下)。
- 摩擦力方向始终与相对运动 (或相对运动趋势) 方向相反。

### 六、实验结果与结论

1. 静摩擦力大小在 0 到最大静摩擦力之间,随外力变化,方向与相对运动趋势方向相反。
2. 滑动摩擦力大小 f = μN,与正压力和接触面粗糙程度有关,与接触面积和速度无关 (在通常情况下),方向与相对运动方向相反。
3. 最大静摩擦力略大于滑动摩擦力。

### 七、误差分析

1. **系统误差**:
   - 弹簧测力计本身的零点误差。
   - 木块匀速运动难以精确控制,实际可能为变速运动。
2. **偶然误差**:
   - 弹簧测力计读数误差。
   - 接触面状态不一致 (如有灰尘、磨损)。
3. **减小误差的方法**:
   - 实验前对弹簧测力计调零。
   - 用力传感器代替弹簧测力计,可实时显示拉力大小,精度更高。
   - 多次实验取平均值。

### 八、注意事项

1. 用弹簧测力计拉木块时,拉力应沿水平方向,与接触面平行。
2. 测量滑动摩擦力时,应使木块做匀速直线运动,这时拉力才等于滑动摩擦力。
3. 实验中应注意区分"静摩擦力"和"滑动摩擦力"的测量方法。
4. 用力传感器测量更精确,可显示拉力随时间变化的曲线,便于分析。

## 实验 5: 探究滑动摩擦力的影响因素

### 一、实验目的

1. 探究滑动摩擦力大小与哪些因素有关。
2. 理解滑动摩擦力公式 f = μN 的含义。
3. 学会用控制变量法研究多变量问题。
4. 测定动摩擦因数 μ 的值。

### 二、实验器材

- 弹簧测力计 (或力传感器)
- 木块 (带钩)
- 长木板
- 毛巾、棉布、玻璃板 (改变接触面粗糙程度)
- 砝码 (若干)
- 天平

### 三、实验原理

滑动摩擦力的大小可能与多个因素有关:接触面的粗糙程度、正压力大小、接触面积、运动速度等。本实验用控制变量法逐一探究。

**控制变量法**:
- 探究 f 与正压力 N 的关系:保持接触面粗糙程度、接触面积、速度不变,改变正压力 (在木块上加砝码),测量对应的滑动摩擦力。
- 探究 f 与接触面粗糙程度的关系:保持正压力、接触面积、速度不变,改变接触面材料 (木板、毛巾、棉布、玻璃板),测量对应的滑动摩擦力。
- 探究 f 与接触面积的关系:保持其他条件不变,改变木块的接触面积 (如把木块立放、侧放、平放),测量对应的滑动摩擦力。
- 探究 f 与速度的关系:保持其他条件不变,以不同速度匀速拉动木块,测量对应的滑动摩擦力。

**滑动摩擦力公式**:$f = \mu N$,其中 μ 为动摩擦因数,与接触面材料和粗糙程度有关;N 为正压力。

### 四、实验步骤

1. **调零**:实验前对弹簧测力计 (或力传感器) 进行调零。

2. **探究 f 与正压力 N 的关系** (控制其他条件不变):
   - 用弹簧测力计水平匀速拉动木块在长木板上滑动,记录滑动摩擦力 f₁。
   - 在木块上加一个砝码 (增加正压力),再次匀速拉动,记录 f₂。
   - 继续增加砝码,记录多组 (N, f) 数据。
   - 分析:f 与 N 是否成正比?

3. **探究 f 与接触面粗糙程度的关系** (控制正压力等其他条件不变):
   - 保持木块和砝码不变,在长木板上铺毛巾,匀速拉动木块,记录摩擦力。
   - 换成棉布,匀速拉动木块,记录摩擦力。
   - 换成玻璃板,匀速拉动木块,记录摩擦力。
   - 分析:接触面越粗糙,摩擦力是否越大?

4. **探究 f 与接触面积的关系** (控制其他条件不变):
   - 木块平放 (接触面积最大),匀速拉动,记录摩擦力。
   - 木块侧放 (接触面积较小),匀速拉动,记录摩擦力。
   - 木块立放 (接触面积最小),匀速拉动,记录摩擦力。
   - 分析:f 与接触面积是否有关?

5. **探究 f 与速度的关系** (控制其他条件不变):
   - 以较慢速度匀速拉动木块,记录摩擦力。
   - 以较快速度匀速拉动木块,记录摩擦力。
   - 分析:f 与速度是否有关?

6. **计算动摩擦因数**:由 f = μN,得 μ = f/N,计算木块与木板之间的动摩擦因数。

### 五、实验现象与数据记录

**f 与 N 的关系** (接触面为木板):

| 砝码个数 | 正压力 N/N | 滑动摩擦力 f/N | μ = f/N |
|---|---|---|---|
| 0 |  |  |  |
| 1 |  |  |  |
| 2 |  |  |  |
| 3 |  |  |  |

**f 与接触面粗糙程度的关系** (正压力相同):

| 接触面材料 | 滑动摩擦力 f/N |
|---|---|
| 毛巾 |  |
| 棉布 |  |
| 木板 |  |
| 玻璃板 |  |

### 六、实验结果与结论

1. 滑动摩擦力 f 与正压力 N 成正比,比值 f/N = μ 为常数,即动摩擦因数。
2. 滑动摩擦力与接触面的粗糙程度有关:接触面越粗糙,动摩擦因数越大,摩擦力越大。
3. 滑动摩擦力与接触面积无关 (在通常情况下)。
4. 滑动摩擦力与运动速度无关 (在通常情况下,速度不太大时)。
5. 滑动摩擦力公式:f = μN,其中 μ 由接触面材料和粗糙程度决定。

### 七、误差分析

1. **系统误差**:
   - 弹簧测力计本身的误差。
   - 木块匀速运动难以精确控制 (实际为变速运动)。
   - 接触面状态可能不一致。
2. **偶然误差**:
   - 弹簧测力计读数误差。
   - 接触面磨损或灰尘影响。
3. **减小误差的方法**:
   - 使用力传感器,实时显示拉力,精度更高。
   - 多次测量取平均值。
   - 实验前确保接触面清洁、状态一致。
4. **实验改进**:用图象法处理数据,作 f-N 图像,若为过原点的直线,则验证 f ∝ N,直线斜率为 μ。

### 八、注意事项

1. 拉动木块时,拉力应沿水平方向,与接触面平行。
2. 测量滑动摩擦力时,必须使木块做匀速直线运动,这时拉力才等于滑动摩擦力。
3. 实验中要严格控制变量,每次只改变一个因素,其他因素保持不变。
4. 加砝码时,要确保砝码稳固放置在木块上,不与木板接触。
5. 改变接触面积时,要保证正压力 (即总重力) 不变。
6. 注意实验结论的适用范围:滑动摩擦力与接触面积、速度无关是在通常情况下,极高速或极低速时可能有差异。

## 实验 6: 探究两个互成角度的力的合成规律 (验证平行四边形定则) 「学生必做实验」

### 一、实验目的

1. 验证互成角度的两个力合成时遵循平行四边形定则。
2. 学会使用弹簧测力计,练习用作图法求两个力的合力。
3. 体会"等效替代"的物理思想。
4. 培养科学探究能力和实验数据处理能力。

### 二、实验器材

- 方木板 (或平板)
- 白纸
- 图钉若干
- 橡皮条 (一端固定,一端可系细绳)
- 细绳套 (两个)
- 弹簧测力计 (两个)
- 三角板
- 刻度尺
- 铅笔

### 三、实验原理

如果一个力 F' 的作用效果与两个力 F₁、F₂ 共同作用的效果相同,那么 F' 就是 F₁ 和 F₂ 的合力,F₁、F₂ 是 F' 的分力。

**等效替代法**:本实验利用一个力拉橡皮条和两个力共同拉橡皮条产生相同的形变效果 (橡皮条伸长到同一位置),实现等效替代。

**实验验证**:
1. 用两个弹簧测力计互成角度地拉橡皮条,使橡皮条的结点到达某位置 O,记录两拉力 F₁、F₂ 的大小和方向。
2. 用一个弹簧测力计单独拉橡皮条,使结点到达同一位置 O,记录拉力 F' 的大小和方向。
3. 根据平行四边形定则,以 F₁、F₂ 为邻边作平行四边形,其对角线即为理论合力 F。
4. 比较 F (理论值) 和 F' (实验值) 的大小和方向,若在误差允许范围内相同,则验证了平行四边形定则。

### 四、实验步骤

1. **固定白纸**:用图钉把一张白纸钉在水平桌面上的方木板上。
2. **固定橡皮条**:用图钉把橡皮条的一端固定在方木板上的 A 点,橡皮条另一端系上两条细绳套。
3. **两力拉 (实验组)**:
   - 用两个弹簧测力计分别钩住两个细绳套,互成角度地拉橡皮条,使橡皮条伸长,结点到达某一位置 O。
   - 用铅笔描下结点 O 的位置和两根细绳的方向,并记录两个弹簧测力计的读数 F₁、F₂。
4. **一力拉 (对照组)**:
   - 只用一个弹簧测力计,通过细绳套把橡皮条的结点拉到与前面相同的位置 O。
   - 记下弹簧测力计的读数 F' 和细绳的方向。
5. **作图验证**:
   - 取下白纸,按选定的标度,用铅笔和刻度尺从 O 点沿两细绳方向作出 F₁ 和 F₂ 的图示。
   - 以 F₁ 和 F₂ 为邻边,用三角板作平行四边形,过 O 点画对角线,此对角线代表的力即为理论合力 F。
   - 从 O 点按同样的标度沿记录的方向作出 F' 的图示。
6. **比较**:比较 F 与 F' 的大小和方向,看它们在实验误差允许的范围内是否相同。
7. **重复实验**:改变两个弹簧测力计的拉力大小和方向 (即改变 F₁、F₂ 之间的夹角),重复上述实验。

### 五、实验现象与数据记录

- 用两个弹簧测力计拉橡皮条时,结点 O 到达某位置;用一个弹簧测力计拉时,结点 O 到达同一位置。
- 在白纸上作出的 F (理论合力,对角线) 和 F' (实验合力,沿细绳方向) 在大小和方向上接近相同。

数据记录表:

| 物理量 | F₁ | F₂ | F (理论值) | F' (实验值) |
|---|---|---|---|---|
| 大小/N |  |  |  |  |
| 方向 |  |  |  |  |

### 六、实验结果与结论

1. 在误差允许范围内,理论合力 F 与实验合力 F' 的大小和方向相同,验证了互成角度的两个力合成时遵循平行四边形定则。
2. 结论:两个互成角度的共点力合成时,以表示这两个力的线段为邻边作平行四边形,这两邻边之间的对角线就代表合力的大小和方向,这就是力的平行四边形定则。
3. 此实验体现了"等效替代"思想:用两个力的共同作用效果与一个力的作用效果等效,从而求出合力。

### 七、误差分析

1. **系统误差**:
   - 弹簧测力计本身的零点误差或刻度不准。
   - 弹簧测力计与木板之间有摩擦 (使用时应使弹簧测力计与木板平行)。
2. **偶然误差**:
   - 读数误差:读数时视线未与刻度垂直,或未估读。
   - 作图误差:作平行四边形时两对边不严格平行,或线段长度不准。
   - 方向记录误差:细绳方向记录不准,或细绳套较短难以确定方向。
   - 结点位置不一致:两次拉动结点未到达完全相同的位置。
3. **减小误差的方法**:
   - 实验前对弹簧测力计调零,并将两个测力计对拉检查示数是否相同。
   - 在不超过弹性限度的条件下,拉力尽量大一些,以减小相对读数误差。
   - 细绳套应适当长一些,便于准确确定方向 (相距较远的两点确定方向)。
   - 读数时视线应与弹簧测力计刻度垂直。
   - 作图时使用刻度尺和三角板,使平行四边形的对边严格平行。
   - 在同一次实验中,画力的图示选定的标度要相同。

### 八、注意事项

1. **调零**:实验前必须对弹簧测力计进行调零,并将两个测力计的挂钩互拉检查示数是否相同。
2. **平行**:弹簧测力计、橡皮条、细绳应与木板表面平行,避免与木板摩擦。
3. **结点位置一致**:同一次实验中,两次拉橡皮条时结点必须到达同一位置 O,这是实验的关键,体现了等效替代思想。
4. **夹角合适**:两个弹簧测力计拉橡皮条时,夹角应合适,以 60°~120° 为宜。夹角过小或过大都会增大实验误差。
5. **拉力大小**:在不超过弹簧测力计量程和橡皮条弹性限度的条件下,拉力应尽量大一些,以减小相对误差。
6. **细绳套长度**:细绳套应适当长一些,便于准确确定拉力方向 (用相距较远的两点确定方向)。
7. **统一标度**:在同一次实验中,画力的图示选定的标度要相同,并且要恰当选定标度,使力的图示稍大一些。
8. **作图规范**:作图时使用刻度尺和三角板,平行四边形的对边要严格平行。
9. **记录方向**:用相距较远的两点确定细绳方向,不要只记一点。

## 实验 7: 探究作用力与反作用力的关系 (牛顿第三定律)

### 一、实验目的

1. 通过实验探究作用力与反作用力的大小、方向关系。
2. 理解作用力与反作用力总是大小相等、方向相反、作用在两个物体上。
3. 学会使用弹簧测力计和力传感器进行实验。
4. 理解牛顿第三定律的内容,体会相互作用力的同时性。

### 二、实验器材

- 弹簧测力计 (两个)
- 力传感器 (两个)
- 数据采集器
- 计算机 (配套软件)
- 木块、细绳

### 三、实验原理

力是物体对物体的作用,物体间力的作用是相互的。一个物体对另一个物体施加力的作用时,同时也受到另一个物体对它的反作用力。这一对力称为作用力和反作用力。

**探究方法**:
1. **用弹簧测力计探究**:将两个弹簧测力计的挂钩钩在一起,对拉。分别读出两个测力计的示数,比较大小和方向。可在静止、匀速运动、加速运动等不同状态下探究。
2. **用力传感器探究**:将两个力传感器的挂钩钩在一起,对拉。通过数据采集器和计算机,实时显示两个力传感器受力随时间变化的图线,可观察任意时刻两个力的大小和方向关系。

**牛顿第三定律**:两个物体之间的作用力和反作用力,总是大小相等,方向相反,作用在同一条直线上。

### 四、实验步骤

#### 实验一: 用弹簧测力计探究

1. **静止状态下的探究**:
   - 取两个调好零的弹簧测力计 A、B,将两挂钩钩在一起。
   - B 固定,A 用手拉着。观察两测力计的示数,记录 F_A 和 F_B 的大小和方向。
   - 改变拉力大小,重复实验多次。
2. **水平运动状态下的探究**:
   - 将两个弹簧测力计挂钩钩住,B 连接一块木块,A 用手拉着。
   - 用手拉 A 使木块在水平面上运动 (先匀速、后加速)。
   - 观察并记录两测力计的示数 F_A 和 F_B 的大小和方向,比较两者关系。
3. **竖直方向运动状态下的探究**:
   - 将拉动方向改为竖直方向,重复上述探究。

#### 实验二: 用力传感器探究

1. **连接器材**:将两个力传感器接入数据采集器,连接到计算机,启动配套软件。
2. **传感器调零**:对两个力传感器进行调零。
3. **静止状态下的探究**:
   - 取 A、B 两个力传感器,使两挂钩钩住,B 固定,A 用手拉着。
   - 以不同力拉 A 一段时间,通过数字化实验系统记录两传感器间的相互作用力 F_A 和 F_B 随时间变化的图线。
   - 观察两条曲线:它们关于时间轴对称,即一个为正值时,另一个为负值,大小相等。
4. **运动状态下的探究**:
   - 在水平方向、竖直方向分别使传感器运动 (匀速、加速),记录 F-t 图线。
   - 观察两条曲线是否仍保持大小相等、方向相反的关系。
5. **数据分析**:任取若干时刻,结合图线读出这些时刻两个传感器的相互作用力,比较大小和方向。

### 五、实验现象与数据记录

- 静止状态下:两个弹簧测力计 (或力传感器) 示数大小相等,方向相反。
- 匀速运动状态下:两个示数仍大小相等、方向相反。
- 加速运动状态下:两个示数仍大小相等、方向相反。
- 力传感器的 F-t 图线显示:两条曲线关于时间轴对称,同时上升、同时下降、同时为零。

### 六、实验结果与结论

1. 无论物体是静止还是运动,是匀速还是加速,作用力与反作用力总是大小相等、方向相反、作用在同一直线上。
2. 作用力与反作用力同时产生、同时变化、同时消失,具有同时性。
3. 作用力与反作用力分别作用在两个物体上,不能相互抵消 (不同于平衡力)。
4. 作用力与反作用力是同种性质的力 (如都是弹力、都是摩擦力等)。
5. **牛顿第三定律**:两个物体之间的作用力和反作用力,总是大小相等,方向相反,作用在同一条直线上。

### 七、误差分析

1. **系统误差**:
   - 弹簧测力计本身的示值误差 (不同测力计可能略有差异)。
   - 力传感器的零点漂移。
2. **偶然误差**:
   - 弹簧测力计读数误差 (尤其在运动状态下难以读数)。
   - 两个弹簧测力计拉力方向不在同一直线上。
3. **减小误差的方法**:
   - 实验前对弹簧测力计 (或力传感器) 调零。
   - 选用示值相同的弹簧测力计 (可将两测力计挂钩互拉,选读数相同的一对)。
   - 用力传感器代替弹簧测力计,可实时显示拉力大小,精度更高,且能观察运动状态下的力。
   - 拉力方向应在同一直线上。
   - 使用力传感器时也要调零,确保拉力在同一直线上。

### 八、注意事项

1. **调零**:使用弹簧测力计或力传感器前,必须先调零。
2. **共线**:弹簧测力计或力传感器对拉时,作用力要在同一直线上。
3. **示值误差**:实际弹簧测力计存在一定的示值误差,若发现两示数不等,可将 A、B 分别与第三个测力计 C 互拉,通过等效替代方法比较两力是否相等。
4. **力传感器使用**:用力传感器对拉时也要使作用力在同一直线上,且需调零。
5. **同时性观察**:用力传感器可清楚观察到作用力与反作用力的同时性——同时产生、同时变化、同时消失。
6. **平衡力与相互作用力的区别**:作用力与反作用力作用在两个物体上,不能相互抵消;而平衡力作用在同一物体上,可以相互抵消。这是两类力的本质区别。
7. **普适性**:牛顿第三定律适用于任何情况,无论物体大小、形状、运动状态如何,均成立。
